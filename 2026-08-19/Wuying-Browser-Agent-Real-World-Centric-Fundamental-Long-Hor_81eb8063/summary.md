# 论文速读：Wuying-Browser-Agent-Real-World-Centric-Fundamental-Long-Hor

## 一句话总结
论文针对浏览器智能体在真实长程部署中面临的“错误恢复弱、长轨迹信用分配稀疏、双语长程评测缺失”三大结构性瓶颈，提出从执行底座、监督信号、在线优化到评估基准的协同设计框架。通过 RUIC-SFT 课程化微调与 DAO-GRPO 在线强化学习，Wuying-Browser-Agent-27B 在 WebVoyager、Online-Mind2Web 与 BrowserBench 上刷新开源 SOTA，并展现出向通用 Agentic 任务的强迁移能力。

## 研究问题与动机
1. **训练数据以成功轨迹为主，缺乏错误恢复监督**：真实长程交互中智能体必然遭遇页面重定向、状态突变或复杂控件，但现有演示数据几乎全为正样本，导致基座模型仅能恢复约 8.5% 的已偏离步骤，复杂 UI 模式也因分布稀疏而无法靠规模习得。
2. **长轨迹稀疏终端奖励导致信用分配稀释**：同任务的多条 rollout 往往共享超长前缀，仅在少数决定性分支步产生行为差异；若采用统一轨迹级优化，学习信号会被冗长前缀稀释，且浏览器上下文具有动态替换特性，传统追加式 transcript 会导致训练分布与在线推理错位。
3. **评测基准严重低估真实部署 regime**：现有在线基准高度英语中心化且任务偏短（如 WebVoyager 中位数 8-15 步，Online-Mind2Web 平均 8.4 步），中文网络覆盖几乎空白，难以暴露智能体在长 horizen 下的规划断裂与恢复失效模式。

## 核心贡献（创新点）
1. **提出协同设计的长程浏览器智能体训练管线**：打破单一依赖 Scale-up 或静态演示的范式，将执行层、监督层、优化层与评估层统一对齐至真实长程部署场景，区别于以往孤立优化模型架构或算法的工作。
2. **设计 RUIC-SFT 课程化监督初始化**：显式引入反思纠错轨迹与复杂 UI 组件数据，并通过三阶段渐进退火混合策略稳定训练，使模型同时具备基础操作鲁棒性与事后自我修正能力，区别于仅模仿成功路径的常规 SFT。
3. **提出 DAO-GRPO 在线强化学习优化器**：融合潜力奖励塑形（PBRS）提供密集进度信号、LLM 分歧估计器定位关键分支步并进行差异化权重分配、以及逐步骤上下文重构的对齐目标，解决长轨迹稀疏反馈下的信用归属难题，区别于标准 GRPO 的均匀轨迹级优化。
4. **构建 BrowserBench 双语长程真实网页基准**：收录 350 个中英双语任务（平均 37.9 步，最长 100 步，覆盖 254 个真实网站），采用 Goal-only 指令与结构化成功标准，填补现有基准在长程与多语言维度的评估空白。
