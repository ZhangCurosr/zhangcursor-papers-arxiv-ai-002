# 论文速读：SPADE-Speculative-Decoding-for-Precise-and-Low-Cost-Distribu

## 一句话总结
本文提出 SPADE，一种将投机解码（Speculative Decoding）迁移至边缘-云端异构架构的即插即用分布式推理框架：轻量草稿模型在边缘侧快速自回归生成候选 token，云端大模型单次前向传播并行验证，仅拒绝时才触发云端修正。该方法在保证输出分布与全量云端模型严格等价的前提下，将云端模型调用量降低约 76%，显著压缩推理延迟与计算成本。

## 研究问题与动机
1. **纯边缘与纯云端的性能-成本悖论**：直接在边缘部署压缩版 LLM 会显著降低生成质量；而全量模型托管云端虽保真，但自回归逐 token 计算导致云端负载与费用随输出长度线性增长。
2. **现有分布式推理方案的缺陷**：层分割（Layer-splitting）、早期退出（Early-exit）等方法要么依赖数据集特定的启发式路由策略，要么在宽松/严格路由下难以同时兼顾精度与开销，泛化性受限。
3. **云端按需调用的效率浪费**：云端推理服务通常按调用次数计费，传统方式每个 token 均需完整前向传播，无法充分利用边缘侧闲置算力进行粗粒度预测。
4. **投机解码的架构解耦潜力**：投机解码原本要求草稿与验证模型紧密配合；将其草稿端下沉至边缘、验证端留驻云端，可打破单机算力束缚，实现真正的低成本混合推理。

## 核心贡献（创新点）
1. **边缘-云端分布式投机解码框架（SPADE）**：首次将投机解码范式应用于异构边缘-云部署，边缘负责快速草稿生成，云端负责并行验证。*与现有投机解码方法本质不同在于：打破了草稿/验证模型必须同构或共享算力的假设，实现计算下沉与按需验证的自然分层。*
2. **零训练成本的即插即用设计**：框架直接复用预训练轻量模型与全规模模型，无需任何联合微调或蒸馏即可上线。*区别于知识蒸馏或量化压缩方法，该方法不牺牲模型表达能力，且兼容任意尺寸匹配的边缘-云端模型对。*
3. **严格的概率等价性保障**：通过标准接受-拒绝准则与修正分布重采样，理论上保证最终输出序列与纯云端大模型完全一致。*与早期退出等近似推理方法不同，SPADE 提供理论上的零精度损失保证。*
4. **系统级效率量化与超参调度**：提出以草稿长度 $d$ 为核心的控制机制，平衡边缘计算开销、网络传输延迟与云端验证频率，并在多任务基准上验证吞吐提升与云端耗时压缩。*区别于单纯追求算法加速的工作，本文从系统工程视角量化了 edge-cloud 协同的真实推理收益。*

## 方法详解
1. **双模型协同架构**：边缘侧部署紧凑草稿模型 $\mathcal{M}_q$（如 LLaMA-3.2-1B），负责在受限内存下自回归生成长度为 $d$ 的候选 token 序列；云端部署全规模验证模型 $\mathcal{M}_p$（如 LLaMA-3.1-8B），负责单次前向传播并行计算该序列每个位置的条件概率分布。
2. **接受-拒绝验证准则**：对于草稿分布 $q(x)$ 提出的候选 token $x$，按概率 $\alpha(x) = \min\left(1, \frac{p(x)}{q(x)}\right)$ 决定是否接受（$p(x)$ 为云端目标分布）。接受则直接追加至输出序列。
3. **首次拒绝处理机制**：若第 $j$ 个 token 被拒绝，则从修正分布 $p'(x) = \text{norm}(\max(0, p(x) - q(x)))$ 中重采样替换该位置，丢弃后续草稿 token，并以修正后的上下文继续下一轮生成。该过程保证了统计分布与纯验证模型解码等价。
4. **流水线执行流程（Algorithm 1）**：初始化提示词 $y_{1:m}$ → 边缘生成 $y_{m+1:m+d}$ → 单次传输至云端 → 云端并行计算 $[y_{m+1}^*, \dots, y_{m+d+1}^*]$ → 并行验证并接受最长前缀 $y_{m:m+k}$ → 采样修正 token $\tilde{y}_{m+k+1}$ → 更新上下文 $m \leftarrow m+k+1$ → 循环至 `<eos>`。
5. **草稿长度超参 $d$ 的调节**：$d$ 控制每次云端验证前的生成长度。$d$ 过小会导致频繁同步与通信瓶颈；$d$ 过大则增加边缘计算负担与 rejection 概率
