# 论文速读：Tracing Provenance and Detecting Tampering with Complementary LLM Watermarks

## 一句话总结
本文提出 **Cocktail** 水印方法，通过在每生成 token 中联合嵌入一个鲁棒信号（服务溯源）和一个脆弱信号（服务篡改检测），解决了现有 LLM 水印在抵御"搭车伪造"（piggyback spoofing）攻击方面的根本性困境，实现了三态决策（完整/已篡改/无水印）。

## 研究问题与动机
- **现有水印的单信号困境**：为抵御编辑保持鲁棒性的水印，使攻击者可以在篡改关键内容的同时保留溯源归属，形成"搭车伪造"漏洞。
- **鲁棒性与敏感性的互斥**：溯源需要信号对编辑免疫，篡改检测需要信号对编辑敏感，单一信号无法同时满足两者。
- **既有两信号方案的缺陷**：最接近的工作 Bileve 以签名方式嵌入信号，其载体 token 不受签名保护；检测时对重分词敏感，未编辑文本验证失败率达 91.1%；质量损失严重（PPL 升至 62.2，约为基线 6 倍）。
- **Token-ID 与读者可见内容的脱节**：现有方法以 token ID 作为种子和载体，导致隐形编辑（如同形替换）可破坏检测；需以读者实际接收的归一化文本为锚点定义篡改证据。

## 核心贡献（创新点）
1. **解耦设计解决二元困境**：在一篇文本中同时嵌入鲁棒信号和脆弱信号，将二值决策扩展为三态决策，两者分别服务于溯源和篡改检测。
2. **以归一化文本而非 Token-ID 定义篡改证据**：将信号种子锚定于读者实际接收的归一化文本，使篡改检测针对可见内容而非生成中间量，奠定了三态决策的基础。
3. **无偏 tournament 联合嵌入**：通过多轮无偏概率重加权将双信号共同嵌入每个 token，不损失生成质量（PPL 与基线持平），且信号强度比可通过周期轮次分配模式 tunable。
4. **实验验证超越所有单信号基线**：在两个 LLM 和两个数据集上，Cocktail 的篡改检测率比最强单信号基线高出超过 66 个百分点，同时保持有竞争力的溯源能力和困惑度。

## 方法详解
**Cocktail 方法包含三个核心机制：**

1. **互补信号设计**：
   - 两个独立绿红列表 $g_r$（鲁棒）和 $g_f$（脆弱），由不同密钥 $k_r \neq k_f$ 生成，互不相关。
   - 鲁棒信号采用短窗口 $h_r=1$（仅前 1 个 token），编辑影响范围有限；脆弱信号采用长窗口 $n_f$（全归一化前缀），单个编辑影响下游所有 token。
   - 种子均以归一化文本 $\mathcal{N}(\cdot)$ 计算：$s_r(t) = H(\mathcal{N}(x_{\max(1,t-h_r):t-1}))$，$s_f(t) = H(\text{suffix}_{n_f}(\mathcal{N}(x_{1:t-1})))$。

2. **无偏联合嵌入（向量 tournament）**：
   - 借鉴 SynthID 的两样本 tournament 的闭式表达，每轮 $i$ 用独立的绿红列表 $g^{(i)}$ 重加权分布：$\hat{p}^{(i)}(x) = (1 + g^{(i)}[x] - q^{(i)}) \hat{p}^{(i-1)}(x)$，其中 $q^{(i)} = \sum_{x} g^{(i)}[x] \hat{p}^{(i-1)}(x)$。
   - 由于 $g^{(i)}[x] \sim \text{Bernoulli}(0.5)$，期望调整因子为 1，故多轮后仍保持无偏性：$\mathbb{E}[\hat{p}^{(d)}(x)] = p(x)$。
   - 通过周期模式 $\pi$ 控制两轮次分配比例（如 r:1 即每 $r+1$ 轮中有 1 轮脆弱、其余鲁棒），周期分配近似实现信号强度比的可调控制。

3. **二维评分空间与三态判定**：
   - 对文本 $x$，分别计算鲁棒分 $z_r$ 和脆弱分 $z_f$：$z_* = (\sum_{t,i:\pi_i=*} g^{(i)}[x_t] - \frac{1}{2}Td_*) / \sqrt{Td_*/4}$。
   - 判定规则：$z_r > \tau_r \land z_f > \tau_f \Rightarrow \text{Intact}$；$z_r > \tau_r \land z_f \leq \tau_f \Rightarrow \text{Tampered}$；$z_r \leq \tau_r \Rightarrow \text{No-Watermark}$。
   - 脆弱窗口必须显著长于鲁棒窗口，否则两信号对编辑响应相同，评分空间退化为一维，无法分离完整与篡改状态。

## 实验与结果
- **数据集与模型**：Llama-3.2-1B 和 Gemma-3-4B；C4 realnewslike 子集和 LFQA 数据集，每组 500 篇文本。
- **基线方法**：KGW、Unigram、SynthID、SIR（均为单信号水印）。
- **评估协议**：溯源任务（attributions）和篡改检测任务（tamper evidence），报告 TPR@1%FPR（在前 300 token）。攻击方式包括：Dipper 改写、opus-mt 往返翻译、随机 token 替换、情感翻转。
- **主要结果（Table I）**：
  - **溯源**：Cocktail 各变体在未攻击文本上达 99.7–100.0%；在 4:1 模式下对改写和往返翻译的溯源与最强单信号基线相当甚至领先。
  - **篡改检测**：所有 Cocktail 变体在 1% 误报率下检出 89.5–100.0% 的篡改文本，而所有基线均不超过 23.1%，**Cocktail 超越最强基线超过 66 个百分点**。
  - **PPL**：Cocktail 保持在基线范围内（8.8–10.6），无质量损失。
  - **轮次比调节**：从 1:1 到 4:1，溯源鲁棒性提升（C4/Llama 改写任务 82.0%→92.4%），篡改检测略降（情感翻转 99.4%→97.2%），但最低值（89.5%）仍大幅领先所有基线。

## 相关工作脉络
1. **KGW / SynthID**：建立推理时嵌入框架，SynthID 提出无偏 tournament 重加权——Cocktail 在此基础上扩展为双信号联合嵌入。
2. **Unigram / SIR**：通过全局固定划分或语义种子提升编辑鲁棒性——Cocktail 承认鲁棒性天花板，转而用互补脆弱信号补偿。
3. **Dipper / SemStamp / 其他语义方案**：关注改写得抗性，但仍是单信号——Cocktail 证明单信号无法同时满足溯源与篡改检测。
4. **Bileve**：最接近的双信号/双阶段方案，但以签名绑定 token-ID，重分词即失效；Cocktail 指出其质量代价（PPL×6）和效率代价（检测耗时 144s），并从根本上以归一化文本锚定脆弱信号。
5. **An et al. [26]**：用对比表示学习增强语义绑定，但仍是单信号，存在相同的鲁棒-敏感冲突。
6. **图像水印中的 Cocktail 概念**（Lu et al., 2000）：将鲁棒与脆弱水印成对使用——Cocktail 将此思想首次引入生成式 LLM 文本水印。

## 局限性与未来方向
- **只覆盖尾部编辑**：当前检测对所有 token 打分，若编辑仅发生在文本尾部则难以局部定位，作者自述可在尾部片段上分别计算 $z_f$ 作为扩展方向。
- **短鲁棒窗口共享泄露风险**：短窗口 $h_r=1$ 的鲁棒信号与现有鲁棒方案一样面临水印窃取（inference-based forgery）威胁。
- **泛化至其他模态**：作者指出双信号配方可扩展到需要溯源与篡改证据并重的其他生成模态（如图像、音频），但尚未在文本外验证。
- **轮次分配的精度**：轮次比是强度的单调代理而非精确线性控制，实际强度比取决于分布碰撞熵的非线性消耗。

## 研究启发与可借鉴点
1. **双信号解耦思路的通用性**：溯源与完整性检测的矛盾本质是"单一信号的两个对立属性"，Cocktail 的解耦范式可迁移到图像/音频等多模态水印、数字签名等领域。
2. **无偏重加权 + 周期分配模式**：vectorized tournament 的无偏性质保证了质量不下降，周期轮次分配作为可调强度旋钮的设计简洁且可复用于其他无偏水印框架。
3. **归一化文本作为种子锚点**：将"读者可见内容"而非"token-ID"作为信号锚点，对水印的鲁棒性和语义一致性均有显著提升，值得在其他水印方案中推广。
4. **二维评分空间 + 级联阈值判定**：将两个独立维度组合实现三态决策的设计范式清晰可复现，可直接用于构建其他需要同时验证来源与完整性的检测系统。
5. **消融实验的设计层次**：论文从归一化位置、联合嵌入 vs. 逐 token 分配、窗口长度、判定顺序四个维度逐一消融，层层递进地论证每个设计的必要性，方法论清晰。

## 关键术语表
**Piggyback Spoofing（搭车伪造）**：攻击者修改水印文本的关键内容后，利用单信号水印的鲁棒性使篡改文本仍能被溯源到原文生成者，从而冒充原文内容的攻击方式。

**Green-Red List（绿红列表）**：基于密钥和种子生成的词汇表二分标记，绿色 token 概率被提升、红色 token 概率被抑制，是 KGW 类水印的核心信号形式。

**Unbiased Reweighting（无偏重加权）**：对 token 概率分布进行调整，使调整后分布的期望等于原始分布，保证水印嵌入不改变模型的期望输出质量。

**Collision Entropy（碰撞熵 / Renyi 熵 H₂）**：$H_2(p) = -\log \sum p_i^2$，衡量分布的不确定性；每次 tournament 轮次消耗部分碰撞熵，是信号嵌入的"预算"来源。

**Normalized Text（归一化文本）**：经不可见字符清理、Unicode NFKC、同形符折叠、大小写归一、空格合并等操作后的文本，保证水印种子对读者不可见编辑保持鲁棒。

**TPR@1%FPR**：在假阳性率控制在 1% 时的真阳性率，是水印检测性能的标准评估指标。

**Score Plane（评分平面）**：由 $(z_r, z_f)$ 两个坐标构成的二维空间，三个状态（完整/篡改/无水印）在平面上占据可分离区域。
