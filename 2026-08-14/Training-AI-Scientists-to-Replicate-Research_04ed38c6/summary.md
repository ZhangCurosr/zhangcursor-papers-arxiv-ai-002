# 论文速读：Training-AI-Scientists-to-Replicate-Research

## 一句话总结
本文提出名为 **Replica** 的可扩展论文复制任务空间，并在此基础上通过后训练（RL）一个 27B 参数的 AI 科学家代理 **Faraday**。Faraday 将大型编码代理作为工具，在论文复现任务上显著超越了参数量大两个数量级的 Claude Opus 4.8 和 GPT-5.5，展现出更严谨的科学实验行为。

## 研究问题与动机
1.  **科学界的复现危机**：机器学习等领域的论文复现率低下，威胁科学知识的可靠性，而 LLM 代理理论上可提供规模化解决方案。
2.  **现有 AI 代理的不足**：复制任务本质上是“定义不良”（underspecified）的，需要推断缺失细节并进行开放探索；而现有代理多针对封闭、明确定义的问题训练，且依赖的复杂 harness（如 autoresearch）在通用复制任务中难以直接应用。
3.  **缺乏可靠的奖励信号**：科学发现过程没有明确的、可微分的奖励函数来支持传统的 hill-climbing 优化，如何为长周期的非验证性任务提供低噪声的训练信号是关键挑战。
4.  **前沿模型在科学复原上的局限**：尽管编程能力强，但最新的 AI 代理在处理复制论文所需的科学严谨性、机制理解和对资源约束的适应上表现仍不理想。

## 核心贡献（创新点）
1.  **提出 Replica 任务空间**：自动化地从 100 篇经典 ML/AI-for-science 论文中生成 310 个“图表复现”任务，为训练科研代理提供了大规模、可扩展的评估基准。
2.  **设计稳定的长周期 RL 后训练方案**：通过**自动生成的评分标准（rubric-based）裁判**、**多采样裁判聚合**和**轮次级信用分配**，解决了在非验证性长周期任务中使用 GRPO 训练的稳定性问题。
3.  **训练出高效的 AI 科学家代理 Faraday**：仅用 27B 参数模型，通过利用一个估计 5T 参数的 Coding Agent 作为工具，实现了超越更大前沿商业模型（Claude Opus 4.8, GPT-5.5）的论文复制能力。
4.  **证明科学严谨性可被训练**：定性分析显示，Faraday 代理更倾向于实现实验背后的科学机制、遵循科学诚信、并在资源受限下进行忠实的缩放，而非简单地硬编码结果或走捷径。

## 方法详解
1.  **Replica 任务空间构建**：
    *   选取 1990-2026 年间 100 篇知名 ML 及 AI-for-science 论文。
    *   使用多阶段视觉-语言模型（Gemini 2.5 Pro）自动扫描、定位并不可逆地抹除论文中的结果图表，生成任务三元组：任务提示（caption）、黄金图表（gold plot，仅裁判可见）、带抹除图表的论文 PDF。
    *   任务要求代理在 60 分钟时间和单张 H200 GPU（1/7 MIG 切片）的限制下复现图表；若原实验规模不可行，则要求尽可能忠实地缩放复现。
2.  **基于评分标准的裁判（Rubric-based Judge）**：
    *   **自动评分标准生成**：使用 Claude Opus 4.7 和元提示词，为每个任务自动生成特定的评分标准（rubric），涵盖五个维度：(1) 视觉相似性，(2) 对科学主张的支持度，(3) 实验实现的忠实度，(4) 计算预算利用效率，(5) 科学诚信。黄金图表对评分标准生成器隐藏。
    *   **编码代理裁判**：使用 Codex GPT-5.5 作为裁判，赋予其与代理相同的工具有效时间，访问完整的复现工作空间（代码、git历史、交互记录、黄金图表），并依据任务专属评分标准进行多维度打分（0-1 连续值）。
    *   **训练时降噪**：对每个 rollout 独立采样裁判 3 次，取平均分作为 rollout 级奖励，以降低裁判噪声。
3.  **Coding Agent as a Tool (CAT) 架构**：
    *   Faraday 作为一个规划层，通过 shell 工具调用一个独立的编码代理（Codex CLI）来执行代码编写、调试等具体实施工作。
    *   这种分离允许小模型（Faraday）学习如何指导大模型（Coding Agent）完成复杂的科研任务。
4.  **后训练（Post-training）流程**：
    *   **基础模型**：Qwen3.6-27B。
    *   **算法**：基于 GRPO 的修改版，采用逐 turn 信用分配。
    *   **轮次级信用分配**：裁判不仅给出总分，还预测一个权重分布 $u_k$，用于对每个 agent turn 的 advantage 进行加权缩放，从而更公平地分配长轨迹内的奖励信用，稳定训练。
    *   **训练细节**：LoRA (rank 128, $\alpha=128$)，128K 上下文窗口，学习率 $6 \times 10^{-6}$，每批次 10 个任务各 8 个 rollout，异步训练。

## 实验与结果
1.  **数据集**：Replica 训练集 242 个任务（ML论文），测试集 68 个任务（AI-for-science 论文）。
2.  **评估基线**：Claude Opus 4.8, GPT-5.5 (Codex), GLM-5.2，均在相同的资源限制和时间预算下运行。
3.  **主要结果**：
    *   Faraday 在 **73%** 的分布内（ML）任务和 **60%** 的分布外（AI-for-science）任务上击败了最强的基线 Claude Opus 4.8 和 GPT-5.5。
    *   在测试集上，Faraday 平均比 Claude 提升 **6%**，比 Codex 提升 **8%**。
    *   对 Codex 进行 24 轮自动化 prompt 优化后，性能提升微乎其微，无法缩小与 Faraday 的差距，表明提升主要来自模型本身的 post-training 而非提示工程。
4.  **裁判有效性**：人工评估实验显示，该 rubric judge 与人类专家判断的一致性（Kendall $\tau$ = 0.19）高于一个无任务特定性的基础裁判（$\tau$ = 0.15），且裁判自身的样本间一致性更高。
5.  **定性分析**：Faraday 的成功案例中，代理更倾向于完整实现论文机制（如进化搜索、技能获取流程），而非基线代理常见的硬编码预期输出或使用不恰当的黑盒模型。

## 相关工作脉络
1.  **AI 科学家的奖励信号**：与 FunSearch、AlphaEvolve 等依赖可验证、可优化的硬编码奖励不同，本文采用 LLM 裁判进行事后定性评估，适用于更开放、定义不良的研究场景。
2.  **复制基准**：相比 PaperBench、REPRO-Bench 等提供代码或部分实现的基准，Replica 给予代理最少的初始信息（仅论文和抹除的图表），更考验自主探索和复现能力，且任务规模更大、自动生成。
3.  **长周期/非验证性任务的 RL**：将 GRPO 成功扩展至长达 60 分钟、无明确终点奖励的科研复现任务，通过轮次级信用分配和多采样裁判解决了该领域已知的训练不稳定问题。
4.  **AI Scientist 系统架构**：不同于 AI-Scientist、AIRA 等采用复杂、多层、角色分离的手动设计的多代理系统，Faraday 采用更简单、灵活的 CAT 架构，通过调整外层小模型的权重来学习科研智能，而非设计复杂的内层 harness。
5.  **编程代理作为工具**：延伸了 ToolOrchestra 等“小模型使用大模型作为工具”的思路，但将工具特化为用于自由探索和实施科研的、处于标准 CLI 环境下的前沿编码代理。

## 局限性与未来方向
1.  **任务范围与资源限制**：当前任务限于单图表复现和严格的 60 分钟/单卡 GPU 限制，虽培养了高效缩放能力，但扩展到更大规模、多图表或更长周期的完整实验复现仍需验证（附录 A.1 有初步尝试）。
2.  **裁判的泛化与验证**：rubric judge 尚未在“假设性创新”任务或完全全规模复现任务上进行充分的人类验证，其判断的鲁棒性有待进一步检验。
3.  **训练数据的潜在污染**：尽管图表被抹除，但论文文本和背景知识可能存在于预训练数据中，可能对前沿模型构成一定优势，本文认为这不影响对复制过程的评估，但需在实际应用中注意。
4.  **可扩展性的挑战**：随着任务空间扩大到数万级别，如何有效处理那些本身存在“不可复现性”或实验失败的论文，需要裁判和代理具备识别和诚实报告失败的能力。
5.  **人类偏好的全面评估**：当前人工评估仅在裁判认为 Faraday 优势明显的子集上进行，尚需更大规模、随机采样的研究来确定人类是否普遍偏好 Faraday 的复现结果。

## 研究启发与可借鉴点
1.  **低成本高阶智能训练**：证明可以通过在特定领域任务上进行后训练，让一个较小的开源模型（27B）学会有效调度和指挥远超自身能力的大型商业 API 模型，实现“小模型驾驭大模型”的科研智能，具有显著的性价比优势。
2.  **长周期非验证任务的 RL 稳定训练技巧**：提出的**轮次级信用分配**和**多采样裁判聚合**方案，为在其他长 horizon、过程不可直接验证的复杂 agent 任务（如科学研究、复杂项目管理、创意写作）上进行 RLHF/RLAIF 训练提供了有价值的参考。
3.  **自动化大规模基准构建**：展示了如何利用 VLM 和 LLM pipeline 自动化地从海量论文中生成高质量、多样化的研究评估任务，为构建领域特定 agent 基准提供了一种可扩展的方法论。
4.  **CAT 范式的灵活性**：将“编程代理作为工具”的概念明确化并成功应用于科研复制，启示了在其他需要深度领域知识整合和工具使用的复杂代理任务中，可以类似地解耦“规划/决策”与“执行”模块，分别进行优化。
5.  **科学严谨性的可训练性**：研究表明，通过精心设计的任务和奖励信号，可以引导代理养成避免捷径、实现核心机制、诚实报告等科学实践习惯，这为训练可信、可靠的科学代理指明了路径。

## 关键术语表
*   **Replica**：本文提出的一个自动生成的、用于评估 AI 代理论文复制能力的任务空间基准。
*   **Faraday**：本文训练的一个 27B 参数 AI 科学家代理，能够使用编码代理工具来复现研究论文的实验结果。
*   **Rubric-based Judge**：一种基于为每个任务自动生成的、多维度评分标准（rubric）来评估代理复现质量的 LLM 裁判系统。
*   **Coding Agent as a Tool (CAT)**：一种架构范式，其中主代理（Faraday）将具体的代码实现、调试等任务委托给一个独立的、更强大的编码代理作为工具执行。
*   **Turn-level Credit Assignment**：在 RL 训练中，由裁判模型为 agent 轨迹中的每个交互轮次分配信用权重的技术，用于解决长周期任务的奖励分配问题。
*   **Gold Plot**：在 Replica 任务中，从原始论文中提取的、被抹除的目标结果图表，仅供裁判参考，不对代理可见。
*   **GRPO**：Group Relative Policy Optimization，本文用于后训练 Faraday 的主要强化学习算法基础。
*   **AI Scientist**：指能够自主执行科学研究任务（如假设生成、实验设计、结果分析）的 AI 代理系统。

*   **数据集**：Replica 任务空间（310 个图表复现任务）。论文未明确声明是否完全开源，但给出了任务生成流程和大量示例。
*   **代码/权重**：Faraday 模型基于 Qwen3.6-27B 进行 LoRA 微调，基础模型开源。训练代码和 harness 细节在附录中部分提供，但未明确声明核心训练代码是否开源。
