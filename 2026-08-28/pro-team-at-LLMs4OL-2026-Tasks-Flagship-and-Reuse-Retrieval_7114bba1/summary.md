# 论文速读：pro-team-at-LLMs4OL-2026-Tasks-Flagship-and-Reuse-Retrieval

## 一句话总结
本文针对 LLMs4OL 2026 挑战赛的旗舰任务（Task A）与本体复用任务（Task B），提出了一种离线检索增强生成（RAG）框架，通过稠密语义检索构建动态 Few-shot 提示，并结合左侧截断的上下文管理与词汇约束过滤策略，有效抑制了大模型的 OOV 幻觉；该方法在层级关系与术语分类上取得高分，但在非层级关系抽取上因闭集提示设计而完全失效。

## 研究问题与动机
- **大模型本体学习的幻觉与格式不一致**：现有生成式 LLM 常输出预定义词汇表外的术语或格式杂乱的三元组，导致语义一致性下降且后期清洗成本高昂。
- **纯检索增强缺乏输出对齐机制**：现有 RAG 本体学习方法多聚焦于提示工程与语义检索，未显式强制生成结果与候选词汇表保持一致，OOV 问题依然突出。
- **长上下文提示易丢失关键指令**：检索多个示例会显著拉长提示，常规截断方式可能意外删除系统指令或任务约束，损害指令遵循能力。
- **传统方法缺乏深层语义理解**：基于规则与统计的传统本体学习高度依赖手工特征与领域语言学知识，难以泛化至多领域与形态复杂的文本，亟需 LLM 驱动但需加以约束。

## 核心贡献（创新点）
- **离线 RAG 本体学习框架**：结合稠密语义检索与指令引导的 LLM 推理动态构建少样本提示，与以往静态 Few-shot 方法相比，该框架能按输入文档自适应匹配最具代表性的训练样本，且全程无需微调模型参数。
- **词汇约束过滤算法（Vocabulary-Constrained Filtering）**：针对 Task B 的封闭世界假设，通过精确词法匹配剔除超出候选词汇表的非法三元组，与纯生成式流水线相比，该方法将输出严格锚定在预定义本体词汇空间内，显著降低了 OOV 幻觉。
- **左侧截断的上下文窗口管理策略**：在提示超长时优先丢弃较早的检索示例以保留系统指令与目标查询，与常见尾部截断策略相比，该设计从根本上避免了任务约束被遗忘导致的格式或逻辑错误。
- **混合抽取后处理机制**：融合 LLM 生成输出与基于句级邻近度的确定性模式匹配启发式规则，与仅依赖大模型单一生成路径相比，该设计利用词法共现规律有效补充了召回盲区，尤其缓解了生成模型遗漏分类的问题。

## 方法详解
- **问题形式化**：设输入文档集合为 $D = \{d_1, d_2, \ldots, d_n\}$。Task A 目标是从无到有构建初始本体 $O = \{(h, r, t)\}$；Task B 目标是在给定基础本体 $O_{\text{base}}$ 与新文本证据的情况下，仅推断需增量添加的新三元组 $O_{\text{new}}$，最终本体为 $O_{\text{final}} = O_{\text{base}} \cup O_{\text{new}}$。
- **稠密语义检索**：使用 `sentence-transformers/all-MiniLM-L6-v2` 将训练文档与查询文档编码为固定维度向量，通过余弦相似度 $\mathsf{sim}(q, d_i) = \frac{e_q \cdot e_i}{\|e_q\|\|e_i\|}$ 排序。Task A 检索 top-5 示例以覆盖术语抽取、分类、层级与关系抽取的多重推理需求；Task B 检索 top-2 示例，因已提供显式词汇表与部分本体，更少示例即可提供充分上下文且能控制提示长度。
- **提示构建与生成配置**：基座模型为 `Qwen2.5-14B-Instruct`，采用 16-bit 精度与贪心解码（采样关闭）。Task A 提示明确定义三元组格式并要求精确复制原文主语/宾语，同时将自然语言短语映射至闭集关系（如 `subclass of` → `is-a`）；Task B 提示强制预测直接父类关系。输入最大限制为 3072 tokens 以控制 80GB VRAM 上的 KV cache 显存与 logits 波动，Task A 最大生成 900 tokens，Task B 最大生成 320 tokens。
- **左侧截断策略**：当动态拼接的提示超过 3072 tokens 时，按时间顺序优先丢弃最早的 in-context 示例，确保系统指令（system prompt）与末尾待处理文档始终保持完整，避免关键约束被截断丢失。
- **混合抽取与词汇约束过滤（Task B 专用）**：① 确定性启发式补充：扫描文档中预定义 terms 与 types 的句级共现，若词汇距离低于高置信阈值则自动赋予 `instance-of` 关系，作为召回增强；② 词汇约束过滤：候选三元组 $[h, r, t]$ 仅当 $h$ 或 $t$ 至少一端属于样本已知词汇表（terms ∪ types ∪ 初始本体实体）时才被保留；完全重复 $O_{\text{base}}$ 已有关系的三元组直接丢弃；不进行任何词法修复或模糊匹配，严格执行精确匹配。
- **解析与输出**：采用三级回退解析器（JSON 直接解析 → 正则提取首条合法数组 → 逐行正则恢复引号包裹的三元组），去重并移除平凡自环，最终输出严格符合挑战赛 Schema 的 JSON 文件。Task A 不施加词汇约束，仅做去重与解析。

## 实验与结果
- **数据集与评估协议**：基于 LLMs4OL 2026 Challenge 官方 Task A（端到端旗舰）与 Task B（本体复用扩展）数据集。评估使用官方脚本，计算 Edge F1、Neighborhood Similarity、Taxonomy Similarity 及综合 Graph Similarity，并同步报告 Exact Match、Fuzzy Match（基于 RapidFuzz 编辑距离）与 Semantic Match（基于连续嵌入相似度）三种变体。
