# 论文速读：pro-team-at-LLMs4OL-2026-Tasks-Flagship-and-Reuse-Retrieval

## 一句话总结
本文针对大模型在本体学习（Ontology Learning）中易产生术语幻觉、格式不一致及过度偏向层级关系的问题，提出了一套离线检索增强生成（RAG）框架，结合左截断上下文管理与词汇约束确定性过滤算法，在 LLMs4OL 2026 的端到端旗舰任务（Task A）与本体扩展复用任务（Task B）上均取得显著成绩，但非层级关系提取仍面临零分瓶颈。

## 研究问题与动机
1. **生成幻觉与词汇不一致**：LLM 常输出未定义于预定义本体词汇表中的虚构术语，破坏语义一致性并增加后处理负担。
2. **层级与非层级关系提取能力失衡**：现有研究表明 LLM 在层次分类预测上表现较好，但在需要深层上下文理解的非层级关联关系识别上明显不足。
3. **长提示指令丢失风险**：检索增强 Few-shot 提示通常需要大量示例，易超出上下文窗口，传统右侧截断会丢失关键任务指令。
4. **缺乏统一闭环评估与后处理保障**：纯生成式方案缺乏对闭集假设的严格约束机制，传统方法又依赖手工规则且泛化性差，亟需兼顾语义理解与形式一致性的工程化管线。

## 核心贡献（创新点）
1. **离线检索增强生成框架**：结合密集语义检索与指令引导的 LLM 推理，动态选取相似示例作为上下文，无需微调即可适配资源受限环境。*区别于静态 Few-shot 或在线 RAG，该设计完全离线且按任务信息密度动态调整示例数量。*
2. **左截断上下文管理策略**：在长提示构建中优先保留系统指令与目标查询，自动从左侧（最旧示例）开始丢弃超出阈值的上下文。*区别于传统右侧截断，确保任务语义与生成约束的完整性不被破坏。*
3. **词汇约束确定性过滤算法（Task B）**：针对闭世界假设的复用任务，对生成三元组执行严格词汇表交集过滤，仅保留至少一端命中已知词汇或初始本体的三元组，彻底阻断 OOV 幻觉。*区别于通用生成后处理，将过滤规则与闭集假设强绑定，实现确定性去伪。*
4. **LLM + 轻量启发式混合提取管线**：在 Task B 中补充基于句子级共现距离的确定性模式匹配规则，作为生成召回的重要补充。*区别于纯神经方案，以极低计算成本弥补生成模型在分类遗漏上的固有缺陷。*

## 方法详解
- **问题形式化**：Task A 从文档集 $D$ 构建原始本体 $O = \{(h, r, t)\}$；Task B 在给定初始本体 $O_{base}$ 下仅推导需扩展的新三元组 $O_{new}$，最终本体为 $O_{base} \cup O_{new}$。
- **密集语义检索**：使用 `sentence-transformers/all-MiniLM-L6-v2` 对训练文档与输入文档编码，计算余弦相似度排序。Task A 取 Top-5 示例（开放设定需更宽上下文覆盖），Task B 取 Top-2 示例（已有明确词汇表与初始本体作为 grounding，无需过多示例）。
- **提示构建与生成本地**：采用 `Qwen2.5-14B-Instruct`（16-bit 精度，贪心解码）。输入硬性限制为 3,072 tokens（受限于 80GB VRAM 显存与 KV cache 规模），超出时触发**左截断策略**（保留指令与查询，丢弃最旧检索示例）。输出预算：Task A 最多 900 tokens，Task B 最多 320 tokens。
- **三段式解析器**：直接 JSON 解析 → 正则提取首个合法数组 → 逐行正则恢复引号包裹的三元组，提升对格式偏差的鲁棒性。
- **混合提取与词汇约束过滤（Task B 特有）**：
  1. 启发式召回增强：扫描文档中预定义术语与类型的句子级共现，词距低于高置信阈值时赋予 `instance-of` 关系，与 LLM 输出合并。
  2. 词汇约束过滤：候选三元组 $[h, r, t]$ 仅当 $h$ 或 $t$ 至少一端属于样本闭集词汇（提供的 terms + types + 初始本体已有实体）时保留；与 $O_{base}$ 重复的关系直接丢弃；严格精确匹配，不进行词形归一化。
- **输出格式化**：最终三元组转换为符合 LLMs4OL 官方评估规范的 JSON 格式提交。

## 实验与结果
- **数据集与评估**：LLMs4OL 2026 Challenge 官方数据集，覆盖 Task A（端到端旗舰）与 Task B（本体复用扩展）。评估包含 Exact/Fuzzy/Semantic Match 三种图相似度变体，以及 Term-Typing、Taxonomy Discovery、Non-Taxonomic RE 的 P/R/F1。
