# 论文速读：When-Names-Cross-Scripts-A-Source-Grounded-Benchmark-for-His

## 一句话总结
本文提出 **MHER**，一个面向蒙古世界历史人物的源验证控制基准，用于研究跨语言/跨文字的历史实体两两 reconcilation。核心结论是：仅凭名字表面形式进行历史身份推断高度依赖模型的不确定性策略，而引入与原始文献来源独立绑定的历史证据（Source-grounded）可显著提升多类模型的解析准确率（最高提升 94.44 个百分点），并使同名异人等结构难题得以有效解决；同时证明“提供上下文”不等于“提供有效证据”，源出处（provenance）控制本身是评估语义的必要组成部分。

## 研究问题与动机
1. **历史身份跨文字/跨语言的歧义性**：同一人物在不同文献中可能以完全不同的拼写、文字、转写系统或头衔出现；反之，不同人物可能共享完全相同或高度相似的名字。传统字符串匹配或音译无法独立解决身份同一性问题。
2. **现有 KB 映射范式的局限**：现代多语言实体链接默认存在完整、稳定的知识库清单。但历史长尾人物常被遗漏，史料来源碎片化且不一致，两两直接比对（pairwise reconciliation）比“提及→KB”映射更贴合历史文献聚合的实际需求。
3. **上下文基准的标签泄漏与假证据风险**：简单附加背景文本可能通过上下文重复、等价陈述或通用话题相似度间接泄露 gold label，使基准评估沦为测量文本长度或语料熟悉度，而非历史推理能力。
4. **模型对不确定性的响应策略差异巨大**：在仅有名字的情况下，不同模型表现出截然不同的行为（高频弃权 vs. 激进二分类），导致纯准确率难以公平比较，需要设计允许显式弃权（abstention）及证据干预的评估框架。

## 核心贡献（创新点）
1. **将历史实体 reconcilation 形式化为证据条件任务**：明确区分“名字表面形式”与“历史身份关系”，支持系统在证据不足时输出 AMBIGUOUS（弃权），避免强制二分类混淆错误决策与不确定性识别。与现有工作的本质区别在于不依赖完整 KB 索引，直接评估两个 source attestation 是否指向同一人。
2. **构建 MHER 源验证控制基准**：包含 396 对 Name-only 核心（84 位历史人物，实体隔离划分）与 160 对 Source-grounded 严格子集（基于 mention×source 级别的独立证据）。与已有基准的本质区别在于证据与提及一一对应，且刻意排除了上下文重复或等价陈述泄漏。
3. **设计 Leakage-aware 证据干预与证伪对照**：提出 Context-only、Source-grounded 及三种确定性打乱上下文（Shuffled context A/B/C）的对照实验，分离“历史描述本身的信息量”与“证据归属的正确性”。定位差异在于将 provenance 从元数据提升为基准语义的核心约束。
4. **提出超越强制二分类准确率的评估矩阵**：结合词汇、音译、多语言嵌入、商业/开源大模型，并引入弃权率、条件选择性准确率、概率校准指标（Brier score/log loss）及同名挑战集，系统性区分错误解析、表面形式依赖与证据使用失败。

## 方法详解
- **任务形式化**：历史人物提及表示为 $m_i = (s_i, \ell_i, \sigma_i)$（表面形式、语言、文字/转写系统）。目标判断 $y(m_a, m_b) \in \{\text{SAME, DIFFERENT}\}$。模型输出动作 $\mathcal{A} = \{\text{SAME, DIFFERENT, AMBIGUOUS}\}$，其中 AMBIGUOUS 为弃权而非第三类身份。
- **基准构建流水线**：
  1. 从多语言/多文字蒙古世界史料构建含 84 位候选历史人物的受控注册表，金标准源于学者考据而非字符串相似度；10 个学者未决案例单独保留为 expert-unresolved challenge。
  2. 按 canonical entity 划分 DEV/TEST（17/67），确保同一人不会出现在两侧；相同表面形式的硬负样本留在同一 split。
  3. **Name-only core**：生成 396 对平衡二元样本（DEV 80, TEST 316）。
  4. **Source-grounded subset**：对每侧提及绑定独立的 mention×source 证据 $e_i$（描述年代、官职、亲属、地理、参与事件等），禁止上下文直接陈述身份等价关系，要求 same 对的两侧证据必须独立来源。最终保留 160 对（DEV 52, TEST 108），该子集是 Name-only TEST 的严格子集。
  5. **控制条件**：Context-only（移除名字仅保留正确上下文）；Shuffled context（冻结的确定性错位重排，显式告知模型证据已错配）。
