# 论文速读：Your-AI-On-a-Dial-Controlling-Investment-Bias-in-LLMs-with-a-Single-Neuron

## 一句话总结
本文提出了一种"投资偏见旋钮（investment-bias dial）"，通过对单个 MLP 神经元的推理时加法干预，连续调节大语言模型的整体买卖倾向（不修改提示词或模型参数），并在五个开源 LLM 上验证了其单调性、可校准性及在 Agent、长上下文和组合构建中的下游传播效应。

## 研究问题与动机
- **核心问题**：LLM 在投资决策中存在系统性、模型特异的买卖偏见（如行业、市值、动量维度偏好），但金融场景下并不存在唯一的"正确立场"，用户需要根据投资目标灵活调节模型的整体风险偏好方向与强度。
- **现有方法不足**：提示工程对措辞敏感、效果跨模型不一致；微调则将模型锁定于固定目标，无法动态切换；现有激活引导方法干预面较宽，可能对非目标能力造成副作用。
- **三个研究问题**：(RQ1) 单个神经元能否提供单调的投资立场控制？(RQ2) 能否校准到包括中立在内的目标立场？(RQ3) 干预效果是否会传播到下游投资工作流（检索、长上下文、组合构建）？

## 核心贡献（创新点）
- **提出投资偏见旋钮**：一种基于单神经元推理时干预的新方法，无需修改 prompt 或模型参数即可连续调节 LLM 的整体买卖先验；与现有 dense activation steering（如 CAA、RepE）的本质区别在于仅操作一个 MLP 坐标，干预足迹极小。
- **两阶段自动选神经元机制**：先用梯度敏感度筛选与买卖决策相关的候选坐标，再用留出集上的 RMSE 校准误差排序，选出可迁移的控制坐标；与前人随机/启发式选取神经元的本质区别在于引入了系统化的可校准性评估。
- **在五个异构 LLM 上系统验证了单调控制与中立校准**：覆盖不同架构家族与规模，证明该方法具有跨模型泛化能力；与仅针对单一模型或单一偏见类型工作的本质区别在于其通用性与多模型实证。
- **揭示了单神经元干预的下游传播效应**：在 Agent 检索、长上下文保持和组合构建三种场景中验证了干预效果的持续性；与先前工作仅关注单点决策改变的本质区别在于揭示了模型级先验调控的系统性影响。

## 方法详解
- **投资偏见度量**：采用 Lee 等人 [18] 的受控证据冲突框架，对 427 个股票代码，每个 ticker 呈现等量匹配的多头和空头证据，要求模型输出 buy/sell 决策。ticker 级偏置得分 $\pi_s = (N_{buy}^{(s)} - N_{sell}^{(s)}) / (N_{buy}^{(s)} + N_{sell}^{(s)})$，模型级得分 $\pi$ 为所有 ticker 的聚合。
- **单神经元干预**：在解码器 MLP 块的降投影输入处，对选定坐标 $n$ 施加加法偏移：$\tilde{h}_{\ell,t}[n] = h_{\ell,t}[n] + \Delta$，在所有 token 位置（包括 prompt 和生成 token）生效，不修改模型参数或 prompt。
- **神经元选择流程（Algorithm 1）**：
  1. **决策相关性筛选**：计算每个 MLP 坐标的梯度敏感度 $G_c = |\frac{1}{|S|} \sum_{s \in S} \sum_p \frac{\partial(z_{buy}^{(s)} - z_{sell}^{(s)})}{\partial x_{\ell,p}^{(s)}[n]}|$，过滤出与买卖决策相关的候选坐标。
  2. **先验可控性评估**：将证券宇宙划分为 $S_A$ 和 $S_B$，对每个候选坐标在 $S_A$ 上估计各目标先验 $t \in \mathcal{T}$ 对应的干预系数 $\hat{\Delta}_{c,A}(t) = \text{Inv}(\pi_{c,A}, t)$，然后在 $S_B$ 上计算 RMSE 校准误差 $\text{RMSE}(c) = \sqrt{\frac{1}{|\mathcal{T}|}\sum_{t \in \mathcal{T}}[\pi_{c,B}(\hat{\Delta}_{c,A}(t)) - t]^2}$，选择 RMSE 最低的可行坐标。
  3. 在全量宇宙上重新估计校准设置。
- **能力保持评估**：使用 5 个通用基准（MMLU、GSM8K、ARC-Challenge、TruthfulQA、RACE）和 2 个金融基准（FinQA、Financial PhraseBank），在 $\pi \in \{-0.3, 0, +0.3\}$ 三个校准点上评估，配对 McNemar 检验 + BH 校正。

## 实验与结果
- **数据集与模型**：427 个 S&P 500 股票代码的匹配多空证据集；5 个开源 LLM：Qwen3-8B、Llama-4-Scout-17B-16E-Instruct、DeepSeek-R1-Distill-Qwen-14B、Gemma-4-12B-it、Mistral-Small-24B-Instruct-2501。
- **RQ1 单调性**：所有五个模型的 $\pi$ 随 $\Delta$ 单调变化。四个模型接近全区间 $[-1, 1]$，DeepSeek-R1-14B 响应范围较窄（因推理过程中出现混合决策）。选中坐标均位于网络的中间到偏后层。
- **RQ2 中性校准**（Table 3）：
  - Qwen3-8B：基线 $\pi=+0.575$，校准至 $\Delta^*=-11.44$，达到 $\pi=-0.010$，29.6% 决策改变。
  - Llama-4-Scout：基线 $\pi=+0.623$，校准至 $\Delta^*=-4.43$，达到 $\pi=-0.026$，32.5% 决策改变。
  - DeepSeek-R1-14B：基线 $\pi=+0.095$，校准至 $\Delta^*=+3.55$（反向旋钮方向），达到 $\pi=+0.010$，21.1% 决策改变。
  - Gemma-4-12B 和 Mistral-24B 基线已接近中立，无需干预。
- **能力保持**：七个基准上最大绝对变化为 1.60 个百分点，BH 校正后无显著性能退化（配对 95% 下界从 -2.49 到 -0.81 个百分点）。
- **RQ3 下游传播**：
  - **Agent 检索**：以 Qwen3-8B 为例，校准中性设置使下行信息搜索增加 88%，打开证据中下行占比增加 41%，备忘录引用中下行强调增加 74%。
  - **长上下文鲁棒性**：上下文从 ~550 增至 16,025 tokens 时，匹配的 system prompt 指令逐渐衰减，而旋钮保持稳定的空头立场。
  - **组合构建**：在 2025.8.4–2026.2.20 的周度回测中（427 只 S&P 500 股票），旋钮偏移减少了 $\Delta=0$ 时的分数饱和现象，改变了 Top-100 组合的 Sharpe 比率，强设置下 Sharpe 超过 500 个随机组合的 95th 分位。
- **对比基线**（Appendix C/E）：提示工程方法（披露、角色设定、匿名化）跨模型效果差异大，部分甚至放大偏见；dense activation steering（CAA、RepE）虽可达到类似控制范围，但 FDR 损失更多（CAA: 4/105, RepE: 2/105 vs. Dial: 0/105）。

## 相关工作脉络
- **Lee 等人 [18]**：提出受控证据冲突框架测量 LLM 隐性投资偏好，本文在此基础上实现对该偏见的连续可调控制，从"测量"推进到"干预"。
- **Dimino 等人 [9, 10]**：发现 LLM 金融决策中的位置偏见和模型置信度随公司特征变化的系统性变异，本文进一步表明这些偏见可通过单神经元进行全局调控。
- **Bini 等人 [3]**：通过提示工程（理性导向提示）减少行为偏见，但提示方法对措辞敏感且效果跨模型不一致；本文的内部干预提供了更稳定的替代方案。
- **Li 等人 [20]（Inference-Time Intervention）**：通过对注意力头激活的定向修改控制真相性；本文沿袭推理时干预思路，但将干预粒度从注意力头降维至单个 MLP 坐标。
- **Rimsky 等人 [27]（CAA）与 Zou 等人 [32]（RepE）**：dense activation steering 的代表方法，通过对比激活差或高层表示工程构造 steering vector；本文的单神经元方法与这些 dense 方法形成对比，证明了局部干预的可行性与优势。
- **Geva 等人 [12]、Liu 等人 [24]、Kazemi 等人 [15]**：神经元级别分析系列工作，分别发现事实知识神经元、社会偏见神经元、以及安全对齐的单神经元绕过；本文将这些发现延伸至金融投资偏见领域。

## 局限性与未来方向
- 旋钮仅控制模型整体的多空倾向，无法针对特定公司、行业或资产类别进行定向控制，也未解决其他形式的金融偏见（如确认偏误、呈现偏差）。
- 所有结果仅在评估的设置内经验性成立，校准后的 $\Delta$ 值不适用于不同输出空间、证据结构或推理需求的其他任务，需要重新校准或重新识别相关坐标。
- 组合回测仅为探索性演示，未考虑交易成本、滑点和执行延迟，不构成投资策略 alpha 的证据。
- 方法需要访问内部模型激活，仅适用于开源/可访问中间表示的模型；模型权重、架构、分词器或推理实现的变更可能需重新估计坐标和校准系数。
- 未来方向包括扩展到更多偏见维度（行业、市值、动量偏好）、探索任务不变的控制机制、以及在真实交易环境中的验证。

## 研究启发与可借鉴点
- **单坐标干预的极简主义设计**：仅修改一个 MLP 坐标即可实现对模型级先验的连续控制，这一极简思路可迁移到其他需要精细行为调节的领域（如风险评估倾向、合规立场等），值得在更多金融子任务中验证。
- **两阶段选神经元范式（梯度敏感度 + 留出集 RMSE 校准）**：该自动化筛选流程可复用于其他内部表征控制任务，避免了人工搜索神经元的低效；特别是将可控性评估分为发现集和验证集的做法，有效防止了过拟合到特定样本。
- **长上下文稳定性的对比实验设计**：通过与匹配 system prompt 的对比，清晰展示了内部干预相对于外部提示的优势，这一实验设计范式可用于评估其他推理时干预方法的上下文鲁棒性。
- **下游传播效应的多层次评估**：从单点决策 → Agent 检索行为 → 长上下文保持 → 组合构建，逐层验证干预效果的传播，为行为调控方法提供了系统的评估框架。
- **与 dense steering 方法的公平对比**：在相同协议下比较单神经元干预与 CAA、RepE，不仅证明了单神经元方法的有效性与更低的 FDR 损失，也为未来的 steering 方法比较提供了基准。

## 关键术语表
- **Investment-bias dial（投资偏见旋钮）**：通过对单个神经元施加推理时加法干预，连续调节 LLM 整体买卖倾向的控制机制。
- **Decision prior（决策先验）**：模型在特定任务中的整体倾向性偏好，本文中指模型倾向于 buy 或 sell 的全局倾向。
- **Gradient sensitivity（梯度敏感度）**：衡量 MLP 坐标变化对 buy-sell 决策相对偏好的影响程度，用于筛选决策相关神经元。
- **Calibration error / RMSE（校准误差）**：在留出集上评估选定坐标 reproduce 目标先验网格的准确性，用于排序候选神经元。
- **Activation steering（激活引导）**：在推理时直接修改模型内部激活表示以调控输出行为的技术总称。
- **Monotonic control（单调控制）**：干预系数 $\Delta$ 的变化导致输出指标（如投资偏置得分）单向变化的性质。
- **Evidence-conflict framework（证据冲突框架）**：通过构造等量匹配的多头和空头证据来测量模型隐性偏好的实验范式。
- **FDR losses（假发现率损失）**：在多次比较校正后仍显著的能力下降，本文用于量化干预对非目标能力的影响。
