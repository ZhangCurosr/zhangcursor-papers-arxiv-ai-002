# 论文速读：The-Retriever-Should-Remember-Experience-Amortized-Reranking

## 一句话总结
论文提出 EARM（Experience-Amortized Reranking for Memory）框架，将 LLM 相关性分数作为可累积的"检索经验"存储在因果查询-记忆矩阵中，通过在线低秩矩阵补全预测未评分候选的相关性，使 LLM 重排从每次查询的重复开销转变为跨 Agent 生命周期的可学习能力；在 LoCoMo 上较语义检索最高提升 6.62% 准确率，仅在 17.5% 候选获直接 LLM 评分时仍有效，并将总 LLM 调用量减少 74.43%。

## 研究问题与动机
- **检索器遗忘问题**：长期 Agent 的记忆库随交互不断增长，但检索流程每次都从初始状态开始；LRR 重排产生的相关性分数在每次查询后被丢弃，不积累任何"检索经验"。
- **语义检索不充分**：嵌入相似度不能等价于查询条件化的记忆相关性；词汇/主题相近的记忆未必包含答案所需证据，真正相关的记忆可能因时间距离远而被语义检索遗漏。
- **全 LLM 重排成本过高**：对 T 个查询、每个 N 个候选，点式重排最多需 TN 次 LLM 评分；对长期存活的 Agent，该成本随交互次数和候选池规模持续增长。
- **分数价值未被利用**：每次 LLM 评分都揭示了记忆可访问性的一条证据，但无状态重排器不保留这种跨查询的结构信息，导致同一批记忆反复被重新评分。

## 核心贡献（创新点）
- **将 LLM 分数定义为持久化检索状态**：构建因果查询-记忆经验矩阵 $R^{(t)}$，把每条历史相关性分数视作可复用知识；区别于仅存储记忆内容的既有工作，本文让检索器也"记住"什么记忆对哪些需求有用。
- **分层锚点采样策略（exploit + explore）**：每个查询只预算 $B_t$ 个直接 LLM 分数，其中一半从高相似区域随机采样以利用第一阶段的语义过滤，另一半从其余候选随机采样以探索低排名区域、扩大矩阵覆盖；区别于纯贪心采样或全量评分。
- **在线因果低秩矩阵补全**：采用带全局均值、记忆偏置 $\alpha_i$、查询偏置 $\beta_\tau$ 及隐因子交互 $p_i^\top z_\tau$ 的偏置低秩模型，使用 ALS 从上一解 warm-start 迭代更新；区别于离线批量矩阵分解和纯缓存方案，本文保持因果性（只用历史观测），并显式分离通用偏好与成对结构。
- **混合观测-估计排名 + 候选扩展**：最终排名优先使用直接 LLM 分数，未观测项用补全估计；不仅重排当前候选集 $C_t$，还可把历史上获得行参数支持但被当前语义检索遗漏的"白格"记忆 $E_t$ 纳入排序；区别于固定池重排，本机制使语义检索变为软边界。
- **阶段性递减预算调度**：定义经验阶段与观察比例 $\rho_\ell$，随积累逐步从 100% 降至 17.5%；证明即使只剩约六分之一的候选获得直接 LLM 评分，补全重排仍稳定优于语义检索。

## 方法详解
**整体流程**：对每个新查询 $q_t$，先由语义检索器返回 $N$ 个候选 $C_t$；按阶段预算 $B_t = \lfloor \rho_{\ell(t)} N \rfloor$ 从 $C_t$ 中分层采样锚点子集 $O_t$；LLM 打分器对 $O_t$ 产出 $s_{it}^{\mathrm{LLM}} \in [0,1]$；将其写入因果查询-记忆矩阵 $R^{(t)}$ 对应列；通过偏置低秩模型补全未观测项并对 $D_t = C_t \cup E_t$ 混合排序，取 Top-K 送入下游生成。

- **经验矩阵定义**：$R_{i\tau}^{(t)} = s_{i\tau}^{\mathrm{LLM}}$ 若 $m_i \in O_\tau$，否则 unobserved。未观测分两类：灰色格（出现在候选池但未直接评分）、白色格（不在候选池但历史上已被评估过）。
- **偏置低秩模型**：$\widehat{R}_{i\tau} = \mu + \alpha_i + \beta_\tau + p_i^\top z_\tau$，其中 $\alpha_i, p_i$ 为记忆侧参数、$\beta_\tau, z_\tau$ 为查询侧参数；矩阵补全即为估计隐式"记忆可访问性地图"。
- **损失与优化**：$\mathcal{L}_t = \sum_{(i,\tau)\in \Omega_t}(R_{i\tau}-\widehat{R}_{i\tau})^2 + \lambda(\|\alpha\|^2+\|\beta\|^2+\|P\|_F^2+\|Z\|_F^2)$，用 ALS 求解并在每步 warm-start 从上一解续跑，最大 5000 次迭代，收敛阈值 $10^{-6}$。
- **因果掩码**：对 $q_t$ 排名时仅允许使用 $\tau \le t$ 的历史观测，禁止未来查询信息泄漏；保证在线部署下的时间因果性。
- **混合打分公式**：$\widetilde{s}_{it} = s_{it}^{\mathrm{LLM}}$ 若 $m_i \in O_t$，否则 $\widetilde{s}_{it} = \widehat{R}_{it}$；选出的 Top-K 记忆按时间序还原后作为 Answer Context。
- **候选扩展**：对任一 $m_i \in \mathcal{T}_{t-1}\setminus C_t$ 且其行参数已学得的记忆，可估计其白色格 $\widehat{R}_{it}$，并入排序集合 $E_t$；该扩展不增加 LLM 评分预算，仅消耗补全推理。

## 实验与结果
- **数据集与管线**：LoCoMo 长对话基准；沿用 Mem0 的记忆提取与存储管线；问答由 GPT-4o-mini 生成并用同等 LLM 评估器判分；LLM 重排器为 Qwen3.5-4B-Q8。
- **主要数字**：
  - Top-10：EARM (r=8) 整体准确率 88.83%，较 Semantic 的 82.21% 提升 **+6.62%**；多跳 +10.29%、单跳 +7.25%；距 Full LLM reranking (91.62%) 仅差 2.79%。
  - Top-20：EARM (r=2) 整体 90.06%，较 Semantic 的 87.08% 提升 **+2.99%**；距 Full (92.40%) 差 2.34%。
  - 最低预算阶段 B5+（17.5% 直接评分）：Top-10 仍提升 5.53%，Top-20 提升 2.46%，始终优于 Semantic。
- **组件归因**：Observed-only（禁用补全）较 Semantic 提升 1.36–3.83%；重开补全后 Mixed 再提升 0.78–2.79%（最高 r=8/Top-10 处达 2.79%）。
- **开销对比**：EARM 共 78,736 次 LLM 调用，Full reranking 需 307,982 次，**减少 74.43%**；EARM 恢复 Full 相对 Semantic 增益的约 70%（Top-10）/56%（Top-20）。
- **结论**：混合观测-补全排名在大幅削减 LLM 重排预算的同时，稳定优于纯语义检索；补全本身对最终上下文质量有独立正贡献。

## 相关工作脉络
- **Mem0 / MemoryBank / MemGPT 等**：聚焦记忆提取、压缩与层次化组织，本文假定其存储管线不变，仅在检索/重排层引入"经验积累"；定位差异在于前者关心"存什么"，本文关心"如何记得怎么取"。
- **MemRL**：用强化学习从环境反馈更新记忆效用并选择策略；本文用 LLM 点式相关性分数而非任务奖励，目标为查询-记忆对的成对结构而非每条记忆的单值效用。
- **EcoRank 等预算受限 LLM 重排**：仅针对单次查询在预算内做局部决策，不跨查询复用分数；本文把评分预算摊销到持久矩阵上，跨时间复用。
- **传统矩阵分解 / 推荐系统**：多为离线批量重建；本文是因果在线设定，只允许历史列，目标是下游答案质量而非矩阵重构本身。
- **Budgeted column-space recovery**：数学形式相关但设定为预算内列空间恢复；本文输入来自 LLM 推理、仅因果历史可用、目标为问答性能。
- **Sim/Candidate cache**：缓存针对相同或近同查询复用结果；本文通过共享记忆/查询偏置与隐因子在不同查询间迁移经验，无需精确重复查询。

## 局限性与未来方向
- **固定阶段预算**：当前调度按查询索引预先设定，不能根据模型不确定性、分布漂移或冷启动记忆自适应调整。
- **低秩结构假设**：高度异构的查询流可能违反"稳定低维可访问性图"这一前提，导致补全退化。
- **点式 LLM 分数噪声**：LLM 相关性评分存在噪声、校准偏差与 prompt 敏感性，补全可能放大而非吸收误差。
- **未来方向**：可引入不确定性驱动的动态预算调度；探索与任务奖励结合的交叉监督；设计抗噪声/校准友好的分数融合与补全损失；研究非平稳场景下的记忆参数衰减与遗忘机制。

## 研究启发与可借鉴点
- **"检索记忆"作为独立持久化对象**：除内容记忆外，可为 Agent 显式维护一张"哪些记忆曾被证明对相关"的经验矩阵，这一抽象可移植到其他 RAG/检索增强场景。
- **分层 anchor 采样（exploit + explore）的通用性**：高置信区随机采样与低置信区随机采样各半的设计简洁而稳健，可直接套用到任何预算受限的排序/评估管线。
- **偏置低秩模型分离通用偏好与成对交互**：记忆偏置 $\alpha_i$ 与查询偏置 $\beta_\tau$ 显式分离"普遍高分记忆"和"普遍广泛查询"，在相似跨会话排序任务中可作为基础建模单元。
- **Warm-start ALS 的在线增量更新范式**：从上一时刻解续跑、逐步收敛，避免每次查询的全量重拟合，适用于任意序列到达、历史累积的数据矩阵。
- **候选扩展（补全白格）的思路**：把第一阶段检索器当作软边界而非硬截止，允许历史上获得支持但当前未召回的候选重新进入排名；对任何两阶段检索系统均有参考价值。

## 关键术语表
- **Experience-amortized reranking**：将多次查询上的 LLM 评分成本分摊到持久经验矩阵中，使后续查询只需少量锚点评分即可借助历史结构完成重排。
- **Retrieval-experience matrix**：行代表持久记忆项、列代表查询的稀疏相关性矩阵 $R^{(t)}$，仅在对角线因果窗口内观测过的位置含值。
- **Causal low-rank completion**：在只允许使用历史观测的前提下，用带偏置的低秩模型在线估计矩阵未观测项的查询-记忆相关性。
- **Latent memory accessibility map**：通过矩阵补全学到的隐式结构，刻画哪些记忆对哪些类型的查询更容易被检索到。
- **Mixed observed-and-completed ranking**：最终排序中，直接观测到的 LLM 分数优先使用，未观测项用补全估计填补。
- **Stratified anchor scoring**：按高相似区与剩余区各半采样的预算内 LLM 打分策略，兼顾利用与探索。
- **Content memory vs. Retrieval memory**：前者指 Agent 存储的事件/事实内容；后者指从历史检索行为中学到的"如何访问这些内容"的经验。

## 可复现要素
- **数据集**：LoCoMo（公开基准）；记忆提取/存储使用 Mem0 管线。
- **代码/权重**：代码已开源（https://github.com/FengQi-HITSZ/earm）；LLM 重排器为 Qwen3.5-4B-Q8、答案生成与评估使用 GPT-4o-mini（闭源 API）。
- **关键超参**：候选池大小 $N=200$；阶段观察比例 100%/40%/25%/20%/17.5%；每阶段每 10 个查询一组；$L_2$ 正则系数 0.1；隐秩 $r \in \{2,8\}$；ALS 最大 5000 次迭代、收敛阈值 $10^{-6}$；Top-K $\in \{10,20\}$。
