# 论文速读：WHAT-PROCESS-EVALUATION-OF-CODING-AGENTS-ACTUALLY-MEASURES-A

## 一句话总结
本文提出一个分层测量框架（含 SCAE 重放估计器），实证揭示代码智能体过程评估中**动作预测、任务不确定性与步骤因果归因**分属三个不同层级：下一步动作由执行痕迹（而非代码图）主导，不确定性主要位于任务层而非步骤层，且全轨迹 LLM 评判存在系统性碰撞偏差，实际测量的是下游语义相关性而非可认证的因果贡献。

## 研究问题与动机
1. **现有评估概念混淆**：当前过程评估常将动作级预测、任务级不确定性和步骤级因果归因视为同一问题，导致输出难以解释和验证。
2. **因果估计的理论挑战**：代码智能体轨迹中本地正向性（positivity）常缺失，上下文压缩可能破坏状态可逆性，使得步骤级因果效应难以识别。
3. **不确定性层级未明**：执行方差究竟结构化于任务实例层面还是单个步骤层面，尚未有实证检验。
4. **评判机制潜在偏差**：全轨迹 LLM 评判因条件于后续动作与终态，可能引入后处理偏差（collider bias），但其实际测量目标不明确。

## 核心贡献（创新点）
1. **三层测量框架**：将过程评估明确拆分为动作预测、任务不确定性和步骤归因三个独立层级，各层级信号不可互换。
2. **SCAE 重放估计器**：基于 Gumbel-max 结构因果模型，结合观测重放与干预分支，实现前缀条件化步骤因果效应的混合估计。
3. **执行痕迹主导动作预测**：实证表明下一步操作主要由智能体刚见过的工具输出路径（执行痕迹）驱动，代码依赖图对局部转移预测几乎无增量。
4. **任务层不确定性定位**：执行方差主要由实例身份解释（ICC=0.640），步骤位置与工具类型无显著效应，因果归因在可行重放成本下统计功效不足。
5. **碰撞偏差隔离**：通过可控信息集操纵证明，全轨迹评判在可见后续步骤时会系统性推迟归咎位置（平均偏移 +0.537），其选择偏向金标准文件相关的后期语义线索。

## 方法详解
1. **结构因果模型**：将智能体动作建模为 Gumbel-max 扰动 argmax（$A_t = \arg\max_k(\log \pi_k(S_t) + G_{\pi,k}^{(t)})$），环境状态由确定性转移函数 $\mathcal{T}$ 更新，终端结果 $Y$ 基于文件召回率计算。
2. **前缀条件化因果量**：定义步骤 $t$ 的因果效应 $\theta_t(a,a')=\mathbb{E}[Y_{A_t=a'}-Y_{A_t=a}|\tau_{1:t-1}]$，仅在已实现前缀上条件以避免后处理偏差。
3. **任何时刻值函数**：构建轨迹上的值函数 $v_t=\mathbb{E}[Y|\tau_{1:t},q,G]$，其增量 $\Delta_t=v_t-v_{t-1}$ 提供可加的步骤贡献分解。
4. **混合重放估计**：
   - **观测分支**：当重放动作熵 $\widehat{H}(\widehat{\pi}_t)>\tau_H$ 时，用 $m$ 次重放均值估计 $\widehat{v}_t$。
   - **干预分支**：当熵接近零（策略有效确定），代入替代动作 $a'$ 并实际执行，拼接真实工具输出后重放后续轨迹。
5. **不确定性分解框架**：将预测不确定性概念分解为任务不确定性 $U_{task}$、策略不确定性 $U_{policy}$ 和模型不确定性 $U_{model}$，并通过重放方差直接估计策略分量。

## 实验与结果
- **数据集**：499 个文件定位实例（来自 SWE-bench-Verified），覆盖 12 个仓库（django 占 46%）。
- **评估基线**：仓库频率基线、强化代码依赖图预测器、访问历史、执行痕迹变体（uniform/recency/frequency/last-output）、工具路由候选集等。
- **动作预测（RQ1）**：在首次访问步骤上，仅用最近工具输出的执行痕迹预测器达 top-3=0.326（CI[0.276,0.375]），远超强化图预测器的 0.058（提升 +0.136）和仓库频率基线的 0.072。
- **图结构作用（RQ2）**：连续步骤在图中无显著近邻优势（对换排列零模型，1-hop lift=0.94），但访问集合内部边密度比随机集合高 30.9 倍，图仅描述工作区域而非转移顺序。
- **不确定性层级（RQ4）**：实例身份解释 64% 重放方差（对置换零模型 ICC=0.640 vs 0.196），步骤位置与工具类型无显著效应；190 个干预估计效应中仅 5.3% 达 uncorrected $p<0.05$，0 个通过 FDR 校正。
- **评判偏差（RQ5）**：隐藏后续步骤使评判位置平均提前 +0.537（标准化位置，CI[+0.459,+0.610]），59/70 集 episode 延迟归咎；评判将 90% 裁决置于金标准相关步骤（vs 基线 41.3%），但在该类步骤内偏向后期位置（0.746 vs 均匀零模型 0.5）。

## 相关工作脉络
1. **反事实离散序列推理**：先前工作基于已知 MDP 和固定动作空间，本文面向 LLM 智能体，不假设已知转移机制，通过重放估计应对局部正向性缺失。
2. **步骤级信用分配与过程监督**：过程奖励模型（如 Math-Shepherd）常从完整 rollout 回溯标注，混入下游信息；本文关注单轨迹步骤的前缀条件因果效应，非策略优化信号。
3. **过程导向评估**：现有评估多聚焦终端成功率或人工标注一致性，本文通过可验证终端结果将过程分数测量转化为可实证检验的因果推断问题。
4. **LLM 不确定性量化**：校准研究多针对单轮生成；本文处理序列决策累积不确定性，揭示其任务级结构化特征。
5. **导航结构先验**：现有系统假设代码结构指导动作；本文实证表明图结构仅描述工作区域，局部转移由执行痕迹主导。

## 局限性与未来方向
1. **任务范围限制**：仅在文件定位子任务上验证，代码编辑/补丁合成等开放工具使用场景结论外推需谨慎。
2. **因果信号微弱**：步骤级因果效应在可行重放成本下统计功效不足，无法对单 episode 认证关键步骤。
3. **重放粒度与成本**：估计在采样前缀进行，贡献为段级近似；增加重放密度受限于不确定性本身的任务级分布。
4. **假设不可完全检验**：解码噪声外生性为结构性假设；干预分支依赖替代动作在扰动策略下的可行性假设。
5. **评判泛化性**：碰撞偏差跨模型稳定，但评判选择的语义内容（如金标准偏向）在不同模型间存在异质性。
6. **图覆盖率限制**：仅 46.2% 的智能体对象可解析到依赖图节点，自由文本查询的图表示较弱。

## 研究启发与可借鉴点
1. **分层评估范式**：可迁移至其他 agent 系统，明确区分预测、不确定性量化与因果归因目标，避免指标误用。
2. **混合识别策略**：正定性作为局部可测性质而非全局假设，结合观测重放与真实干预的自适应分支设计值得借鉴。
3. **信息集操纵实验**：通过控制评判可见性隔离机制偏差，为 LLM-as-a-judge 提供无需外部因果参考的验证方法。
4. **重放技术细节**：字节级上下文一致性、环境噪声钉扎、共随机数设计保障估计有效性的工程实践。
5. **多结果变量筛选**：基于干预敏感度（recall 2.505 > $F_1$ 2.165 > binary 1.643）选择评估指标，避免退化分布。

## 关键术语表
- **SCAE**：Step-level Causal Attribution via Execution replay，基于重放的前缀条件化步骤因果效应估计器。
- **过程评估（Process Evaluation）**：评估智能体执行轨迹质量而非仅终端结果，需区分动作/任务/步骤不同层级。
- **碰撞偏差（Collider Bias）**：条件于后代变量（如后续动作或终态）打开非因果路径，导致归因估计偏离真实因果效应。
- **执行痕迹（Execution Provenance）**：智能体在工具输出中已见路径集合，作为下一步动作的主要预测信号。
- **任何时刻值函数（Anytime Value）**：轨迹任意前缀下的条件期望终端结果 $v_t=\mathbb{E}[Y|\tau_{1:t},q,G]$。
- **局部正向性（Local Positivity）**：在给定前缀下各动作具有非零概率，为观测因果识别的前提条件。
- **共随机数设计（Common Random Numbers）**：重放中共享相同环境噪声与解码扰动，降低方差使有限重放可行。
- **前缀条件化因果效应**：仅在已实现历史 $\tau_{1:t-1}$ 上条件的步骤干预效应，避免下游信息泄漏。

## 可复现要素
- **数据集**：499 个文件定位实例来自 SWE-bench-Verified，论文未声明公开承诺，代码/脚本位于 `python3 -m pilot.analyze.*` 等命令。
- **模型与环境**：Codex CLI + gpt-5.5-0424-global 模型，沙箱只读模式，环境钉扎（locale/timezone/terminal width/hash seeds）。
- **关键超参**：重放次数 $m=8$，估计点间隔（每 episode 5 个点），熵阈值 $\tau_H=0$，BH-FDR 校正 $q=0.10$，95% 置信区间采用 episode 级 bootstrap。
