# 论文速读：WildHandBench: A Benchmark for Handwritten Text Understanding that Challenges MLLMs and Humans

## 一句话总结
本文提出了 WildHandBench——首个统一评估手写自由文本、表格与公式的多语言真实场景基准，并引入 Prior-Driven Error (PDE) 指标量化模型错误是否源于语言先验而非视觉证据；评测 18 个最先进 MLLM/OCR 模型后发现手写文档理解仍存在显著鸿沟（最佳模型 71.85% vs 人类 77.09%），且模型错误以高置信度的语言先验驱动为主（63–91%），与人类保守性错误存在质的差异。

## 研究问题与动机
- **印刷文档评测已接近饱和，但手写文档能力未量化**：OmniDocBench 顶模已达 96.34%，给人"OCR 已解决"的错觉，然而病历、表单、课堂笔记、历史档案等手写文档对当前 MLLMs 仍极具挑战。
- **现有手写基准碎片化**：既有数据集专注孤立行级识别（IAM、CASIA-HWDB、SCUT-EPT）或独立公式（CROHME、MathWriting），而表格基准（PubTabNet、FinTabNet、ICDAR Table）均基于印刷文档，缺乏统一覆盖手写自由文本+表格+公式的基准。
- **仅用准确率无法诊断错误本质**：现有评测只报告聚合准确率，无法回答错误源于视觉感知缺陷还是语言先验过度依赖，而这两类错误需要不同的建模改进。
- **MLLMs 在手写场景的幻觉风险被忽视**：既有工作（如 PINK、CHAOS-Bench）仅关注手写数学表达式或合成扰动印刷文档，从未在自然手写文档上系统性度量语言先验驱动错误。

## 核心贡献（创新点）
1. **提出 WildHandBench，首个统一覆盖手写自由文本、表格、公式的多语言真实场景基准**——与已有工作相比，现有基准要么仅覆盖单一结构，要么仅针对印刷文档，本文首次将三者置于统一评估框架下并配有校准的人类基线。
2. **引入 Prior-Driven Error (PDE) 指标**——通过外部参考语言模型计算 ppl 差值，量化模型错误中语言先验驱动的比例，超越传统准确率指标，使幻觉式识别行为可系统分析。
3. **系统性评测 18 个前沿模型并建立校准人类基线**——揭示了持续存在的"手写鸿沟"（best 71.85% vs human 77.09%）、模型与人类错误的质差异（模型 63–91% 错误为前验驱动 vs 人类仅 49%），为安全关键应用提供诊断依据。
4. **发现 OCR 专用模型在手写泛化上的劣势**——在印刷文档基准上远超通用 VLM 的 OCR 专用模型，在手写场景反而落后于通用 VLM，揭示专业化与泛化能力之间的张力。

## 方法详解
- **基准设计（三维分类法）**：每个样本按三个维度组织——语言（4 种：简体中文 333/66.6%、英文 143/28.6%、繁体中文 13/2.6%、中英混合 11/2.2%）、文档结构（3 种：自由文本 367/73.4%、表格 81/16.2%、公式 52 图含 278 个标注区域/10.4%）、真实世界场景（9 种：文学写作、书信笔记、病历、商务政务、教育、数理化材料、古典书法、日常杂项、历史档案）。
- **数据收集与标注流程**：双源收集（离线手写原稿 141 份 / 网络收集 359 份）→ 自动内容相似度去重 → MLLM 辅助预标注（3 个 SOTA 模型独立转录，仅作提示）→ 主标注员生成 Gt（Markdown/LaTeX/HTML 表格）并标注 6 维难度评分 → 独立二审员无接触复核 → 讨论达成共识，无法识别字符在原图中掩码并剔除评测。
- **识别评测指标**：自由文本用归一化编辑距离 Edit↓；公式用 CDM（Character Detection Metric，渲染后匹配边界框）↑；表格用 TEDS（Tree Edit Distance Similarity）↑；综合分数 = [(1−Edit)×100 + CDM + TEDS] / 3。
- **PDE 指标设计**：对每个错误段，用外部参考语言模型 Qwen3-8B-Base 计算模型预测段 m_i 与 Gt 段 g_i 的 ppl；若 ppl(m_i) < ppl(g_i)，则判定为语言先验驱动错误（含插入内容 g_i=ppl=∞ 恒为前验驱动）；PDE(s) = Σ[I(ppl(m_i)<ppl(g_i))·|m_i|] / Σ|m_i|，模型最终 PDE 为三类任务 PDE 的算术均值。
- **人类基线协议**：参与者收到与模型完全相同的图像，单遍识别（无回看、无修改），禁止查阅任何辅助资源（MLLM 预判、作者转录、社区讨论、领域专家），使用相同目标格式与相同评测指标。

## 实验与结果
- **数据集**：WildHandBench，500 份手写文档图像（来源见上文），PNG 格式≤1MB，硬命名 handhand_{UUID}.png。
- **评测模型（18 个）**：专有 VLM（Claude Opus 4.8、Gemini 3.1 Pro、Gemini 3.5 Flash）；开源通用 VLM（InternVL3.5、Qwen3-VL、Qwen3.5-Plus、Kimi-K3）；开源 OCR 专用 VLM（DeepSeek-OCR-V2、MinerU2.5、MinerU2.5-Pro、Unlimited-OCR、Dots.ocr、Dots.mocr、HunyuanOCR、Qianfan-OCR、FireRed-OCR、GLM-OCR、PaddleOCR-VL-1.6）。所有模型使用统一后处理 pipeline 与 OmniDocBench prompt 模板（OCR 专用模型使用默认 API 参数）。
- **主要结果**：
  - 最佳模型 Gemini 3.1 Pro 综合 71.85%（Text Edit 24.32 / Table TEDS 60.44 / Formula CDM 79.42），较 OmniDocBench 印刷场景（>90%）大幅下降，确认"手写鸿沟"。
  - 人类基线综合 77.09%（Text Edit 30.08 / Table TEDS 74.78 / Formula CDM 86.56），以 5.24 绝对百分点领先最佳模型。
  - **表格是最大瓶颈**：最佳 TEDS 仅 60.44，函数模型间方差最小；人类在表格上领先模型超 14 绝对百分点。
  - **文本识别上模型反超人类**：Edit 24.32 vs 30.08，模型产出格式更合规的转录。
  - **PDE 分析**：功能性模型 PDE 率 63–79%（GLM-OCR 最低 63.28%、PaddleOCR-VL-1.6 为 64.48%；通用 VLM 较高如 Gemini 3.5 Flash 79.21%、Qwen3.5-Plus 77.82%）；人类 PDE 仅 49.27%。公式错误几乎全为前验驱动（87–98%），文本错误跨度最大（52–84%），表格居中（42–90%）。
  - **关键发现**：OCR 专用模型在手写场景整体落后于通用 VLM，前六名全为通用 VLM。

## 相关工作脉络
1. **手写识别经典基准**（IAM、RIMES、CASIA-HWDB、SCUT-EPT、SCUT-HCCDoc）仅覆盖行级自由文本，缺乏表格与公式统一评测——WildHandBench 首次在三类结构上联合评测手写内容。
2. **印刷文档基准**（OmniDocBench、Real5-OmniDocBench、OCRBench/OCRBench v2）已达高精度饱和（96.34%），但几乎不涉及手写退化场景——本文填补手写真实场景评测空白。
3. **手写数学表达识别基准**（CROHME、MathWriting）专攻公式，不涉及自由文本与表格——本文公式评测覆盖自然书写场景而非竞赛式标准写法。
4. **印刷表格基准**（PubTabNet、FinTabNet、ICDAR Table）完全基于印刷文档——本文首个覆盖手写表格理解的统一基准。
5. **先验驱动错误分析相关**（PINK 针对手写数学表达式过修正、CHAOS-Bench 针对印刷文档合成扰动）——本文首次在自然手写文档的多种结构上系统性度量语言先验驱动错误。
6. **现有幻觉诊断工具**（HallucinationBench）侧重生成式幻觉而非视觉文本识别中的"流畅但无视觉支撑"错误——本文 PDE 专为手写文档识别场景设计。

## 局限性与未来方向
- **基准规模有限**：500 样本不宜作为 population-level 估计；公式（52 图）和表格（81 图）子集较小，统计检验力有限。
- **语言覆盖偏窄**：主要聚焦中文与英文，繁体中文仅 13 份、中英混合 11 份，未来需扩展语种。
- **标注与人类评测的局限**：部分数据来自公开网络资源可能引入源偏差；主观性场景（如古典书法、严重退化手稿）难以定义绝对正确转录；所有标注员为中文母语者，可能低估高连笔/风格化英文手写的人类性能上限。
- **PDE 指标的局限**：依赖特定参考语言模型（Qwen3-8B-Base），不同参考模型可能改变边界案例分类；PDE 刻画的是错误类型而非错误数量，高 PDE 不意味着模型更不可靠，而仅表示错误更系统化。

## 研究启发与可借鉴点
1. **PDE 指标的设计思路可迁移**：用参考 LLM 的 ppl 对比来判断错误是否由语言先验驱动，这一思路可推广至其他视觉-语言错误分析场景（如图表理解、科学文献解析），超越单纯准确率诊断。
2. **校准人类基线的协议值得借鉴**：单遍识别、禁止辅助资源、与模型使用完全相同的格式和指标，确保人机比较的公平性，这一协议可复用于其他视觉理解基准。
3. **多阶段标注质量管控流程**：MLLM 辅助预标注→主标注→独立二审→共识裁决的流程，既提升效率又保障可靠性，可作为高质量手写文档基准构建的范式。
4. **发现"OCR 专用模型在手写场景弱于通用 VLM"的启示**：提示未来在开发手写识别模型时，需增强视觉表征的多样性与泛化能力，而非仅优化结构化印刷文档的解析精度。
5. **6 维难度标注体系**（视觉退化、连笔程度、语言模糊性、结构复杂度、领域知识、多语言混合）支持细粒度误差分析，可启发后续研究进行困难度自适应评估。

## 关键术语表
- **WildHandBench**：首个统一评估手写自由文本、表格、公式的多语言真实场景基准，包含 500 份手写文档与校准人类基线。
- **Prior-Driven Error (PDE)**：衡量模型识别错误中源于语言先验（而非视觉证据）的比例的指标，通过参考 LLM 的 ppl 差值判定。
- **OmniDocBench**：印刷文档理解的综合性基准，当前顶模达 96.34%，代表印刷场景已接近饱和。
- **CDM (Character Detection Metric)**：将预测与 Gt 渲染后匹配字符边界框，用于公式识别评测。
- **TEDS (Tree Edit Distance Similarity)**：基于 HTML 表示的树编辑距离相似度，联合衡量表格结构正确性与文本保真度。
- **手写鸿沟 (Handwritten Gap)**：印刷文档高精度模型到手写文档的大幅性能下降现象（OmniDocBench >90% → WildHandBench 71.85%）。
- **Language Prior**：模型内部的语言知识先验，在手写模糊时可能导致"流畅但无视觉支撑"的幻觉式输出。
