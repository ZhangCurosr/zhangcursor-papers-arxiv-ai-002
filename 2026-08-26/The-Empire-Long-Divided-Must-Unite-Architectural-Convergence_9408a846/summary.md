# 论文速读：The-Empire-Long-Divided-Must-Unite-Architectural-Convergence

## 一句话总结
本文通过对三个理念极端的开源LLM Agent Harness（deepagents、pi、dsh）进行源码级多案例纵向研究，揭示了它们在长周期自主运行压力下正收敛于一种包含五个核心要素的“中间架构形态”；同时首次将外部可验证性（external verifiability）确立为当前所有生产级Harness的共同盲区，预测其将成为下一代Harness的核心竞争维度。

## 研究问题与动机
1. **核心问题**：在同等前沿能力的模型中，环绕模型的Harness代码层（负责上下文构建、工具中介、循环运行与状态持久化）已成为长周期Agent行为的绑定约束（binding constraint），但其架构演化轨迹与目标形态缺乏系统性刻画。
2. **源码覆盖不足（G1）**：此前最近的源码分类研究明确排除了deepagents，且pi与dsh从未出现在任何架构研究中；既有工作多聚焦编码Agent应用而非通用Harness层。
3. **缺乏纵向轨迹刻画（G2）**：现有研究仅分析静态快照，或仅量化发布速度/代码质量，未追踪架构形态随commit历史的实际演化路径。
4. **收敛性未被验证（G3）**：虽有零星观察提及维度趋同，但未将其作为核心命题进行机制分解与跨案例验证。

## 核心贡献（创新点）
1. **首次源码级覆盖通用Harness层**：以固定commit版本逐行阅读deepagents、pi、dsh，填补了对象选择与覆盖率上的空白。*区别于仅做静态快照或限定特定应用的研究，本文首次将Harness本身作为独立研究对象进行纵向对比。*
2. **刻画演化轨迹并归纳收敛中间形态**：从commit考古中提炼出“减法（deepagents）”、“积累（pi）”与“复用（dsh）”三条路径，识别出收敛的五个重复要素。*区别于仅统计行数或质量的纵向研究，本文直接描绘架构形态的演进方向与交汇点。*
3. **分解收敛机制（并行发现、扩散、字面复用）**：论证趋同并非完全独立发明，而是共享压力驱动下的三种具体机制共同作用的结果。*将“收敛”从偶然观察提升为核心论断，并提供可验证的机制分类框架。*
4. **揭示“外部可验证性”为未收敛的边界维度**：证明所有三个Harness均未实现第三方无需信任运行时即可核查的防篡改记录，将其定性为预测性缺口而非疏忽。*在现有工作关注性能与稳定性的同时，首次将审计溯源维度置于架构比较的核心位置。*
5. **归纳跨哲学背景的收敛故障线**：通过复现缺陷提炼出四类高频架构接缝（同步/异步漂移、规范化信任缺口、字符串匹配语义、静默降级 vs 硬性失败）。*提供可操作的设计准则，证明缺陷分布同样受共同问题形状驱动而非单一设计流派。*

## 方法详解
1. **研究设计**：采用解释性、理论构建的多案例研究（multiple-case study），遵循最大差异选择逻辑。选取三个理念极端的开源编码Agent Harness：LangChain的deepagents（batteries-included）、Earendil的pi（radical minimalism）与DeepSeek的dsh（everything-is-a-plugin）。
2. **锚定版本与数据源**：所有源码引用均固定于特定commit/tag（deepagents `2c8015378`、pi `a470b121b`、dsh `b150a551b`）。数据包括：(i) 固定版本源码（附文件:行号证据）；(ii) commit/PR/issue考古追踪演化轨迹；(iii) 沙箱内人工复现两个缺陷及自行开发两个插件；(iv) 上游确认（已合并一个文档修复，提交缺陷报告#5640）。
3. **预定义分析维度**：在深度阅读前预先设定对比维度（共9项），涵盖循环设计、会话记录、崩溃恢复、模型quirks处理、上下文渐进披露、扩展接缝、沙箱及外部可验证性，避免事后拟合。
4. **AI辅助与人工核验**：使用并行AI代理进行源码扫描与摘录，但所有结论均经人工逐行核对。阅读深度不对称（deepagents/pi逐行精读，dsh一次 thorough pass + 插件实验）。
5. **收敛机制分解框架**：将观察到的架构趋同拆解为三种机制论证——并行发现（不同起点受相同压力到达同一形态）、扩散（公开项目间的惯例模仿，如AGENTS.md）、字面复用（dsh直接依赖pi的`@earendil-works/pi-ai`包）。

## 实验与结果
1. **研究性质与动机基准**：本文为源码级架构分析而非传统机器学习实验。动机引用[4]表明，固定模型下单次Harness变更可使Terminal-Bench 2 pass@1提升数分，SWE-bench Verified提升多达15分。
2. **五大收敛要素**：三个Harness均收敛于同一中间形态：(1) **商品化循环**（pi 796行无try/catch，dsh 515行，deepagents委托LangGraph）；(2) **追加式可重放会话记录**（强度：deepagents弱/视图 < pi中/追加条目 < dsh强/事件溯源+运行时不变量）；(3) **模型quirks数据化**（类层次/数据目录/运行时解析器三种序列化）；(4) **上下文渐进披露**（仅前置名/描述/路径，正文按需读取）；(5) **显式扩展接缝**（中间件/事件总线/服务定位器三元组）。
3. **收敛机制验证**：平行发现、扩散与字面复用共存。dsh的`llm-pi-ai`适配器直接复用pi的开源包，构成最直接的收敛证据。
4. **四大故障线（Fault Lines）**：复现/定位的缺陷均落在四类架构接缝上：S1同步/异步漂移、S2路径规范化信任缺口、S3基于正则的语义分类、S4静默降级 vs 硬性失败。其中3/4导致不可逆损失（如对话历史被破坏性压缩）。
5. **核心结论**：所有三个生产级Harness在外部
