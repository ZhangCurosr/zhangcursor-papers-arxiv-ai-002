# 论文速读：What Guides the Agent? Adjudicating Unauthorized Behavior via Localizing Behavior-Guiding Instructions

## 一句话总结
论文提出 **AttnLocate**，一个运行时监控框架，通过将行为引导指令的定位问题转化为注意力矩阵上的目标检测任务，实现 LLM Agent 上下文中真正影响工具调用决策的 token 级细粒度定位，并基于来源权威动态裁决越权行为，有效防御间接提示注入与工具投毒攻击。

## 研究问题与动机
1. **LLM Agent 易受注入攻击**：Agent 整合外部工具、数据库等不可信资源，统一自然语言上下文通道使不可信数据可能被模型动态解析为行为引导指令，颠覆预期决策。
2. **现有防御粒度粗糙**：静态扫描、架构隔离、行为审计等方法只能检测明显恶意内容或限制执行，无法识别看似无害但实际被模型解读为行为引导指令的上下文片段。
3. **归因方法边界模糊**：现有基于归因的工作（如 MindGuard、TracLLM）以段落、文档或元数据字段为粒度，将短暂恶意指令与无害载体纠缠，难以精确定位真正影响决策的上下文跨度。
4. **需要细粒度溯源与动态裁决**：防御系统需在运行时保留完整上下文信息，同时精确识别行为引导指令及其来源，实现基于权威的细粒度策略执行。

## 核心贡献（创新点）
1. **将行为引导指令定位形式化为注意力矩阵上的对象检测任务**，证明注意力激活模式可提供识别决策引导确切上下文跨度的证据；与现有归因方法依赖粗粒度单元（段落、元数据字段）的本质区别在于实现 token 级定位，避免边界碎片化与不稳定。
2. **提出 AttnLocate 框架**，结合多头多层注意力聚合、带感知 attention sink 正则化的 1‑D U‑Net 无锚检测头，以及基于权威的裁决器；与静态扫描或架构隔离方法的本质区别在于无需修改模型或隔离组件，仅通过白盒访问注意力矩阵实现运行时监控。
3. **系统性评估验证强定位与高裁决性能**，在十个 Agent 配置（六个模型家族）的两个攻击场景（工具投毒、间接提示注入）上取得平均 mIoU 0.743、平均 AUROC 0.956、FPR 0.067 时 TPR 0.934 的结果；与现有基线（如 TracLLM、MindGuard）相比，在 TPR/FPR 权衡上显著提升，且支持跨模型零样本迁移与策略自适应。

## 方法详解
AttnLocate 由三个核心模块构成：

1. **注意力聚合（Attention Aggregation）**
   - **头聚合**：对每层 $l$ 的注意力矩阵 $\mathbf{A}^{(l,h)}$ 按头平均，得 $\bar{A}^{(l)} = \frac{1}{H}\sum_h \mathbf{A}^{(l,h)}$。
   - **高斯层加权**：使用以中上层为中心的高斯权重 $w_l$ 聚合各层矩阵：$A = \sum_l w_l \bar{A}^{(l)}$，默认 $\mu \approx 2L/3$，$\sigma = 2$，突出任务相关信号。
   - **决策条件切片**：仅保留与最终决策 token $y$ 和外部上下文 $C_{\text{external}}$ 相关的子矩阵 $A_y = A[P(y), P(C_{\text{external}})]$。
   - **特征提取**：对每个上下文位置 $j$，计算 $A_y[:,j]$ 的均值、最大值、标准差及学习到的注意力池化操作，生成特征向量 $z_j$，形成序列 $Z$。

2. **指令定位（Instruction Localization）**
   - **1‑D U‑Net 骨干**：编码器逐步加倍通道数并降低时间分辨率，解码器通过跳跃连接恢复 token 级分辨率，捕获远距离上下文依赖。
   - **无锚检测头**：基于 FCOS，每个位置 $i$ 预测物体性 logit $o_i$、左右边界偏移 $(l_i, r_i)$、中心性分数 $c_i$，以及样本级 logit $s$ 判断是否存在行为引导跨度。
   - **感知 attention sink 正则化**：定义高注意力背景位置集合 $S_{\text{sink}} = \{i \mid b_i=0,\ \bar{a}_i > \beta/T_x\}$，赋予更高权重 $\alpha_{\text{sink}}>1$，改进目标 $\mathcal{I}_{\text{obj}}$ 并应用 focal 调制得到 $\mathcal{I}_{\text{focal}}$，使模型区分 attention sink 噪声与真正行为引导跨度。
   - **训练目标**：$\mathcal{I} = \mathcal{I}_{\text{focal}} + \lambda_{\text{giou}} \mathcal{I}_{\text{giou}} + \lambda_{\text{cls}} \mathcal{I}_{\text{bce}}$，其中 $\mathcal{I}_{\text{giou}}$ 为 1D 广义 IoU 损失，$\mathcal{I}_{\text{bce}}$ 为样本级存在监督。

3. **越权行为裁决（Unauthorized Behavior Adjudication）**
   - **溯源解析**：运行时维护上下文来源映射 $\Gamma_t$，将每个 token 位置映射到其提供者，通过 $\rho(\hat{\tau}_t)$ 返回定位跨度所属提供者。
   - **权威仲裁器**：根据可配置策略 $\Pi$ 为每个提供者分配权威级别，若 $\hat{\tau}_t \neq \emptyset$ 且 $\Pi(\rho(\hat{\tau}_t)) < R_y$（执行决策 $y$ 所需最小权威），则判定为恶意调用。

## 实验与结果
- **数据集**：MCPTox（工具投毒攻击）与 InjecAgent（间接提示注入攻击），均为公开基准。
- **模型配置**：十个 Agent 配置，涵盖 Qwen、DeepSeek、Phi、LLaMA、Mistral、Gemma 六个家族，包括标准模式与思维模式。
- **评估基线**：静态扫描（LLM‑Guard、LLM Detector）、行为审计（MCIP）、基于归因的监控（MindGuard、TracLLM）。
- **主要结果**：
  - **定位性能**：平均 mIoU 0.743，思维模式较标准模式提升约 5.4%；Phi‑4† 在 MCPTox 上 mIoU 达 0.858。
  - **裁决性能**：平均 AUROC 0.956，AP 0.934，FPR 0.067 时 TPR 0.934；Gemma2‑9B 在 InjecAgent 上 AUROC 0.989、TPR 0.984。
  - **跨模型迁移**：以 Qwen3‑8B† 训练，零样本迁移至其他模型，mIoU 保持 0.658–0.797，AUROC 平均 0.893–0.921。
  - **策略适应性**：不同权威策略（Principal‑only、Tool‑authorized、Result‑authorized）下 TPR > 0.909，FPR < 0.086。
  - **对比基线**：AttnLocate 在相同设置下 TPR > 0.910、FPR < 0.070，显著优于 MindGuard（TPR ≈ 0.8）和 TracLLM（TPR ≈ 0.9 但 FPR 更高）。
- **最强结果**：Gemma2‑9B 在 InjecAgent 上 AUROC 0.989；Phi‑4† 在 MCPTox 上 mIoU 0.858；整体平均 AUROC 0.956。

## 相关工作脉络
1. **静态扫描防御**（LLM‑Guard、LLM Detector）：输入前过滤可疑内容，无法检测看似无害实则被解析为行为引导指令的上下文；本文在运行时动态定位，不依赖预定义模式。
2. **架构隔离防御**（IsolateGPT、ACE）：系统层面分离不可信组件，限制 Agent 灵活性；本文无需修改架构，仅利用内部注意力信号。
3. **行为审计方法**（MCIP、Claw‑Guard）：运行时约束不安全动作，缺乏对行为引导指令的细粒度识别；本文提供可审计的定位跨度及其来源。
4. **基于归因的方法**（ContextCite、TracLLM、MindGuard）：通过扰动或注意力汇总追溯决策影响，但粒度较粗（段落、元数据字段）；本文实现 token 级定位，避免边界碎片化。
5. **Attention‑based 方法**（AttnTrace）：改进效率但未解决边界不确定性与 attention sink 噪声；本文引入无锚检测与 sink‑aware 正则化。

## 局限性与未来方向
- **局限性**：
  1. 需要白盒访问模型注意力矩阵，不适用于黑盒 API 场景。
  2. 长上下文（>2048 tokens）下定位精度下降，mIoU 与 TPR 单调降低。
  3. 依赖预定义的权威层级策略，可能需要更自动化的策略学习机制。
  4. 仅在两个攻击基准上评估，未覆盖所有注入变体（如供应链投毒、多轮对话攻击）。
- **未来方向**：
  1. 探索黑盒场景下的替代信号（如输出扰动分析、梯度近似）。
  2. 优化长上下文处理，如分层聚合、稀疏注意力或滑动窗口机制。
  3. 结合强化学习或在线策略调整，实现动态权威配置与自适应裁决。
  4. 扩展到其他攻击类型与更广泛的 Agent 框架（如 Multi‑Agent 系统）。

## 研究启发与可借鉴点
1. **问题建模创新**：将指令定位转化为目标检测任务，利用深度学习成熟工具解决自然语言处理中的边界不确定问题，可迁移至忠诚分析、多跳推理溯源等需要细粒度解释的场景。
2. **注意力特征工程模板**：多头多层聚合加高斯加权、决策条件切片及统计特征提取，为其他基于注意力的归因方法提供通用特征构造范式。
3. **噪声鲁棒性设计**：感知 attention sink 的正则化机制（动态权重分配）可有效抑制注意力矩阵中的噪声，适用于任何依赖注意力信号的模型解释或安全框架。
4. **解耦定位与裁决**：分离细粒度定位与基于权威的裁决，使系统可灵活适配不同安全策略，同时保持定位模块的通用性，便于模块化部署。
5. **跨模型泛化验证**：零样本迁移实验揭示了注意力模式在不同架构间的一致性，为后续研究提供验证跨模型可迁移性的标准协议。

## 关键术语表
- **行为引导指令**：外部上下文中被 LLM 动态解析为实际控制决策的文本片段，即使表面无害也能误导 Agent 执行非授权操作。
- **注意力矩阵**：Transformer 中记录查询 token 与键 token 之间注意力权重的多维张量，反映模型在生成时对输入上下文的关注分布。
- **无锚检测头**：基于 FCOS 的目标检测头，直接在每个位置预测物体存在概率和边界偏移，无需预定义锚框，适合变长跨度定位。
- **attention sink**：注意力矩阵中某些位置持续获得高注意力权重但实际与决策无关的现象，常导致噪声干扰。
- **权威仲裁器**：根据预定义策略评估上下文来源提供者的可信级别，并与决策所需最低权威比较，判断调用是否越权。
- **决策条件切片**：从聚合注意力中仅提取与最终决策 token 和外部上下文相关部分的子矩阵，聚焦行为引导信号。
- **高斯层加权**：以模型中层为中心的高斯分布权重，用于聚合不同深度的注意力层，平衡浅层局部依赖与深层语义信息。
