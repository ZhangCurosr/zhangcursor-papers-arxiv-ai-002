# 论文速读：SonarLLM-A-Native-Sonar-Optical-Multimodal-Large-Language-Mo

## 一句话总结
本文提出SonarLLM，将成像声纳作为原生感知模态而非辅助输入，结合声纳专用编码器、物理感知特征增强和可靠性感知分层融合，实现水下声纳-光学期多模态理解；同时引入SonarBench配对基准，在固定场景与声纳观测、仅变化光学质量的条件下量化跨模态互补性。

## 研究问题与动机
1. **光学传感退化严重**：水下浊度升高时，颜色、纹理、对比度和物体边界迅速消失，光学相机表现急剧恶化。
2. **现有MLLM不适配声纳**：自然图像编码器难以匹配声纳的距离-方位几何结构和散斑噪声、混响、声学阴影等声学伪影。
3. **模态可靠性具有观测依赖性**：光学在浊度增加时失效，声纳可能受声学噪声和伪影干扰，固定融合策略对不可靠传感器脆弱。
4. **已有工作缺乏开放式语言推理**：现有声纳-光学系统主要针对任务专用检测/跟踪，不支持开放-ended语言级跨模态交互。

## 核心贡献（创新点）
1. **提出SonarLLM统一框架**：将声纳作为原生感知模态，整合声纳专用表示、模态特定特征增强、可靠性感知门控与分层交互于共享语言模型中；区别于通用MLLM简单拼接声纳图的处理方式。
2. **引入SonarBench配对基准**：控制光学质量而保持场景和声纳观测固定，隔离单模态声纳能力与跨模态互补性增益；区别于NautData/UWBench等仅聚焦光学的基准。
3. **证明原生声纳建模不可替代**：27B–35B通用MLLM无法通过模型规模或指令微调弥合差距；相比海洋域模型OceanGPT/NAUTILUS有显著提升。
4. **揭示可靠性感知融合的动态价值**：融合相对光学的增益从清澈条件的6.0点增至重度浑浊的36.0点，验证了AGFM作为退化缓冲器的作用。

## 方法详解
### 整体架构
保留Qwen3-VL-8B预训练光编码器$\mathcal{E}_o$，引入独立声纳编码器$\mathcal{E}_s$（PSVT）。最终特征$F_m$经过模态特定VFE增强后由AGFM$_0$重加权；中间特征$\{F_m^{(k)}\}_{k=1}^3$（对应Transformer block 8/16/24输出）绕过VFE直接经AGFM$_k$重加权后通过双路DeepStack注入语言模型层8/16/24。

### 声纳原生视觉表示
- **多尺度声纳Stem**：通过不同感受野卷积$f_3/f_5/f_7$捕获回声、边界和声学阴影，零初始化系数$\gamma$逐步引入声纳特有结构。
- **距离-方位位置编码**：在预训练位置编码基础上叠加物理距离$r_i$和方位角$\theta_j$编码$z_{ij}^s = z_{ij}^{\mathrm{base}} + \lambda_p[\phi_r(r_i) + \phi_\theta(\theta_j)]$。

### 模态特定特征增强（VFE）
- **Optical-VFE**：可学习查询$e_b$估计散射相关特征噪声，冻结DINOv2-L提供结构参考$D_o$进行特征校正（非物理反演）。
- **Acoustic-VFE**：可学习声学查询$e_r$估计混响分量，token距离参数化补偿距离相关衰减，补偿系数$\alpha_c$为可学习量。

### 可靠性感知分层融合（AGFM）
- 通过token scorer $h_m^{(k)}$估计token质量，聚合为模态级可靠性$\overline{\mathbf{q}}^{(k)}$，softmex输出模态权重$\mathbf{g}^{(k)}$。
- 通过均数 preserving token modulation $\rho_{m,i}^{(k)}$捕获空间非均匀质量。
- AGFM重加权而非合并两模态序列，通过双路DeepStack注入语言模型多层。

### 渐进式四阶段训练
1. **Stage I**：无标签声纳MAE重建，适应PSVT（掩码率0.60，40K图像）。
2. **Stage II**：23类声纳标注数据CE分类，组织声学语义。
3. **Stage III**：配对声纳-光学数据（随机光学退化$\eta \sim \mathcal{U}(0.1,1.0)$，概率0.7），联合优化InfoNCE对齐、层次特征对齐、BCE门监督和熵正则。
4. **Stage IV**：LoRA（$r=128, \alpha=256$）指令微调（533K声纳+102K光期样本）。

## 实验与结果
**数据集**：训练使用RGBS50、UATD、SCTD、DeeperSense、FLC+FLS、OceanGym等数据源；SonarBench评估含25个子集（各150样本），覆盖识别、计数、VQA和描述生成。

**主要结果**：
- 声纳独用：SonarLLM宏观准确率**72.0%**，超越最强基线**34.4点**（Qwen3.6-35B-A3B仅28.9%，Qwen3.8-27B仅29.1%）。
- 融合输入：达到**68.7%**，超越最强基线**25.1点**。
- 融合相对光学增益：识别从清澈+6.0点增至重度浑浊+**36.0点**；VQA从+7.1增至+14.0点；融合性能自身在退化下保持稳定（-2.6至+0.6点）。
- Qwen3-VL-8B+LoRA控制实验显示，相同指令微调数据下，SonarLLM的声纳/光期/融合增益分别为34.4/14.0/36.5点，证明原生声纳表示不可替代。

**消融结论**：
- Polar PE移除导致融合/声纳宏准确率下降13.5/10.1点，Sonar Stem移除导致8.2/7.5点。
- Optical-VFE移除主要影响光期（-3.7点），Acoustic-VFE移除主要影响声纳（-3.8点）。
- DeepStack移除导致声纳宏下降6.2点。
- 均值融合替代AGFM使清澈→重度退化的下降从1.3点增至3.8点。

**效率**：参数量从8.77B增至10.3B（+17.4%），峰值显存21.6GB，prefill延迟+78.1%，解码吞吐-45.1%。

## 相关工作脉络
1. **MarineGPT/AquaticCLIP/NAUTILUS/OceanGPT**：扩展水下视觉语言理解，但仍主要依赖光学期图像，未解决声纳原生的开放推理。
2. **OceanPile/OceanGym**：提供海洋多模态数据和具身评估，但未考虑配对光学退化下的声纳-光学互补。
3. **LLaVA/BLIP-2/Flamingo/Qwen3-VL**：通用MLLM融合机制假设视觉输入同质，未显式处理不同成像几何和退化过程的异构传感器。
4. **RGBS50/UMOD/SOVIS**：配对声纳-光学数据集，但主要用于任务专用检测/跟踪，未连接声纳表示到开放语言推理。
5. **UATD/SCTD**：声纳感知数据集，支持目标检测和分类，但不涉及多模态语言理解。
6. **UWBench/NautData**：光学主导的水下视觉语言基准，无法隔离跨模态互补性。

## 局限性与未来方向
1. **受控退化协议的局限性**：测试基于合成光学退化，未覆盖自然不均匀散射、动态悬浮颗粒、声纳特有故障模式及时间不同步。
2. **评估范围受限**：仅在配对场景上验证，未探索非均匀退化或动态传感器失效场景。
3. **缺乏任务感知路由**：当前AGFM是全局可靠性感知，未针对具体任务类型动态调整融合策略。
4. **无时序建模**：未处理连续声纳-光学时序推理。
5. **推理效率损失**：参数增加17.4%，解码吞吐下降45.1%。

## 研究启发与可借鉴点
1. **异构传感器原生建模思路**：将声纳视为原生模态而非辅助输入，可将此范式迁移至热红外、激光雷达等其他异构传感场景。
2. **可控退化配对协议设计**：固定场景和非退化模态、仅变化退化模态质量的协议，可隔离单模态能力与跨模态互补性，适用于其他异构感知研究。
3. **物理启发特征增强**：基于成像物理方程（如光学衰减模型、声纳传播模型）设计VFE模块，可推广至其他具有已知物理退化过程的传感器。
4. **渐进式训练课程**：四阶段训练（域适配→语义学习→跨模态对齐→指令微调）可有效缓解多异构目标间的干扰，适用于复杂多模态训练。
5. **AGFM可靠性感知融合机制**：通过token质量估计实现全局+局部双层重加权，而非简单拼接，可迁移至医学影像、自动驾驶等异构多模态场景。

## 关键术语表
**SonarLLM**：将成像声纳作为原生感知模态的声纳-光学期多模态大语言模型。

**PSVT（Polar-aware Sonar Vision Transformer）**：基于Qwen3-VL视觉塔初始化的声纳专用编码器，引入多尺度Stem和距离-方位位置编码。

**AGFM（Adaptive Gated Fusion Module）**：可靠性感知自适应门控融合模块，通过token质量估计实现模态级和token级双重重加权。

**VFE（Visual Feature Enhancement）**：模态特定特征增强模块，包括Optical-VFE和Acoustic-VFE，分别校正散射和混响相关退化。

**SonarBench**：配对声纳-光学水下理解基准，控制光学质量变化以量化跨模态互补性。

**DeepStack**：从Qwen3-VL借鉴的分层视觉特征注入机制，将多层视觉特征分别注入语言模型的不同层。

**InfoNCE**：对比学习损失函数，用于声纳-光学期特征对齐。
