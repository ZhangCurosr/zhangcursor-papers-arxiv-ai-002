# 论文速读：Silent-Revision-Measuring-Undisclosed-Change-in-the-Safety-F

## 一句话总结
本文定义了"静默修订率"（Silent Revision Rate, SRR）这一测量构念，用于量化前沿AI开发者在修订安全框架时未向公众披露的实质性承诺变更比例；实证结果显示67%的重要修订在严格标准下属于"静默"，且承诺弱化往往比强化更易被隐藏。

## 研究问题与动机
1. **现有评估方法的静态局限**：已有研究（如Stelling et al., 2025的65项标准评估）仅对框架进行"快照式"评分，无法追踪框架随时间的演变过程，读者无法区分"适应性调整"与"承诺弱化"。
2. **监管要求与可审计性之间的缺口**：欧盟《通用人工智能法》代码规范和加州《透明前沿人工智能法案》（TFAIA）均要求修订安全框架，但两者均只要求提供"理由说明"（justification），未要求提供"枚举清单"（enumeration），导致修订的可见性不足。
3. **透明度理想与实践的脱节**：Ananny & Crawford（2018）指出"看见不等于知道"，安全框架的修订文档提供了文本可见性，但读者仍难以从开发者自述中获知哪些承诺发生了实质变化及变化方向。
4. **结构性沉默 vs. 策略性沉默的理论张力**：Vaughan的"结构性沉默"理论预测沉默是不均匀的，但不预测方向性；Meyer & Rowan的"脱耦"理论则预测组织会隐藏对其不利（即承诺弱化）的变更，本文通过数据检验这一区分。

## 核心贡献（创新点）
1. **构建了首个前沿AI安全框架版本化语料库**：收录12家开发者所有公开版本的19对连续版本，附哈希锁定文件、修订说明和元数据，支持纵向可复现分析——区别于现有横截面评估研究（如Stelling et al.）。
2. **提出了"静默修订率"（SRR）这一可测量构念**：将修订可审计性操作化为"读者仅凭开发者自述能否识别实质性承诺变更"的比例，并设计了严格/宽松两种阈值及颗粒度敏感性分析——区别于Midas Project的AI安全观察塔项目（后者记录现象但未定义测量或报告可靠性）。
3. **发现了承诺弱化的方向性沉默不对称**：77%的实质性变更属于弱化/移除承诺，且在8对中有7对的弱化比强化更易静默（OR=2.93, p=0.002）——首次为"组织伪善"（organized hypocrisy）理论提供实证支持，反驳单纯结构性沉默解释。
4. **揭示了修订说明形式与静默率的关联**：叙事型说明的SRR为74%，枚举型changelog为63%，而说明长度几乎无关——挑战了"写得越长越透明"的直觉假设。
5. **指出了监管合规缺口并提出政策建议**：TFAIA和EU Code均已施加修订义务但指定了"错误工具"（理由说明而非枚举清单），Anthropic的合规框架已自愿超出法定要求但仍不完整——为监管改革提供实证依据。

## 方法详解
**语料收集**：
- 来源：12家发布安全框架的前沿AI开发者（Anthropic、OpenAI、DeepMind、Meta、Microsoft、xAI、Naver、Cohere、Amazon、G42、Magic、NVIDIA）
- 版本：43个框架版本 + 9个辅助文档（companion documents），共52行清单
- 存储：每个文件以SHA-256哈希锁定，附纯文本提取和来源记录

**单位化（Unitising）**：
- 分析单位是"承诺"（commitment）：开发者以must/will/intend等情态动词或描述性现在时表达的实践陈述
- 排除：风险描述、术语定义、其他方义务、过往评估报告

**承诺分类体系**（9类，详见附录B）：
- 证据性类别（EC1-EC6）：评估范围（EC1）、触发/阈值（EC2）、方法（EC3）、第三方参与（EC4）、披露（EC5）、后果关联（EC6）
- 非证据性层：治理（G）、安全（S）、缓解措施（M）

**追踪与结果编码**：
- 对每对连续版本 $(v_i, v_{i+1})$ 追踪承诺，编码为六种结果：保留（R）、强化（S）、弱化（W）、移除（X）、迁移（L）、新增（A）
- 双方向变更标记为MIX并归为W
- "实质性变更"（material change）定义为改变以下六维之一：范围/阈值/触发器、行为者、义务强度（must→may阶梯）、披露范围、后果

**披露状态编码**（ANN/ANN-P/SIL/NCL）：
- ANN（已宣布）：读者仅凭修订说明可获知该承诺朝此方向变化（包括类级别提及）
- ANN-P（部分宣布）：说明提及该承诺或类别，但未指明方向或实质
- SIL（静默）：说明存在但未识别该变更
- NCL（无changelog）：开发者未发布任何说明

**静默修订率公式**：
$$\text{SRR}_p^{\text{strict}} = \frac{|S_p| + |P_p|}{|M_p|}, \quad \text{SRR}_p^{\text{lenient}} = \frac{|S_p|}{|M_p|}$$
- 差异项 $\frac{|P_p|}{|M_p|}$ 暴露了"部分宣布"所嵌入的判断
- 分母颗粒度敏感性：承诺级 vs. 章节级（section granularity）

**统计方法**：
- Wilson score置信区间（而非Wald区间，适用于小n）
- 精确置换检验（exact permutation test）：8对划分为3对叙事/5对枚举的56种分配，控制嵌套结构
- Fisher精确检验用于方向性比较
- leave-one-provider-out稳健性检验

**编码流程**：
- 第一阶段：Claude系列语言模型系统按冻结codebook编码，产生710行
- 验证：2,130次引文核对，第一作者单独裁决244行（涉及澄清、低置信度、50行样本）
- 裁决结果：4个结果码、54个宣布码被修改（46个SIL→ANN-P，8个ANN→ANN-P，无反向漂移）
- 可靠性：二阶段编码进行中，未报告Krippendorff's α

## 实验与结果
**数据集**：
- 12家开发者，19对连续版本对，其中8对有修订说明可追踪，4对来自xAI无说明（NCL）
- Anthropic最多（9版本），DeepMind 4版本，xAI 5版本，OpenAI/Meta/Microsoft/Naver各2版本
- 9次同标签重新上传（silent same-label re-uploads），2次含实质性变更

**主要结果**：

| 问题 | 发现 | 关键数值 |
|------|------|----------|
| RQ1（规模） | 严格标准下67%重要变更静默 | 257/383, SRR=0.67, 95% CI [0.62, 0.72] |
| | 宽松标准下53%静默 | 203/383, SRR=0.53, [0.48, 0.58] |
| | 章节级颗粒度降至49%严格/34%宽松 | 99个单位, [0.40, 0.59] / [0.26, 0.44] |
| RQ2（形式） | 叙事型说明SRR更高 | 叙事: 0.74 [0.66, 0.81] vs. 枚举: 0.63 [0.57, 0.69], p=0.071 |
| | 说明长度几乎无关 | 词数相关系数-0.17 |
| | 枚举项目数负相关更强 | 项目数相关系数-0.58 |
| RQ3（方向） | 77%变更为弱化/移除 | 229/299, [0.72, 0.81] |
| | 弱化更易静默 | 弱化SRR=0.75 (135/181) vs. 强化SRR=0.50 (25/50), OR=2.93, p=0.002 |
| | 8对中7对呈现方向性不对称 | 幅度0.03-0.67 |

**最强结果与提升**：
- Microsoft v1→2026 SRR最严格达0.81，但其仅6个枚举项目覆盖21项变更，提示枚举质量比数量更关键
- Anthropic 2.2→3.0（叙事型）SRR=0.73，51/86项重大变更静默，包括删除"删除模型权重"承诺和将"暂停训练"弱化为"迅速降低中期风险"
- xAI四对版本无说明（NCL），所有变更默认静默

**稳健性检验**：
- leave-one-provider-out：剔除任意一家，弱化比例仍在0.70-0.79区间
- 颗粒度检验：承诺级SRR 0.67 vs. 章节级0.49，支持承诺级为读者视角的真实度量
- TFAIA生效前后比较：生效后5对SRR=0.71 vs. 生效前3对SRR=0.61，但未发现沉默率下降

**类别分解**（附录H）：
- EC2（触发/阈值）：SRR=0.66 [0.53, 0.77]，68项变更中多次丢失定量锚点
- G（治理）：SRR=0.77 [0.65, 0.85]，最高静默率
- EC4（第三方参与）：最小类别21项，SRR=0.67

## 相关工作脉络
1. **Stelling et al. (2025) 的65项标准评估**：本文与之定位不同——Stelling是对单个时间点的横截面评分，本文聚焦纵向追踪和修订可审计性；Stelling仅在注释中提到"无changelog则无法区分适应与弱化"，本文将其操作化为测量构念。
2. **Midas Project AI Safety Watchtower（2024）**：追踪16家公司政策文件的未宣布编辑，记录现象但**未定义测量、未报告可靠性、未检验方向不对称**；本文是其首个系统测量。
3. **Foundation Model Transparency Index系列（Bommasani et al., 2023/2024/2025）**：测量开发者的信息披露类别覆盖率，但不测量"披露文档自身的后续修订是否被披露"这一二阶属性；本文填补这一gap。
4. **Algorithmic audit文献（Raji et al., 2020/2022; Costanza-Chock et al., 2022）**：本文方法论承袭其传统，但将审计对象从"审计结果"扩展到"被审计标准本身的修订"，延伸了强制公开披露的建议。
5. **隐私政策长期研究（Amos et al., 2021）**：对Internet Archive百万隐私政策的纵向分析，本文借鉴其方法但增加了"开发者自述"作为比较基准——这是测量可审计性的必要条件。
6. **法律文本分析方法（Hall & Wright, 2008; Krippendorff, 2019）**：本文将系统内容分析应用于法律 Operative 文件，采用Adcock & Collier（2001）的效度词汇，区别于以往AI治理研究中的启发式定性分析。

## 局限性与未来方向
1. **编码可靠性尚未完整报告**：Krippendorff's α未能在提交时完成，可靠性指标依赖裁决的微弱指标（0.6%结果码变更、7.6%宣布码变更），未来需独立编码验证。
2. **枚举类型的选择偏差**：Anthropic是唯一发布红线的提供者（5对），但其最大修订（2.2→3.0）反而是叙事型且SRR最高（0.73），可能存在自我选择效应——选择发布红线的是较透明的版本，8对数据无法分离此效应。
3. **统计推断受限**：变更在版本对内嵌套，依赖置换检验；无对照组（如无监管要求的其他标准领域），无法判断67%是否"高"；沉默仅反映外部可见性，不揭示动机。
4. **颗粒度敏感性**：承诺级SRR（0.67）vs. 章节级（0.49）差异显著，说明测量对单位化选择敏感，需在后续研究中测试更多颗粒度。
5. **xAI数据的特殊性**：4对无说明版本对整体沉默率有拉低效应，若仅看有说明的8对，平均SRR更高；未来需扩展更多开发者的样本量。
6. **未来方向**：(a) 完成独立编码报告α；(b) 扩展至更多开发者和时间段；(c) 探索枚举格式的最佳实践（如结构化JSON vs. 自然语言列表）；(d) 检验"枚举职责"立法的实际影响。

## 研究启发与可借鉴点
1. **可复用的测量构念设计**："静默修订率"将抽象的"透明度"操作化为"读者仅凭自述能否识别变更方向"，这一思路可迁移至任何需要评估文档修订可审计性的领域（如隐私政策、服务条款、开源许可证）。
2. **颗粒度敏感性检验作为标准实践**：本文同时报告承诺级和章节级SRR，暴露了测量对单位化的依赖；这一做法应成为内容分析的标配，而非可选补充。
3. **方向性不对称检验的方法**：使用Fisher精确检验比较弱化vs.强化的静默率，并提供odds ratio；这一设计可应用于其他领域检验"负面信息是否更易被隐藏"的假设。
4. **与监管框架的对接潜力**：本文发现TFAIA的"理由说明"义务未降低沉默率，为政策倡导提供了实证依据；团队可借鉴此方法评估中国AI治理框架的修订透明度。
5. **LLM辅助编码的验证框架**：本文使用Claude系统进行初编，再通过引文核对和人工裁决验证，这一混合流程可在保持大规模编码效率的同时控制误差——但需明确报告采样参数和种子重跑结果以提升可复现性。
6. **哈希锁定与可追溯性实践**：每个文件附SHA-256哈希和来源记录，任何读者可验证文本未被篡改；这一做法值得在政策分析项目中推广。

## 关键术语表
**Commitment（承诺）**：开发者作为语法主语并以情态动词或描述性现在时表达的实践声明，是本文的分析单位。
**Material Change（实质性变更）**：改变承诺的范围/阈值/触发器、行为者、义务强度、披露范围或后果六维之一的变更。
**Silent Revision Rate (SRR)**：修订说明未能识别的实质性变更比例，严格标准包含"部分宣布"，宽松标准不包含。
**Disclosure Regime（披露体制）**：修订说明的形式分类，按可读性排序为：红线（redline）> 枚举changelog > 叙事说明（announcement post）> 无说明。
**ANN / ANN-P / SIL / NCL**：宣布状态编码，分别为已宣布、部分宣布、静默、无changelog。
**Structural Secrecy（结构性沉默）**：Vaughan提出的组织理论，指专业化分工导致组织成员无法看到自身偏差的全貌，预测不均匀沉默但不预测方向性。
**Decoupling / Organized Hypocrisy（脱耦/组织伪善）**：Meyer & Rowan、Brunsson的理论，指组织将正式结构与实际行动分离，预测不利变更更可能被隐藏。
**Justification vs. Enumeration（理由说明vs.枚举）**：TFAIA要求的"理由说明"解释为何变更，本文主张应改为"枚举清单"逐条列出变更及其方向。
