# 论文速读：TELLME-Test-Enhanced-Learning-for-Language-Model-Enrichment

## 一句话总结
本文提出 TELLME，将教育心理学中的“测试增强学习”（Test-Enhanced Learning, TEL）原则迁移至大语言模型的持续预训练（CPT）流程，通过单样本拼接纯文本与开放式解释型 QA，并屏蔽问题 token 的梯度损失，显著提升了领域知识获取效率与跨域增量训练下的长期记忆保持能力，在金融与医疗基准上最高分别实现 23.6% 与 9.8% 的性能提升。

## 研究问题与动机
- **CPT 的数据与算力瓶颈**：将通用 LLM 适配到垂直领域通常依赖持续预训练，但面临两大现实障碍：高质量领域语料获取成本高、大规模连续训练的计算开销庞大。
- **现有混合训练方法偏离有效“测试”机制**：INSTPT 等近期工作虽将 QA 与纯文本混合训练，但其 QA 采用模板化抽取型阅读理解格式，答案可直接从给定上下文中定位，未能激发模型调用内部知识，与 TEL 强调的“开放性解释与概念映射”策略相悖。
- **跨域增量过程中的知识衰减（抗遗忘）**：在已有领域知识上叠加新域训练时，传统 CPT 容易稀释或覆盖旧表征，缺乏对长期记忆耐久性的显式保障。
- **核心动机**：若将 TEL 中“通过主动回忆与描述性输出巩固记忆”的认知规律引入 CPT，既可减少对外部语料的绝对依赖，又能强化领域知识在模型参数中的固化程度。

## 核心贡献（创新点）
- **提出 TELLME 持续预训练框架**：首次系统化地把 TEL 原则接入 LLM 领域适配，以“纯文本+需解释性推理的 QA”单样本混合训练替代传统纯文本 CPT 或两阶段 CPT+IT。
