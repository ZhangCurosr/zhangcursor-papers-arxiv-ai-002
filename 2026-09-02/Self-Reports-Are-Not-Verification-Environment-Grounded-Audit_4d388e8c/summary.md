# 论文速读：Self-Reports-Are-Not-Verification-Environment-Grounded-Audit

## 一句话总结
本文在基于词游戏 Contexto 的进化搜索环境中，对 LLM 代理生成的自我报告（置信度与理由）进行环境接地审计；发现三个关键假设均不成立：置信度系统性高估（4.8–9.3 倍）、继承理由对后代提议无显著因果影响、适应度选择并不改善报告质量。

## 研究问题与动机
- **核心问题**：当 LLM 在自动化搜索循环中生成自我报告（置信度预测与自由文本理由）时，这些报告是否可靠？
- **现有方法不足**：主流 Agent 基准侧重最终任务成功，进程监督通常需要人工标注中间步骤；失败提案往往被忽略，但它们是检验置信度与理由质量的关键证据。
- **验证缺口**：自我报告由同一模型生成，"便利性不等于验证"；缺乏对环境反馈的密集、逐条比对。
- **研究目标**：构建一个每个中间提议都能获得精确环境评分的设置，系统检验三项假设——置信度校准、继承理由的因果影响、选择机制对报告质量的优化效果。

## 核心贡献（创新点）
1. **环境接地审计框架**：引入外部环境的逐条精确评分机制，将自我报告转化为可被验证的声明而非默认可信的解释。
2. **三项关键假设的系统证伪**：发现置信度在全部模型族中系统性高估（4.8–9.3 倍）、继承理由无法显著改变后代提议或排名、适应度选择不产生报告准确性的选择差异或遗传传递。
3. **校准与区分能力的解耦揭示**：证明"更好识别有希望提议"并不等价于"更准确的概率估计"，EA-Gemma 区分最强但校准最差，EA-Qwen 校准最优但区分较弱。
4. **可迁移的审计模板**：为所有具备"密集反馈表面"的 Agent 循环提供评估模板，将自我报告视为需外部验证的低成本声明。
5. **控制性干预设计**：通过固定搜索状态并替换继承理由为无关/填充/空值，隔离理由的因果效应，量化其影响边界（至多约 250 个排名单位）。

## 方法详解
- **测试床设计**：使用 Contexto 词游戏——隐藏目标词，对每个有效猜测返回精确语义相似度排名（rank 1 为最优，最大观察排名 79,552）。环境无需人工标注即可对每条提案给出分级。
- **进化搜索框架**：LLM 充当变异算子，在每代生成新类别与 3 个候选词，附带结构化自我报告（top-100 概率、置信区间桶、基础词汇、理由）。适应度定义为后代新词中最优排名。
- **选择机制**：截断选择（truncation selection），从累计归档中保留排名最佳的 5 个个体作为下一代父代种群。
- **报告字段与评估**：
  - 概率误差 = 陈述的 top-100 概率与真实结果的差异
  - 桶精度 = 报告的桶（top-10 / top-100 / top-500 / beyond）与实际返回桶的一致性
  - 报告精度以第一条被评分词为基准；适应度使用后代的最佳排名
- **控制实验**：
  - **理由干预**：回放 754 次变异事件，固定父代、尝试词、变异算子与提示状态，替换为真实理由/无关理由/长度匹配填充/无理由，比较返回排名与提议身份
  - **选择对照**：将适应度选择替换为均匀随机采样，验证搜索行为差异是否伴随报告质量差异
- **统计方法**：
  - ECE（期望校准误差）：$ECE = \sum_{b=1}^{B} \frac{|I_b|}{n} |\bar{p}_b - \bar{y}_b|$，B=10 等宽分箱
  - 区分能力：Spearman ρ（负值更优）与 AUROC
  - 选择差异：置换检验（permutation test），1,000 次重采样
  - 因果效应：Hodges–Lehmann 估计，95% 置信区间通过 bootstrap 重采样整条运行获得

## 实验与结果
- **数据集**：Contexto 词游戏，10 个目标词（ID: 1303, 1307, 1319, 1327, 1335, 1352, 1364, 1365, 1372, 1384）
- **模型配置**：
  - EA-Qwen（Qwen-3 14B）、EA-Gemma（Gemma-4 12B）、EA-Ministral（Ministral-3 14B），各 50 运行×10 目标 = 150 运行
  - Direct-Qwen（同一 Qwen-3 14B，无进化循环，25 运行×5 目标）
  - EA-Qwen 无报告对照（25 运行）
- **总报告数**：12,249 条自我报告，11,976 条可评分
- **核心结果**：
  | 指标 | EA-Qwen | EA-Gemma | EA-Ministral |
  |------|---------|----------|--------------|
  | 平均陈述 top-100 概率 | 47.7% | 75.3% | 67.9% |
  | 实际 top-100 频率 | 10.0% | 12.3% | 7.3% |
  | 高估倍数 | 4.8× | 6.1× | 9.3× |
  | ECE（中位数） | 0.363（最优） | 0.652（最差） | 0.594 |
  | Spearman ρ（中位数） | -0.230 | -0.450（最强区分） | -0.211 |
  | AUROC（中位数） | 0.655 | 0.717 | 0.625 |
- **选择实验**：
  - 选择差异：概率误差 +0.039 (p=0.713)，桶距离 -0.146 (p=0.253) —— 无显著偏好
  - 遗传力：概率误差 ρ=+0.023 (p=0.524)，桶距离 ρ=+0.057 (p=0.911) —— 无显著传递
  - 随机选择同样无报告质量差异，但搜索行为显著不同（中位猜测数 446 vs 1,828）
- **理由干预**：
  - 真实理由 vs 无关理由：Hodges–Lehmann +73（区间 [-5, +477]）
  - 真实理由 vs 填充：0（区间 [-242, +138]）
  - 真实理由 vs 无理由：+50（区间 [0, +279]）
  - 首次词匹配率：15.5%（无关）/ 16.3%（填充）/ 15.1%（无）—— 无显著变化
- **最强结果**：EA-Gemma 在区分能力上最强（ρ=-0.450, AUROC=0.717），但校准最差（ECE=0.652）；EA-Qwen 校准最优但区分较弱。
- **提升幅度**：相比直接搜索，EA-Qwen ECE 从 0.421 降至 0.377（经难度重加权后解释 40.4%），但剩余 59.6% 差异无法由搜索状态解释。

## 相关工作脉络
1. **Agent 与外部验证**（ReAct、Toolformer、Reflexion、Self-Refine、CRITIC）：本文与之区别在于不仅评估轨迹成功，而是对每条中间提案（包括失败者）进行精确环境评分。
2. **LLM 引导的进化搜索**（Evolution through Large Models、Eureka、LLM as Optimizers）：prior 关注是否提升目标函数，本文进一步追问"幸存者选择是否偏好更准确的自我报告"。
3. **置信度校准**（Guo et al., Naeini et al.）：本文首次将校准与区分同时应用于中间搜索提案而非最终答案，并揭示两者的解耦现象。
4. **理由忠实度**（Jacovi & Goldberg, Lanham et al., Turpin et al.）：本文扩展 perturbation 方法，通过固定搜索状态替换继承理由，隔离理由对后代提议的因果效应。
5. **进程监督**（Let's Verify Step by Step）：本文对比点在于"人工标注的进程监督 vs 环境自动提供的密集反馈"，后者可对所有失败提案评分。
6. **Agent 基准评测**（AgentBench、LLM-as-judge）：本文批评仅关注最终成功的评测范式，主张建立可验证中间过程的审计基础设施。

## 局限性与未来方向
- **单一测试环境**：结果仅在 Contexto 语义搜索场景中验证，需在其他领域（程序合成、定理证明）重复。
- **模型规模受限**：仅测试三款相近规模的模型（3–14B），更大模型或不同架构的结论待验证。
- **反馈完整性假设**：依赖"每条提案都有精确评分"的环境，部分反馈或噪声场景下审计有效性未知。
- **理由干预范围有限**：仅测试继承理由对后代的因果影响，未检验"行动前生成的理由"是否能指导同一次行动。
- **目标函数分离**：报告精度评估基于第一条词，适应度基于后代最佳排名，两者未对齐；未来可探索共同优化。
- **选择与信号的张力**：若将报告质量纳入适应度，报告将不再是"关于系统的声明"而是"系统输出"，审计的无偏性将被破坏。

## 研究启发与可借鉴点
1. **环境接地审计模板可迁移**：对任何具备"密集评分函数"的系统（如带 partial-credit 的程序合成、交互式定理证明、约束满足搜索），可将自我报告转化为可验证声明而非默认接受。
2. **校准与区分的联合诊断**：建议后续研究同时报告 ECE 与 AUROC/Spearman ρ，避免单一指标的误导性结论。
3. **控制性干预设计的严谨性**：通过固定搜索状态仅替换单一变量（如理由内容），可精确量化因果效应边界，此设计可复用至其他 Agent 因果推断场景。
4. **无报告基线对照的必要性**：本文证明关闭报告功能不影响搜索行为（Wilcoxon p=0.82），为后续研究提供了"测量工具不干扰系统"的方法学范例。
5. **选择差异与遗传力的双重检验**：在进化 Agent 中，仅证明"选择优化了任务"不够，还需检验报告质量是否被选择和传递——双重条件缺一不可。

## 关键术语表
- **环境接地审计（Environment-Grounded Audit）**：用外部环境的精确评分对每条自我报告进行验证的方法，将报告视为需外部证据支撑的声明而非可信解释。
- **置信度校准（Confidence Calibration）**：陈述概率与观察频率的一致性；ECE 越低表示校准越好。
- **区分能力（Discrimination）**：模型将更高置信度分配给更优结果的能力；Spearman ρ 更负或 AUROC 更高表示区分更强。
- **选择差异（Selection Differential）**：被选中个体与未选中个体在报告准确性上的平均差异；显著正值表示选择偏好更准确的报告。
- **遗传力（Heritability）**：子代报告准确性与父代的关联程度；显著相关表示报告质量可通过选择积累。
- **截断选择（Truncation Selection）**：从累积归档中保留排名最佳的 μ 个个体作为下一代父代的机制。
- **Hodges–Lehmann 估计**：基于配对秩差的稳健效应量估计，用于理由干预实验的因果推断。
- **密集反馈表面（Dense Feedback Surface）**：能对每条中间提案提供精确评分的环境属性，是环境接地审计的前提条件。
