# 论文速读：TempCloze: Can Video-LLMs Identify the Missing Middle?

## 一句话总结
本文提出 **TempCloze**，一个面向视频大语言模型（Video-LLMs）的视觉时间推理完形填空基准测试，通过给定视频首尾片段、要求从四个同源候选片段中识别正确中间片段，**绕过语言中介带来的捷径**，系统评估模型在语义、时间对齐、进展三个维度上的真实视觉时间推理能力。

## 研究问题与动机
- 现有 Video-LLM 时间推理评测（如 TempCompass、TVBench）仍依赖**语言中介**（多选项文本或自由生成描述），模型可利用选项措辞、答案相关性、语言先验等捷径获得虚高分数，甚至预训练语言模型无需多模态上下文即可远超随机基线。
- 需要一种**更直接的视觉比较评估形式**，迫使模型基于视觉证据而非语言模式进行判断。
- 当前评测对"时间对齐（事件应在何时发生）"与"事件进展（事件应如何展开）"的区分不足，难以定位模型短板。
- 评测常忽视候选排列顺序、上下文方向、帧采样密度等工程因素对模型选择的扰动，导致性能估计不稳定。

## 核心贡献（创新点）
1. **提出首个以"视觉完形填空"为核心形式的 Video-LLM 时间推理基准**：与现有语言中介 benchmark 本质不同，TempCloze 要求模型在视觉片段间进行比较选择，削弱文本措辞/相关性带来的捷径。
2. **引入三维同源性干扰项设计（Semantic / Alignment / Progression）**：候选片段来自同一视频、共享场景与物体，分别考察"事件内容""时间边界""事件顺序"，与以往仅做事件排序或定位的 benchmark 形成互补。
3. **系统性暴露当前 Video-LLM 的时间推理瓶颈在对齐（Alignment）**：通过大规模评测 10 个商业与 21 个开源模型，发现多数模型能识别合理事件内容与局部进展，但在精确时间对齐上显著落后于人类。
4. **提供多维错误模式与行为敏感性分析**：揭示 Expanded 对齐错误、Reversed 进展错误为主要失败模式，并量化候选排序、上下文方向、可见跨度、采样密度、测试时扩展等因素的影响。

## 方法详解
- **任务定义**：对视频 $V = [C_{0,s} \mid C_{s,e} \mid C_{e,T}] = [B \mid M \mid E]$，给定首尾片段 $B$ 与 $E$，模型从候选集 $\mathcal{V}_d = \{M, D_d^1, D_d^2, D_d^3\}$ 中选择正确中间片段 $M$。
- **三维干扰项构造**（均来源于同一视频、保持外观线索一致）：
  - **Semantic (S)**：选取与目标等长但不重叠区间的片段，考察对"应发生何事件"的判断。
  - **Alignment (A)**：对目标区间做偏移/扩展，构造 Advanced、Deferred、Expanded 三类，考察对"应在何时发生"的边界敏感度。
  - **Progression (P)**：对目标区间内部顺序做扰动，构造 Reversed、Reordered、Repeated 三类，考察对"如何展开"的方向与连续性感知。
- **数据构建流程**：从 LVD-2M、EgoLife、MiraData、FAVOR、CaReBench、Video-TT、Daily-Omni 七个来源筛选；依次经时长（12–90s）、LLM 适宜性（GPT-o3 评估）、质量（码率/清晰度）、光流（Farnebäck）过滤，最终保留 **1,521** 个视频；每个视频按三维展开生成候选。
- **评估协议**：默认每片段均匀采样 **16 帧**，共 **96 帧/维度**；报告维度准确率（S/A/P）、累积准确率（≥1/≥2/3-全对）；另构建 TempCloze-Mixed（跨维混杂）与 TempCloze-Hard（多模型高错样本）两个子集用于深入分析。
- **关键消融/分析设置**：候选排列扰动（4 种顺序）、上下文方向（仅首/仅尾/两者）、可见跨度扩展、帧采样密度扩展（8–20 帧）、测试时 scaling（temperature=0.7, Pass@k）。

## 实验与结果
- **评测规模**：10 个商业模型（Seed1.8、Qwen3.5-Plus、Gemini2.5-Pro/Flash、GPT5.4、Claude4.6-Sonnet/Opus、Gemini3-Flash、Seed1.6、Grok4.1）与 21 个开源模型（Qwen3.5-397B/35B、KimiK2.5、Qwen3VL 系列、InternVL3.5/3 系列、KimiVL-A3B、LLaVA-CriticR1、Qwen2.5VL、GLM4.6V、ThinkLiteVL、MiMoVL、Molmo2 等）。
- **主要结果（商业模型均值 vs 开源均值）**：
  - Semantic：商业 70.73% / 开源 34.00%；最佳开源 Qwen3.5-397B 达 75.94%。
  - Progression：商业 67.72% / 开源 36.97%；Qwen3.5-397B 达 78.24%。
  - **Alignment（最大瓶颈）**：商业 48.13% / 开源 26.54%；最佳 Seed1.8 为 76.92%，仍远低于人类基线 98.00%。
- **累积理解**：商业模型 ≥2 维度正确均值为 65.12%，3/3 为 33.24%；开源 ≤35.77%（3/3）。
- **错误模式**：Alignment 错误以 **Expanded** 为主（如 Seed1.8 占 75%）；Progression 错误以 **Reversed** 为主（如 GPT5.4 占 67%）。
- **混合维度假设**：Alignment 是最具误导性的干扰维度；Semantic 有时比 Progression 更误导。
- **敏感性结论**：模型依赖**开头上下文**多于结尾；增加可见跨度/提高帧密度会稀释关键线索，Alignment 尤其下降；测试时扩展可提升绝对分数但不改变维度排序。

## 相关工作脉络
- **Temporal-Bench / TVBench / TempCompass**：直接测试事件排序与细粒度时间定位，但仍是语言中介形式；TempCloze 转向视觉片段比较。
- **LongVideoBench / MVBench / VideoMME**：面向长上下文与多任务综合评测；TempCloze 聚焦单一但严苛的视觉时序衔接任务。
- **NExT-QA / TGIF-QA / ActivityNet-QA**：传统 VideoQA 数据集，侧重显式动作与时空关系问答；未专门控制语言捷径。
- **MovieFIB / FIBER**：文本层面的完形填空视频理解；TempCloze 将其思想迁移至纯视觉时序补全。
- **VideoBERT / VCP / MaskFeat / VideoMAE**：将 cloze 作为预训练自监督目标；本文用于**评测阶段**而非训练目标。
- **Video QA 偏差分析工作（Yang et al., 2020; Xiao et al., 2024; Balepur et al., 2024）**：指出语言先验与选项相关性可导致虚假高分；TempCloze 是对该问题的直接评测回应。

## 局限性与未来方向
- TempCloze 为受控诊断基准，**不覆盖开放生成、对话叙事、音频 grounding、自由未来预测**等任务形态。
- 固定四选一候选形式限制了其对自由形式推理的泛化解释力。
- 数据源以长镜头、第一人称、细粒度动作为主，**尚未覆盖全部场景/相机风格**。
- 模型结果仅为当前 snapshot，API/解码与输入上限随时间变化可能影响排名。
- 未来可扩展到更长视频、更多模态（音频）、更多领域；并需发展能够显式整合双向时序、选择关键证据、表征时序结构的 video-native 机制。

## 研究启发与可借鉴点
- **"去语言中介"的评测范式**：用视觉片段比较替代文本选项，有效压制语言捷径，可作为后续时序/因果评测的参考设计。
- **三维同源性干扰项框架**（内容 / 边界 / 顺序）具有高度可迁移性，可复制到音频时序、动作生成评估中。
- **行为敏感性分析的标准化组合**：候选排序稳定性、上下文方向不对称、采样密度效应、测试时扩展四类消融，可作为 Video-LLM 评测的默认诊断项。
- **人类基线的严格双人一致协议**（两人均选对才算正确）有助于建立可比的人机差距度量。
- 本团队可在"**对齐敏感度训练**"与"**关键帧/跨度选择机制**"两个方向借鉴其发现：例如设计显式时序边界感知模块、双向上下文融合策略、可变密度采样器。

## 关键术语表
- **Temporal Cloze（时间完形填空）**：给定视频首尾片段，要求从候选中补全中间片段的评估形式，用于测量纯视觉时序推理。
- **Semantic distractor（语义干扰项）**：与目标同长但位于不同时段的候选片段，考察事件内容识别。
- **Alignment distractor（对齐干扰项）**：对目标时间区间做平移或扩展的候选，考察时间边界敏感度。
- **Progression distractor（进展干扰项）**：对目标片段做反转/重排/重复的候选，考察事件顺序与连续性感知。
- **Cumulative Accuracy（累积准确率）**：统计单视频至少正确 1/2/3 个维度的比例，反映整体视频级理解。
- **Behavioral Sensitivity（行为敏感性）**：评测模型输出对候选顺序、上下文方向、帧数等呈现方式的稳定程度。
- **Test-time Scaling（测试时扩展 / Pass@k）**：通过多次采样取最优来估计模型上限，但不改变相对维度排名。
- **Expanded error（扩展错误）**：模型选出的片段包含正确事件但超出目标区间边界，为 Alignment 主要失败模式。

## 可复现要素
- **数据集**：TempCloze（1,521 视频）来自七个公开来源（LVD-2M、EgoLife、MiraData、FAVOR、CaReBench、Video-TT、Daily-Omni）；论文未声明独立发布代码仓库，构建流程与 prompt 见附录 G。
- **代码/权重**：评测涉及的商业与开源模型各自按其原始发布渠道获取；论文本身未提供统一推理脚本（主要依赖 vLLM 部署开源模型）。
- **关键超参**：每片段采样 **16 帧**（每维度共 96 帧）；测试时扩展使用 **temperature=0.7**；Gap 长度取视频总长 **20%–40%**，位于中心 50% 区间。
- **人类基线**：100 随机视频，5 位标注者，每人 120 题，双评一致才算正确。
