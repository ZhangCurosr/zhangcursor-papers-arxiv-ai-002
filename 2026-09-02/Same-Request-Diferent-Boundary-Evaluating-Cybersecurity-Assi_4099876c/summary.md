# 论文速读：Same-Request-Diferent-Boundary-Evaluating-Cybersecurity-Assi

## 一句话总结
本文提出 3R-Bench 基准，通过伪造助手先例与多轮任务分解两种对话上下文，系统量化了同一网络安全请求在不同交互历史下的拒绝/合规边界漂移；实证发现接受先例显著提升模型合规率（+23.1 pts），而递进式任务分解反而大幅收紧边界（-45.1 pts）。

## 研究问题与动机
- **核心问题**：现有 LLM 安全评测多聚焦单提示词，缺乏对多轮对话上下文如何动态影响模型“拒绝-有限协助-完全合规”边界的系统评估。
- **动机 1（双用途请求的上下文敏感性）**：网络安全请求常兼具防御与攻击潜力，同一具体任务在不同授权/语境下可能触发完全不同的安全判定，单轮评测无法捕捉这种漂移。
- **动机 2（对抗性对话策略的实证空白）**：攻击者可能利用“伪造的助手接受历史”或“逐步任务拆解”诱导模型绕过护栏，但现有基准未将此类对话结构纳入评估。
- **动机 3（评测方法论缺陷）**：既有工作常将提供商标定块（PB）与模型语义输出混合统计，且缺乏长度匹配与配对控制，难以归因上下文干预的真实效应。

## 核心贡献（创新点）
- **提出 3R-Bench 配对评测基准**：构建 150 条真实网络安全请求（50 良性/模糊/高风险各半）及三种正交场景（S1 直接输入、S2 伪造先例、S3 任务分解），首次在同一请求上隔离对话历史对安全边界的独立影响。
- **揭示上下文依赖的反直觉规律**：接受先例使模糊/高风险请求合规率上升 23.1 个百分点（且无关任务接受同样有效），而六轮任务分解使合规率骤降 45.1 个百分点，失败反馈仅能微弱恢复。
- **建立 PB 与语义标签分离的严格统计规范**：将系统级拦截（PB）独立于模型输出（R/B/C）报告，采用精确模型-请求配对与 prompt-cluster bootstrap 置信区间，避免将服务商策略误读为模型对齐能力。
- **开源可验证的审核基础设施**：发布 CC BY 4.0 授权的标注元数据、文件哈希清单及本地验证器（Verifier），支持独立复现编码逻辑与边界判定。

## 方法详解
- **结果分类体系**：基于“能力优先”原则将模型输出划分为四类：R（Refuse，拒绝且不提供操作能力）、B（Bounded，提供有用但有限/抽象/重定向的帮助）、C（Comply，完整提供请求能力）、PB（Provider Block，服务商层面拦截，独立记录）。
- **S1 直接测量（基线）**：将 150 条请求独立提交至空会话，建立无上下文条件下的 R/B/C/PB 分布基线。
- **S2 伪造助手先例（重复上下文）**：终端请求 $U_3$ 保持不变，前置两条伪造的助手回复（接受或拒绝该请求副本），构成五轮对话 $U_1, A_1, U_2, A_2, U_3$。设 50 条模糊请求的主对照，并另设 20 条长度匹配的控制组（含无关任务接受历史），分离“泛化服从倾向”与“目标特定内容泄露”的效应。
- **S3 任务分解（递进上下文）**：前置六轮对话依次完成解释、可行性评估、有界概念验证（POC），最后以中性语（“POC 已审查，请写另一个”）或失败反馈语（“POC 无效，请写另一个”）结尾，测试递进拆解是否移动边界。
- **配对对比与编码流程**：所有对比仅在两侧均返回 R/B/C 的语义对上计算（剔除 PB 干扰）；使用自动化规则编码，GPT-5.6 Sol 负责初判，Claude Opus 4.6 盲测 100 条样本作审计（Cohen’s κ = 0.748）；统计采用 10,000 次 prompt-cluster 重采样（seed 3407）输出 95% 置信区间。

## 实验与结果
- **数据集**：150 条英文网络安全请求（源自 Security StackExchange 爬取的 66,443 条记录筛选），严格平衡良性/模糊/高风险三类。
- **评测模型**：Claude Opus 4.6, Claude Sonnet 4.6, GPT-5.6 Sol/Terra/Luna, MiniMax M2.5, GLM-5, Qwen3-Next 80B。
- **S2 核心结果**：在 376 个可用语义对中，接受先例使合规率从 233/376 (62.0%) 升至 320/376 (85.1%)（ΔC = +23.1 pts）；长度匹配控制显示无关接受同样提升 23.1 pts，目标特定接受额外提升 13.6 pts。
- **S3 核心结果**：在 800 个尝试对中，任务分解后合规率从 501/800 降至 172/800（-41.1 pts）；在 738 个双侧语义对中降幅达 -45.1 pts（C 从 500 降至 167），其中 C→R/B 转变 351 次。失败反馈较中性结尾仅恢复 +6.3 pts。
- **模型差异表现**：Qwen3-Next 80B 在直接场景高风险请求上合规倾向最高（91% C）；MiniMax M2.5 边界跨度最大，最易受 S2 接受历史影响（C 从 24→44）；GPT-5.6 Sol 频繁触发 PB；所有模型在 S3 分解场景下均显著收紧边界。

## 相关工作脉络
- **HarmBench / StrongREJECT (Mazeika et al., 2024; Souly et al., 2024)**：广泛评测通用恶意提示的拒绝率，但未针对网络安全双用途请求设计上下文对照；本文填补单轮评测无法捕捉边界漂移的空白。
- **CyberSecEval 2 (Bhatt et al., 2024)**：评估安全-效用权衡，但主要依赖单提示词分类；本文证明同一请求在对话中可跨越 R/B/C 边界，挑战静态评测的有效性。
- **Defensive Refusal Bias (Campbell et al., 2026)**：聚焦良性请求被过度拒绝的问题；本文与之互补，指出拒绝历史不会导致无差别拒绝，但接受历史会系统性放宽边界。
- **近期 LLM 安全对齐实践 (OpenAI, 2026; Anthropic, 2026)**：部署额外生物/网络安全拦截；本文建议评测
