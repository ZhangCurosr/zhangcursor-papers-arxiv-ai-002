# 论文速读：Residual-Sparsification-via-Output-Importance-for-Compressin

## 一句话总结
论文针对 MoE-LLM 的残差稀疏化压缩，指出现有方法最小化投影矩阵误差的目标与保持模型准确性不对齐；提出 PARSER 方法，通过引入输出重要性（output importance）直接优化专家输出误差，在相同内存压缩比下显著提升压缩后模型的准确性。

## 研究问题与动机
- MoE 架构推理时需将所有专家参数常驻 GPU 内存，导致严重的显存瓶颈（如 Mixtral-8x7B 需 97 GB 参数，峰值内存 113 GB）。
- 残差稀疏化是当前的 SOTA 压缩技术，其将每个投影矩阵分解为共享基矩阵与专家特有残差矩阵，仅压缩残差部分以降低内存。
- 现有残差稀疏化方法独立压缩每个残差矩阵，目标是最小化矩阵误差（Frobenius 范数），但 MoE 专家的输出由多个投影与隐藏表示耦合计算产生，矩阵误差最小化并不能保证专家输出误差最小化。
- 误差会通过隐藏表示传播并被非线性激活（如 SwiGLU）放大，导致压缩后专家输出失真，进而引起模型精度下降。

## 核心贡献（创新点）
- 理论分析证明：最小化单个投影矩阵误差不足以保持专家输出，因为专家输出误差还依赖于隐藏表示及其误差的耦合交互。
- 提出 PARSER 方法，首次将压缩目标从矩阵误差最小化转向专家输出误差最小化，通过输出重要性度量隐藏维度对输出误差的实际贡献。
- 实验验证 PARSER 在 Qwen 和 DeepSeek 上相比最优基线（D2MoE）将准确性差距分别缩小 1.41× 和 1.44×，同时实现相同的峰值内存压缩比，并在更多模型（OLMoE、Moonlight）与任务（生成质量、指令跟随）上保持领先。

## 方法详解
- **残差稀疏化框架**：对每个投影类型 p∈{u,g,d}，构造共享基矩阵 B_p（如 Wasserstein barycenter），得到残差 R_p^(i)=W_p^(i)-B_p，压缩后重建为 W̃_p^(i)=B_p+R̂_p^(i)。
- **输出重要性定义**：H(h_j)=E_x[||E(x)-Ê_{h_j}(x)||_2^2]，其中 Ê_{h_j}(x) 表示将第 j 个隐藏维度替换为仅由基矩阵贡献的值后的专家输出。该指标衡量压缩 h_j 对输出误差的影响。
- **经验近似计算**：利用校准数据集 D 估计期望，简化公式为 H(h_j)≈(1/|D|)∑_{x∈D}||W_{d,j}h_j(x)-B_{d,j}h_j^b(x)||_2^2，只需计算第 j 维参数，避免全路径前向传播。
- **压缩过程**：给定压缩率 ρ，需压缩维度数 K=ρ·N·H（N 专家数，H 隐藏维度数）。将各专家的 H(h_j) 在全局池化，选择 K 个最小分数对应的维度，移除 R_u、R_g 的对应行与 R_d 的对应列。
- **全局池化优势**：专家对 MoE 最终输出的贡献不均匀，全局池化可避免对高频路由专家过度压缩，让低重要性维度（无论属于哪一专家）优先被剔除。

## 实验与结果
- **模型与设置**：Qwen1.5-MoE-A2.7B、DeepSeek-V2-Lite，bfloat16 精度；压缩率 ρ=90%（主实验），扫描 10%–90%；仅在最后 2/3 层应用压缩；单卡 NVIDIA B200 GPU。
- **基线**：MoE-I²（专家剪枝）、HC-SMoE（专家合并）、D2MoE、ResMoE（残差稀疏化，使用 ResMoE-SVD 变体）。
- **校准数据集 D**：512 条序列随机采样自 Dolly-15K，拼接为约 1M token 的流，切分为 2048‑token 块。
- **评估基准**：lm‑eval‑harness，七项零样本任务（ARC‑Easy/Challenge、WinoGrande、HellaSwag、OpenBookQA、PIQA、MMLU）。
- **主要结果**：Qwen 平均准确率 49.24%（无压缩 59.12%），DeepSeek 47.16%（无压缩 59.64%）；相比最优基线 D2MoE，准确性差距缩小 1.41×（Qwen）与 1.44×（DeepSeek）。峰值内存减少 36%（Qwen）与 33.9%（DeepSeek），与基线相当（差异＜0.5%）。
- **扩展验证**：OLMoE 与 Moonlight 上同样取得最高准确率（分别提升 2.27、6.43 个百分点）；WikiText 困惑度与 IFEval 指令跟随准确率也全部最优。
- **敏感度分析**：D 的采样种子、数据集来源（Dolly‑15K/C4/WikiText）、大小（128/256/512）变化时，PARSER 均保持最优且波动极小（标准差≤2.03%）。
- **消融实验**：输出重要性准则优于矩阵误差最小化与 Wanda 准则；全局池化优于局部选择与路由感知全局池化。
- **开销分析**：压缩时间比 ResMoE 慢约 1.17×（Qwen）与 1.15×（DeepSeek），但推理吞吐量最高（优于 ResMoE 最多 1.05×，优于 D2MoE 最多 2.03×）。

## 相关工作脉络
- **专家剪枝（如 MoE-I²）**：基于路由统计或敏感度移除整个专家，压缩粒度粗，易丢失专家特有知识；本文聚焦更细粒度的残差压缩。
- **专家合并（如 HC-SMoE）**：聚合相似专家以削减数量，可能改变路由分布与模型容量；本文保持专家结构不变，仅压缩残差参数。
- **残差稀疏化（如 D2MoE、ResMoE）**：先分解基矩阵与残差，再独立压缩残差，目标是最小化矩阵误差；本文与之的本质区别是将目标改为最小化专家输出误差，并通过输出重要性指导维度选择。
- **模型压缩重要性评估**：传统方法如 SparseGPT、Wanda 依赖参数幅度与激活范数的乘积；本文输出重要性直接关联到最终预测误差，更贴合 MoE 的计算耦合特性。
- **校准数据集使用**：多数压缩方法使用校准集估计重要性；本文系统化分析了 D 的组成、规模对性能的影响，验证了方法的鲁棒性。
- **MoE 推理优化**：除压缩外，动态专家调度、低秩补偿等方向也被广泛研究；本文在残差稀疏化范式内推进了准确性上限，为下游部署提供轻量方案。

## 局限性与未来方向
- 依赖校准数据集 D，尽管实验显示对种子、来源、大小具有鲁棒性，但极端分布偏移时可能仍需领域自适应校准。
- 逐维度重要性估计忽略了被移除维度间的交互（交叉项），实际误差可能因维度间的协同或抵消而偏离对角近似。
- 目前仅面向推理阶段压缩，未扩展至训练或微调场景（训练涉及梯度动态与优化器状态，目标函数不同）。
- 评估集中于通用多任务基准，医疗、复杂代码生成等对逻辑一致性要求严格的领域尚未验证。
- 未来工作可探索协方差感知评分、贪婪联合维度选择，并将框架推广至训练压缩与领域专用模型。

## 研究启发与可借鉴点
- **输出重要性概念**：可将该思想迁移至其他压缩技术（如量化、结构化剪枝），以输出误差为导向重新设计重要性度量。
- **全局池化维度选择**：对于多专家或多模块模型，跨模块汇总重要性分数再全局选择可避免局部过压缩，该策略值得推广。
- **校准数据集敏感性分析**：系统考察校准数据的种子、来源、规模对最终性能的影响，应作为压缩方法的标准评估环节。
- **矩阵误差与输出误差的解耦**：本文的理论分解揭示了中间量误差如何传播放大，此类分析框架可用于理解其他压缩方法的失效原因。
- **与团队方向的结合**：若团队关注 MoE 路由优化或动态专家激活，可借鉴 PARSER 的输出重要性信号指导路由决策，或用于识别可冻结/剪枝的维度。

## 关键术语表
- **MoE (Mixture-of-Experts)**：混合专家模型，多个专家网络通过路由器动态选择激活，实现参数高效扩展。
- **残差稀疏化**：将投影矩阵分解为共享基矩阵与专家特有残差，仅压缩残差以降低内存与计算开销。
- **输出重要性**：衡量隐藏维度压缩对专家输出误差影响的期望指标，值越大表示该维度对输出越关键。
- **全局池化**：跨所有专家汇总输出重要性分数，再全局选择需压缩维度，避免因专家路由频率差异导致的不公平压缩。
- **校准数据集**：用于估计输出重要性的小规模代表性输入集合，不用于重训练或最终评估。
- **峰值 GPU 内存**：推理过程中 GPU 内存占用的最大值，是部署 MoE 模型的关键瓶颈。
- **压缩率**：需要压缩的残差部分比例，ρ 越大则压缩越激进，内存节省越多但精度下降风险越高。
- **路由**：根据输入 token 计算各专家的得分，选取 top-k 专家处理该 token 的机制。

## 可复现要素
- **数据集**：校准数据集 D 使用 Dolly-15K（随机采样 512 序列）；敏感性分析中使用了 C4 与 WikiText；评估基准（ARC、WinoGrande、HellaSwag、OpenBookQA、PIQA、MMLU、WikiText、IFEval）均为公开数据集。
- **代码/权重**：代码已开源在 https://github.com/OSSS-KU/PARSER；压缩后模型权重未提及开源。
- **关键超参**：压缩率 ρ（主实验 90%，扫描 10%–90%）；校准数据规模（默认 512 序列）；随机种子（默认 0）；压缩层范围（最后 2/3 层）；模型精度（bfloat16）。
