# 论文速读：Polished-but-Unresolved-Identifying-Late-Stage-Pressure-Stat

## 一句话总结
本文识别了长程工具使用智能体中的"晚期压力状态"（late-stage pressure）——模型在任务临近提交时偏向提前闭合而非继续验证的内部表征状态，并提出 PSPR（Probe-Sensed Pressure Relief）插件方法，通过在线探针感知压力并施加激活干预或显式状态重组来缓解该问题，在多个长程规划基准上稳定提升约束满足率与最终输出质量。

## 研究问题与动机
- **现象问题**：长程工具使用智能体常产生"看似完整但关键约束未解决"的精美提交，用户仅看到最终答案而非动作轨迹，此类失败比显式崩溃更难检测。
- **表征问题**：现有工作从行为层面分析约束未满足的原因（如幻觉完成、证据累积衰减），但未回答是否存在一个在隐藏空间中可识别、且能解释过早提交倾向的独立内部状态。
- **可控性问题**：若能识别该状态并施加干预，是否能系统改变智能体的晚期行为，使其倾向于继续验证而非仓促提交。
- **实用性问题**：该方法是否能在多基准、多模型架构上泛化，且不依赖每设定单独调参。

## 核心贡献（创新点）
- **识别晚期压力状态**：在 DeepPlanning-Travel 上用 Qwen3-14B 训练线性探针，证明压力驱动提交（PresC）与健康提交（HealC）/持续执行（ProdC）在隐藏空间中线性可分（AUROC=0.916）。**与已有工作的本质区别**在于：不仅描述失败行为，而是定位到具体可测量、可干预的内部表征维度。
- **揭示压力的行为因果性**：沿压力方向施加激活干预（CAA），反向操作系统提升 CS 分数（0.21→0.25），同时降低下一边界压力评分（0.67→0.53）并提升继续率；方向与压力相关效应独立于通用"提交 vs 继续"倾向。**与已有工作的本质区别**在于：证明了该状态不仅是事后标签，而是行为上可操控的因果因子。
- **发现两类缓解因素**：通过控制上下文操作发现，约束清晰度（constraint clarity）和动作映射（action mapping）是缓解晚期压力的两个关键因素，联合使用时将 PresC-risk 节点压力从 0.62 降至 0.13，Repair 率升至 0.85。**与已有工作的本质区别**在于：将抽象的"压力"概念操作化为可通过上下文结构化信息可调节的变量。
- **提出 PSPR 插件方法**：轻量级在线干预方法，探针连续监控动作边界处的压力分数，中压阶段施加缓解方向激活干预，高压阶段触发显式状态重组（模型自主总结约束状态并规划后续步骤），无需额外训练即可增强 CoT/ReAct/Reflexion₁。**与已有工作的本质区别**在于：将离线诊断探针转化为实时控制器，实现了多级强度的差异化干预策略。

## 方法详解
- **探针构建**：在每个动作边界（prefill 完成后、下一步生成前），取第一个 token 的隐藏状态 $h_T$，对比三类样本：压力驱动提交（PresC，$S_{sat} \leq 0.3$ 且 DPS≥4）、健康提交（HealC，$S_{sat} \geq 0.85$ 且 DPS≥4）、持续执行（ProdC，后续两步继续解决未满足约束）。训练二分类线性探针，负例由 HealC 和 ProdC 联合构成以排除形式捷径。
- **探针损失**：标准二分类交叉熵，在独立划分的 rollout 数据上训练和评估，使用 held-out 测试集保证无泄漏。
- **激活方向构造**：采用对比激活加法（CAA），取各边界后续前 K 个生成 token 的平均隐藏状态 $\bar{h}(x)$，定义类均值 $\mu(C)$，干预方向为 $v_{C^+ \cdot C^-} = \mu(C^+) - \mu(C^-)$。额外构建残差方向 $v_{PresC-ProdC}^{\perp commit}$ 以去除通用承诺分量。
- **PSPR 在线监测**：在每个动作边界 $A_t$，计算压力分数 $s_t = \text{Probe}(h_{t,1}^{(\ell)})$，其中 $\ell$ 为选定的探针/干预层（Qwen3-14B 使用第 26 层）。
- **三级干预策略**：设阈值 $a < b$（默认 $a=0.4$, $b=0.65$）：
  - 低压（$s_t < a$）：不干预
  - 中压（$a \leq s_t < b$）：施加缓解方向 $v_{relief} = \mu_{LP} - \mu_{HP}$ 对前 K=10 个 token 进行激活加法，$\alpha=1$
  - 高压（$s_t \geq b$）：执行显式状态组织——让模型自主识别已满足/未确定的约束并规划后续步骤，插入 prefill 后继续生成
- **缓解方向构造**：HP 集合为原始轨迹的 PresC 节点隐藏状态，LP 集合为附加了约束清晰化和动作映射上下文后到达下一个 productive 动作边界的隐藏状态（而非立即收集，以避免捕捉表面格式特征）。

## 实验与结果
- **数据集**：主实验使用 DeepPlanning-Travel（120 个长程旅行规划任务，含位置、预算、用户硬性约束）；泛化验证使用 DeepPlanning-Shop（购物列表生成）和 TravelPlanner（旅行规划）。
- **评估指标**：交付率（DR）、常识分（CS）、个性化分（PS）、综合分（CP）、案例准确率（Acc），均以 pass@3 报告（取 3 次运行最优）。
- **基线方法**：CoT、ReAct、Reflexion₁，分别在 Qwen3-14B、Qwen3-32B、OLMo-3.1-32B-Instruct 上测试。
- **主要结果（DeepPlanning-Travel，pass@3）**：
  - Qwen3-14B：ReAct+PSPR 的 CS=45.6（vs ReAct 41.5，+4.1）、CP=29.1（vs 26.1，+3.0）；CoT+PSPR 的 CS=36.0（vs 32.2，+3.8）、CP=22.6（vs 19.0，+3.6）
  - Qwen3-32B：ReAct+PSPR 的 CS=50.5（vs 45.3，+5.2）、CP=33.2（vs 29.3，+3.9）；CoT+PSPR 的 CP=28.1（vs 25.2，+2.9）
  - OLMo-3.1-32B：ReAct+PSPR 的 CS=46.0（vs 43.1，+2.9）、CP=28.9（vs 27.0，+1.9）
- **泛化结果**：DeepPlanning-Shop 上 Match 从 65.9 提升至 68.0，Acc 从 19.0 提升至 23.0；TravelPlanner 上所有 CS/HC 指标均提升。
- **不确定性估计**：Paired bootstrap 显示 CS 提升 95% CI 为 [0.4, 8.0]，不包含零。
- **最强结果**：Qwen3-32B + ReAct + PSPR 在 DeepPlanning-Travel 上达到 CS=50.5、CP=33.2，相较于基线 ReAct 的 CS 提升幅度最大（+5.2）。

## 相关工作脉络
- **长程工具使用失败诊断**（Garikaparthi et al., 2026; Wang et al., 2026a; He et al., 2026）：关注轨迹层面的进度控制、资源分配和工具使用组织失败；本文聚焦于"精美提交但约束未满足"这一特定失败模式的内部状态机制。
- **晚期约束失败研究**（Ko et al., 2026; Wang et al., 2026b; Yu et al., 2026; Fang et al., 2026）：从行为层面分析幻觉完成、早期错误放大、证据衰减和推理预算控制等问题；本文的定位差异在于从隐藏状态层面提供可测量、可干预的证据补充。
- **激活工程**（Rimsky et al., 2024; Højer et al., 2025; Stolfo et al., 2025）：CAAs 和 PCA-优化的方向构造被用于指令遵循、诚实性引导等任务；本文将其应用于长程工具使用场景中的特定行为偏差（晚期压力），强调在中间层的选择和残差化去噪。
- **概念擦除与线性解缠**（Belrose et al., 2023; Vu & Nguyen, 2025）：残差方向构造借鉴了 LEACE 等线性概念擦除思想，去除通用承诺分量后提取纯压力信号。
- **语义熵探针**（Kossen et al., 2024）：与本文探针设计思路相似但目标不同——前者检测幻觉不确定性，后者识别行为倾向的内部状态。

## 局限性与未来方向
- 研究主要限于文本型、结构化、可验证的长程工具使用场景，约束状态和下一步动作可被显式表达；扩展至开放式、动态变化或多模态 agent 环境是一个重要方向。
- 晚期压力并非对过早提交的完整因果解释——早期规划错误、证据缺失、上下文遗忘、工具错误或 benchmark 特有激励同样可能导致仓促提交。
- PSPR 需要访问隐藏状态进行探针监控和激活干预，限制了对封闭权重模型的应用；且构建探针和激活方向需要额外的离线标注，引入了一定的额外成本。

## 研究启发与可借鉴点
- **探针驱动的多级干预架构**：将诊断性探针直接嵌入推理循环作为控制器，按压力强度分级施加不同强度的干预（无干预→激活方向微调→显式上下文重组），这种"感知-分级响应"设计可迁移至其他 agent 失败模式（如过度探索、重复循环等）。
- **LLM 自生成的显式状态重组替代人工 oracle**：高压阶段使用模型自身而非人工标注来总结约束状态和规划后续步骤，降低了离线标注成本；这种"让模型反思自身不确定性"的思路可借鉴于其他需要 self-correction 的场景。
- **注意力集中度验证上下文干预有效性**：通过计算附加上下文的注意力集中比（$\rho \approx 1.6\times$），定量验证了模型确实在使用补充信息；这一验证范式可用于评估其他 prompt engineering 或 context augmentation 策略的实际利用程度。
- **跨语言泛化实验设计**：在中国版 DeepPlanning-Travel 上验证 PSPR 效果，表明方法对非英语语境同样有效，为中文 agent 研究提供了即插即用的质量提升方案。

## 关键术语表
- **Late-stage pressure（晚期压力）**：智能体在长程任务临近提交时产生的内部状态，使模型倾向于生成看似完整的最终答案而忽略尚未解决的硬性约束。
- **PresC（Pressure-driven Commit，压力驱动提交）**：标签定义，指约束满足度低（$S_{sat} \leq 0.3$）但交付精致度高（DPS≥4）的动作边界，代表晚期压力状态。
- **Probe（探针）**：在选定隐藏层上训练的线性分类器，用于从单步隐藏状态中预测当前是否为压力驱动提交状态。
- **Activation steering / CAA（激活导向/对比激活加法）**：在推理时向选定层的前 K 个 token 隐藏状态加减干预方向向量，以改变模型行为倾向的方法。
- **Constraint clarity（约束清晰度）**：在上下文中显式列出当前已验证和未解决的硬性约束，帮助模型区分"继续验证"与"仓促提交"之间的界限。
- **Action mapping（动作映射）**：将未满足约束转化为具体下一步工具调用或行动的有序计划，使工作更有条理而非漂向完成式提交。
- **PSPR（Probe-Sensed Pressure Relief）**：本文提出的轻量级插件方法，在线监测压力分数并按阈值分级施加激活缓解或显式状态重组。
- **DeepPlanning-Travel**：120 个长程旅行规划任务的 benchmark，要求 agent 在满足位置、预算、用户硬性约束的前提下生成结构化计划。
