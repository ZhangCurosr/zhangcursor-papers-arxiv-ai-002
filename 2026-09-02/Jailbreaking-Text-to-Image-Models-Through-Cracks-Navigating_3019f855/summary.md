# 论文速读：Jailbreaking Text-to-Image Models Through Cracks: Navigating Heterogeneous Safety Filters via Multi-Agent Debate

## 一句话总结
本文提出 CRACK，一种基于多智能体辩论的黑盒越狱框架，通过引入"检测曲面（Detection Surface）"的几何抽象来刻画异构安全过滤器的联合决策边界，并协调攻击智能体、防御智能体和裁判智能体进行分层诊断、自适应探索与跨层仲裁，从而在多个 T2I 模型上实现了高达 99.63% 的 ASR，同时显著减少查询次数并保持语义保真度。

## 研究问题与动机
1. **现有方法无法应对异构多层安全栈**：当前 T2I 越狱研究要么针对单一过滤器优化，要么将完整流水线视为黑盒只观察整体成功/失败信号，无法识别哪一层安全约束活跃，也无法适应跨层冲突。
2. **跨层冲突未被建模**：绕过某一过滤器的突变可能同时增加暴露于另一过滤器的风险（例如弱化关键词规避文本过滤的同时增强了不安全视觉语义），现有方法缺乏分层感知信号来指导有效的搜索方向。
3. **稀疏性与非凸性导致搜索困难**：多层过滤器的安全区域交集构成稀疏、非凸的逃逸区域，单点贪心搜索容易陷入局部死胡同。
4. **黑盒场景下缺乏细粒度诊断反馈**：商用平台（如 DALL·E 3）的安全机制不可见，攻击者仅有二元安全/不安全信号，难以据此进行针对性突变。

## 核心贡献（创新点）
1. **提出"检测曲面"统一几何框架**：首次将多层 T2I 安全栈的决策边界形式化为连续的 Detection Surface，识别出跨层冲突、稀疏性和非凸性三个结构性性质，为越狱搜索提供统一理论分析基础。
2. **设计 CRACK 多智能体辩论框架**：首创将多智能体辩论应用于 T2I 越狱，通过三个专业化智能体（攻击、防御、裁判）分别实现探索、诊断和跨层仲裁，将堆栈级试探转化为分层感知的自适应搜索。
3. **构建代理分层诊断管线**：在攻击者无目标系统内部状态访问的黑盒约束下，设计三层代理检测机制（关键词/模式匹配、LLM 语义风险评估、CLIPScore 跨模态验证）以逼近真实异构过滤器的检测标准。
4. **引入 RL 引导的策略优化**：将辩论过程中的分层诊断反馈和裁判评分结合为复合奖励信号（绕过奖励 + 裁判奖励），利用 Actor-Critic 方法优化攻击智能体的突变策略选择策略，实现跨层自适应。
5. **全面的实验验证**：在 SD 1.4、SDXL、DALL·E 3 和 Midjourney 四个模型、三种数据集（NSFW-200、I2P、UnsafeDiff）及多种异构安全配置下进行评估，CRACK 在 ASR 和查询效率上均优于现有基线。

## 方法详解
**检测曲面形式化**：
- 将离散提示空间 $\mathcal{P}$ 映射到连续表示空间 $\mathcal{X} \subseteq \mathbb{R}^d$，每个过滤器 $S_k$ 诱导二元决策函数 $h_k(x) = \mathbf{1}[f_k(x) \geq 0]$ 和连续代理评分函数 $f_k$。
- 第 $k$ 个过滤器的安全区域为 $\mathcal{B}_k = \{x \in \mathcal{X} \mid f_k(x) < 0\}$，检测曲面定义为所有过滤器边界的并集：$\mathcal{D} = \bigcup_{k=1}^{K} \partial \mathcal{B}_k$。
- 联合逃逸区域为 $\mathcal{E}^* = \left(\bigcap_{k=1}^{K} \mathcal{B}_k\right) \cap \mathcal{F}(x_h, \delta)$，需同时满足所有过滤器安全且保持语义保真度。

**三个智能体的协作机制**：
1. **攻击智能体（Attack Agent）**：从策略库 $\mathcal{M}$ 中选取突变策略 $a_t \sim \pi_\phi(\cdot | p_t, R_t)$，其中 $R_t$ 为防御智能体提供的分层风险报告，策略选择依赖 RL 优化。
2. **防御智能体（Defense Agent）**：运行三层检测管线：
   - Tier 1（文本边界 $\partial\mathcal{B}_{text}$）：关键词/正则匹配，检测显式违规
   - Tier 2（语义边界 $\partial\mathcal{B}_{sem}$）：微调 LLM 进行语义风险评估
   - Tier 3（跨模态边界 $\partial\mathcal{B}_{cross}$）：计算 CLIPScore 评估图文一致性
   输出结构化风险报告 $R_t = (r_t^{(1)}, r_t^{(2)}, r_t^{(3)})$。
3. **裁判智能体（Judge Agent）**：融合双信号生成奖励分数 $s = \alpha \cdot S_{risk} + \beta \cdot \sigma(\Delta_{CLIP})$，其中 $S_{risk}$ 为 LLM 语义风险评估得分，$\Delta_{CLIP}$ 为跨模态对齐变化量，$\alpha + \beta = 1$。

**RL 策略优化**：
- 状态 $s_t$ = 当前提示 + 分层检测状态；动作 $a_t$ = 所选突变策略；奖励 $r_t$ = 绕过奖励（二元 $\pm b$）+ 裁判奖励（连续 $s$）。
- 使用 Actor-Critic 损失优化策略网络 $\pi_\phi$：$\mathcal{L}(\phi) = -\mathbb{E}\left[\sum_{t=0}^{T} \log \pi_\phi(a_t|s_t) \cdot \hat{A}_t\right] + \mathbb{E}[\hat{A}_t^2]$，其中 $\hat{A}_t$ 为优势估计。
- 关键超参：$\alpha=0.3, \beta=0.7$，绕过奖励 $b=10$，学习率 $3 \times 10^{-4}$，Adam 优化器。

**辩论协议**：每轮迭代执行三步——攻击智能体生成候选突变 → 防御智能体分层诊断 → 裁判智能体仲裁评分；终止条件为进入逃逸区域 $\mathcal{E}^*$ 或达到最大辩论轮数。

## 实验与结果
**数据集与模型**：
- 数据集：NSFW-200（成人内容）、I2P（真实用户不适当提示）、UnsafeDiff（暴力/血腥/歧视）
- 目标模型：Stable Diffusion 1.4、SDXL、DALL·E 3、Midjourney

**主要结果（一次提示攻击设置）**：
- **SD 1.4 + text-c 过滤器**：CRACK 在 I2P 上 ASR-Q16 达 **99.63%**（最强基线仅 90.31%），在 NSFW-200 上 ASR-NudeNet 达 **93.61%**
- **SD 1.4 + text-image-c 过滤器**：ASR-Q16 在 I2P 上达 **83.01%**，超越最强基线 36.37 个百分点
- **SD 1.4 + image-c 过滤器**：ASR-Q16 在 UnsafeDiff 上达 **96.23%**
- **DALL·E 3（未知多层黑盒）**：ASR-Q16 在 I2P 上达 **43.57%**，在 NSFW-200 上 ASR-NudeNet 达 **39.01%**，约为最强基线的两倍
- **查询效率**：CRACK 平均每实例仅需 **6 次查询**，远低于 SneakyPrompt（39.96 次）和 JailFuzzer（29.55 次）
- **语义保真度**：在 image-c 设置下最低 PPL 为 **29.78**，CLIPScore 在 NSFW-200 上达 **0.36**，显著优于基线

**消融验证**：
- 三层检测随机命中率随层数增加呈指数衰减：单文本层 12.3% → 文本+图像 2.7% → 文本+图像+跨模态 0.4%
- 中段插值存活率仅 23.5%，验证了非凸性
- 移除任一智能体或 RL 组件均导致 ASR 和 CLIPScore 显著下降

## 相关工作脉络
1. **SneakyPrompt [8]**：基于 RL 的 token 级替换攻击，仅针对单一 CLIP 安全过滤器优化；CRACK 扩展到多层异构过滤器，通过分层诊断和策略级选择替代粗粒度 token 替换。
2. **JailFuzzer [17]**：模糊测试结合 LLM 智能体的 T2I 越狱框架，仅提供二元成功/失败反馈；CRACK 补充了分层诊断信号以定位具体拦截层。
3. **DACA [20]**：使用 LLM 分解不安全请求的攻击方法，但未显式建模跨层交互；CRACK 通过 Detection Surface 理论和多智能体仲裁解决跨层冲突。
4. **PGJ [16]**：基于感知信号引导的越狱方法，优化目标是单一过滤器；CRACK 支持跨异构层的联合优化。
5. **MMA-Diffusion [19]**：多模态对抗攻击，需要梯度信息（白盒/灰盒）；CRACK 完全黑盒，无需内部参数访问。
6. **Ring-A-Bell [9]**：概念擦除扩散模型的白盒攻击；CRACK 面向黑盒场景，不涉及模型内部结构。

## 局限性与未来方向
1. **代理诊断器的泛化能力受限**：三层代理管线仅覆盖关键词、语义和跨模态三类检测维度，未穷尽所有可能的安全机制（如概念擦除、Safe Latent Diffusion 等），面对未知或自适应的商业防御系统时诊断准确性可能下降。
2. **DALL·E 3 等商业平台 ASR 仍有较大提升空间**：在 DALL·E 3 上的 ASR 仅 43.57%（I2P），表明高度封闭、多层叠加的商用防护仍有较强鲁棒性。
3. **策略库规模有限**：当前仅包含 5 种互补突变策略，可能不足以覆盖更复杂的检测层组合。
4. **论文未讨论防御视角**：虽然结论部分提出联合安全设计的方向，但未提供针对 CRACK 的具体防御方案。

## 研究启发与可借鉴点
1. **Detection Surface 几何框架可迁移到其他多层安全系统**：该形式化方法可将 T2I 越狱中的跨层冲突分析范式推广至其他多阶段安全审核场景（如 LLM 安全防护、多模态内容审核）。
2. **多智能体辩论架构值得复用于红队测试**：CRACK 将探索、诊断、仲裁分离为不同智能体的设计思路，可复用于其他需要多层次反馈协调的对抗性搜索任务。
3. **分层诊断信号替代二元反馈的实验设计**：用代理分层评估管线提供细粒度诊断信号，而非仅依赖目标系统输出，这一设计可显著减少无效查询次数，值得在资源受限的越狱攻击中借鉴。
4. **复合奖励函数结合二值绕过信号与连续质量信号**：绕过奖励（二值）+ 裁判奖励（连续）的组合为稀疏非凸搜索空间中的 RL 策略优化提供了更密集的反馈，可用于其他安全评估场景。
5. **与团队方向的结合机会**：可将 CRACK 的检测曲面分析与团队在 LLM 安全对齐、多模态内容审核方面的研究结合，探索跨层冲突检测的防御方法（如联合优化异构过滤器）。

## 关键术语表
**Detection Surface（检测曲面）**：异构安全过滤器决策边界的并集形成的几何抽象，刻画了提示空间中所有可能被拦截的区域。

**Cross-layer Conflict（跨层冲突）**：不同过滤器的安全约束方向相反，使绕过某一层的突变可能增加暴露于另一层的风险。

**Evasion Region（逃逸区域）** $\mathcal{E}^*$：同时满足所有过滤器安全且保持语义保真度的提示表示集合。

**CRACK**：本文提出的多智能体越狱框架名称，寓意在异构安全过滤器的"裂缝"中导航。

**ASR-Q16 / ASR-NudeNet**：分别使用 Q16 多标签安全分类器和 NudeNet 裸露检测器评估的攻击成功率。

**Surrogate Realizability（代理可实现性）**：假设每个二元决策函数可用连续代理评分函数近似，支持几何分析。

**Mutation Strategy（突变策略）**：攻击智能体从策略库中选择的提示修改方法（如隐喻替换、思维链扩展、场景抽象等）。

**Actor-Critic RL**：用于优化攻击智能体突变策略选择的强化学习算法，通过优势估计最小化策略损失。
