# 论文速读：The Civilization Framework: Sovereign-Anchored Communication Between Personal Multi-Agent Systems

## 一句话总结
本文提出"文明框架"（Civilization Framework），将"一个自然人主权者 + 其持久账本 + 可互换的代理"作为跨方 AI 通信的基本单位，并设计了 Embassy Protocol 实现异步、账本锚定的双方通信；同时在 claude-opus-5 上通过 1,908 次预注册实验验证了时序权重效应（未经验证时错误前提采纳率达 54.2%，全验证下仅 4.2%）。

## 研究问题与动机
- **搬运工问题（Porter Problem）**：AI 辅助的专业协作中，人类已成为 AI 系统之间的传输层——助手产出产物后由人通过聊天/邮件中转，环境指纹、版本约束等关键信息在每次转手时丢失。
- **现有协议层级错位**：MCP 标准化"代理如何访问自身工具"，A2A 标准化"代理如何委派任务给另一代理"，二者均以**代理实例**为端点；但代理是瞬时进程，真正持久的是人及其积累偏好和持久记录。
- **无契约层面的处理方案**：行业调查指出员工每周损失近一整天用于在断开连接的 AI 系统间传递上下文，但学术界尚无同行评审的受控测量来量化此中继成本。
- **A2A 通信中的隐性偏见**：AI 对 AI 传输中存在时序权重效应（先到的信息获得不应有的权威性），现有多代理辩论框架虽有位置敏感性研究，但未在承诺形成型通信场景中进行隔离和协议级缓解测试。

## 核心贡献（创新点）
1. **文明抽象（Civilization Abstraction）**：从四条公理（责任终点的持久性、代理实例的短暂性、异构传输层、对抗性对等方）推导出跨方通信的自然单位是"文明"而非"代理"，本质区别在于将身份锚定在自然人而非瞬态进程上。
2. **Embassy Protocol**：提出三个统一工件（入站通道 ≡ 任务板 ≡ 承诺账本合一）和三级签名纪律（微同步单方签名 / 判断双签 / 仲裁交给人），本质区别在于将消息、任务和承诺转换统一为同一对象的不同读取视角，并以双方账本的承诺状态而非消息投递为事实依据。
3. **基于记忆的授权模型（Memory-Derived Authority）**：代理代表文明的权力由其可访问的文明记忆范围决定（表达力域），外化为有符号凭证，与跨交换积累的文明级声誉分离，本质区别在于以"能力安全"（capability）理念替代角色型访问控制，且授权可事后审计。
4. **时序权重效应（Temporal-Weight Effect）**：在承诺形成型 A2A 通信中隔离并验证了"先到信息获得不应有权威"的现象，并提出密封答案等协议级缓解机制；本质区别在于将排序效应与单纯曝光分离，以密封-比较流程实现顺序无关性。

## 方法详解
**公理体系**：
- A1 Accountability terminus：跨边界行为必须有持久、法律上可追责的责任终点
- A2 Ephemeral members：代理实例短期存活，不持有权威状态
- A3 Heterogeneous carriers：不假设共同平台，通信须承载于已有渠道
- A4 Adversarial counterparties：跨主权输入视为不可信输入
- P1 Personal scope：目标场景为一人一主权的多代理系统

**三层本体**：Creator（自然人/主权者）→ Civilization（主权者 + 所有账本实例的并集）→ Project（文明内部或跨文明的 bounded collaboration domain）。

**内部/外部二分原则**：同一主权者的两个账本实例之间为"内部事务"，收敛目标是权威性层次的一致；不同主权者的文明之间为"外交"，收敛目标是"保留明确记录的残余分歧的同盟"。

**统一工件**：Inbound channel ≡ Task board ≡ Commitment ledger，三者合一。真相不再是"消息是否送达"，而是"双方账本记录了什么承诺状态"。

**三级签名纪律**：
1. 微同步（单次签名）：例行环境指纹、版本清单等，事后争议但两条账本均有出处记录
2. 判断（双签）：任何改变承诺状态的事件需对方反向签名，采用"密封-比较"流程——接收代理先独立记录自己的判断，再打开发送方结论
3. 仲裁（人类）：分歧报告同时提交两位主权者，由人对账本计算出的分歧进行裁决

**信任三分解**：Scope × fidelity（内部，决定调度谁）/ Credential（桥接，决定他人可依赖什么）/ Reputation（外部，决定他人是否接受）。

**身份披露阶梯**：匿名 → 持久伪名 → 已验证身份，每类交互设最低阶梯，承诺级别越高要求披露等级越高。

**时序权重协议缓解**：① Provenance envelope（四字段溯源信封）；② 密封答案分层披露（Delphi 式独立判断先行）；③ 默认反驳式验证；④ 证据优先于地位。

## 实验与结果
- **数据集/材料**：53 道客观可验证的事实性问题，经四条预注册筛选门（G1 干净性、G2 记忆探针、G3 可解性、G4 锚点形式）。
- **模型**：claude-opus-5（effort medium），每个 trial 独立无状态会话。
- **设计**：5 种条件（A 基线、B 正确锚点、C 错误锚点先到、D 带溯源信封的错误锚点、E 先密封己方答案再收到错误锚点）× 2 种验证级别（全验证：web search + page fetch + code exec，最多 8 次调用；受限验证：仅 web search，最多 3 次调用）= 9 单元格，每单元格 212 次重复，共 1,908 次试验。
- **主要结果**（全问题规格）：
  - 验证门控（H6）：错误锚点采纳率 C-restricted **54.2%** vs. C-full **4.2%**，风险差 0.500，分层 OR 71.7，$p \leq 5.0 \times 10^{-5}$（拒绝零假设）
  - 到达顺序效应（H4′）：同样错误锚点，先到 **54.2%** vs. 密封答案后到 **31.6%**，风险差 0.227，分层 OR 12.3，$p \leq 5.0 \times 10^{-5}$（拒绝零假设）
  - 正确锚点救援（Sec-2）：受限下准确率从 32.5% 升至 99.5%，风险差 0.670
  - 密封答案等效性（H5′）：E-restricted 与 A-restricted 配对差异 +0.052（95% CI [0.020, 0.098]），在 ±0.15 等效边界内声明等效
  - 溯源标签缓解（Sec-1）：D-restricted 49.5% vs. C-restricted 54.2%，方向符合预测但幅度有限
- **重要说明**：客观工具调用计数读回未能通过预注册预算条件（15.5% trial 超预算，注册阈值 < 5%），故整轮定为**探索性**（exploratory），确认性地位待 harness-enforced 预算的重复制做。
- **最强结果**：验证能力决定锚点采纳率——有无验证使错误锚点影响相差 **50 个百分点**；到达顺序在受限验证下额外贡献约 22.6 个百分点的采纳差异。

## 相关工作脉络
1. **言语行为语义学（KQML/FIPA-ACL）**：Singh 指出的致命缺陷是语义定义在代理的私有心理状态上，不可由第三方验证；本文以追加式账本作为"公共承诺存储"解决了这一缺陷，但进一步将承诺锚定在人而非代理上。
2. **社会承诺机（Commitment Machines）**：将意义从信念移到可观察的公共承诺；本文继承"意义必须钉在可观察状态上"的核心教训，并回答"谁的存储"这一前作未固定的问题。
3. **计算信任与声誉模型（Sabater & Sierra, FIRE）**：经典模型对代理打分；本文的结构性转移是将声誉附着于文明而非可替换的代理，外部可定价的是凭证（signed scope）和承诺记录（reputation）。
4. **现代互操作协议栈（MCP/A2A）**：MCP 解决代理对自身工具和上下文的访问，A2A 解决代理间的任务委派；两者均为代理寻址，缺少跨部署的主权锚定层和承诺语义层。
5. **主权数据节点与联邦（Solid/Matrix/AT Protocol）**：这些系统的联邦复制内容而非承诺，身份落脚于密钥/账户/域而非可问责的自然人；本文将其与人锚定语义焊接。
6. **代理偏见研究（AnchorBench/SynAnchors/医学阿谀研究）**：位置敏感性和锚定效应在单代理和辩论场景已有记录；本文的贡献是将其隔离到承诺形成型 A2A 通信并测试密封答案等协议级缓解。

## 局限性与未来方向
- **可达性与基础架构**：居民 embassy 在消费级硬件上需要公网入口或中继，自身的宕机语义未解决。
- **数据保护张力**：GDPR Article 17 删除权与追加式账本证据角色存在结构性冲突，crypto-shredding 方案需进一步设计。
- **主权继承与账本生命周期**：死亡与失能情形下的承诺终结、凭证失效、密钥托管未处理；无界账本增长需可验证修剪。
- **开放形式化问题**：表达能力梯度统一为一个有序结构、顺序无关性的严格证明、多方承诺对齐的终止定义、门限双签的证据语义等均待解决。
- **实验限制**：单一模型（claude-opus-5）、单一提示语言、无对照组人类；受限验证仅模拟工具表面收窄，未覆盖付费墙/离线源/组织策略等真实障碍；C/D/E 提示外壳长度不匹配，部分差异可能来自模板形式而非纯顺序效应。
- **响应成本不对称攻击**：虚假微同步项可迫使昂贵仲裁，匿名查询可消耗稀缺注意力，此攻击模式的形式化与机制设计待完成。

## 研究启发与可借鉴点
1. **无状态成员 + 有状态文明模式**可迁移到任何多代理平台：将状态外化到持久账本，代理变为可互换的执行器，极大简化故障恢复和上下文重建。
2. **统一工件设计（inbound channel = task board = commitment ledger）**是简洁性的典范：三个传统子系统合一为最小满足所有公理的物体，消除跨存储协调的复杂性，值得在协议设计中借鉴。
3. **密封答案（sealed answer）分期披露机制**可推广至任何需要形成承诺的异步协作场景（包括人机混合场景），以程序保障独立判断优先于外部影响，而非依赖训练去偏。
4. **基于记忆的授权而非基于角色的授权**提供了一个新的安全建模视角：代理权限由其实际可读取的记忆范围界定，凭证外化可审计轨迹，比传统 RBAC 更适合动态多代理环境。
5. **预注册多规格分析 + 客观读回验证**的实验方法论：本文同时报告两种问题集规格、自我报告和客观计数的双轨操作检查，为 AI 行为研究的可复现性设立了新标准。

## 关键术语表
**Civilization（文明）**：一个自然人主权者 + 持久追加式账本 + 在其上运作的可互换代理所构成的跨边界通信基本单位。
**Embassy Protocol（使馆协议）**：构建在统一工件（入站通道/任务板/承诺账本）之上的载体无关通信叠加层，支持异步存储转发和三级签名纪律。
**Representation Scope（表达力域）**：代理可访问的文明记忆范围，决定其代表主权者的权力上限。
**Temporal-Weight Effect（时序权重效应）**：在 A2A 通信中，先到信息获得不应有的认识论权重，即使内容相同且质量未知。
**Sealed Answer（密封答案）**：接收方在被看到发送方结论之前，先将己方独立判断密封写入账本，以消除顺序影响。
**Credential（凭证）**：文明以签名方式声明某代理拥有特定表达力域的认证，等价于外交"国书"。
**Reconciliation Handshake（调和握手）**：双方交换承诺状态摘要，定位分歧点，仅传输差异部分；内部收敛于一致，外交收敛于保留分歧的条约。
**Provenance Envelope（溯源信封）**：包裹每条跨代理主张的四字段结构（来源、验证状态、置信度等级、处理指令），将主张定位为待检验假设而非事实。

- **数据集**：53 道事实性问题，经预注册筛选门；题目来源列于预注册材料。
