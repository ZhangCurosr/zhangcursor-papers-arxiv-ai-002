# 论文速读：TraceML-An-Empirical-Analysis-of-Human-Agent-Planning-in-Mac

## 一句话总结
本文构建了版本级的人类-Agent 对齐轨迹数据集 TraceML，首次在同一 Kaggle 竞赛维度下实证刻画 LLM Agent 在自主 ML 开发过程中的系统性行为偏差；基于人类实践蒸馏的规划提示符可收敛部分可指令化的行为缺口并提升 5/7 竞赛成绩，但 Agent 缺乏历史记忆与自适应控制的核心缺陷仍无法仅靠提示修复。

## 研究问题与动机
1. LLM 在孤立代码任务上表现成熟，但在长周期、多反馈迭代的自主 ML 开发中仍显著落后于人类高手，而现有基准仅记录最终提交分数，无法解释过程差距的成因。
2. 结果导向评测使两次得分相同的运行被视为等价，掩盖了 Agent 是否进行了有效探索、诊断与方向调整等关键开发行为。
3. 缺乏覆盖人类与 Agent 同任务、同时间尺度、同版本粒度的可比数据，导致 Agent 行为诊断只能停留在抽象工具调用层面，无法落地到真实 ML 工程实践。
4. 如何将人类在 Kaggle 竞赛中沉淀的有效开发模式显式提取，并验证其能否转化为可干预 Agent 的规划机制，尚无实证基准。

## 核心贡献（创新点）
1. **开源 TraceML 数据集与统一提取管线**：提供 4,465 条人类 Kaggle 轨迹与 207 条 Agent 轨迹（Codex 与 MLEvolve），附版本级标注代码、Qwen3-1.7B 标签器权重与规划干预工具。*区别于以往仅含最终分数的基准，本文首次提供带分数、时间戳与动作意图标签的跨系统可比轨迹。*
2. **提出版本级过程标注 Schema**：将 Kaggle 笔记本历史、CLI 提交与树搜索日志映射为同一表示，定义 8 粗粒度+136 细粒度状态标签，以及动作、意图、编辑幅度、分数效应四类过渡标签。*突破以往基准依赖代码相似度或单一指标评测的局限，实现细粒度行为对齐。*
3. **实证定位人类-Agent 过程差距**：量化揭示 Agent 转折率低（Codex 9% vs 人类 25%）或缺失回溯能力（人类 9% vs Agent ≈0%），且集合策略流于形式（重加权占主导而非新增成员）。*与仅比较最终排名的工作不同，本文从行为分布角度给出差距的结构化归因。*
4. **设计并验证规划干预 Harness**：蒸馏出约 1k token 的规划提示（反循环约束、K-fold 优先、早期集成、OOF 缓存、周期性自检），推动部分行为向人类靠拢并在 7 个竞赛中提升 5 个成绩。*证明指令可修复部分缺陷，同时清晰划出“可指令化”与“需架构升级”的能力边界。*

## 方法详解
- **轨迹重构与对齐**：人类侧从 Meta Kaggle 数据库提取公开 Notebook 保存历史，通过 DAG 重建 lineage，过滤死线后编辑、浅层谱系与无分刷榜；Agent 侧分别追踪 Codex 的单目录 Git 提交与 MLEvolve 的搜索树分支，统一线性化为版本序列。两侧均使用竞赛官方指标重评每一版本，并按竞赛内百分位归一化以消除度量差异。
- **版本级标注 Schema**：每版代码分配 8 类粗粒度 ML 阶段标签（data、features、augmentation、model、training、ensemble、validation、inference 等）与 136 类细粒度标签；每次版本过渡标注多标签 action、意图 intent、编辑幅度 magnitude 与分数效应 score-effect。
- **自动化标注流水线**：因手动标注 151,088 版本不可行，采用 GPT-5.4-mini 作为教师模型在精选轨迹上生成约束标签，蒸馏训练两个 Qwen3-1.7B 学生模型（分别预测版本状态与过渡动作）。通过 Schema 合规性、独立标注员一致性（coarse state κ=0.872，intent κ≈0.61-0.83）与行为复核三重验证可靠性。
- **规划干预 Harness**：约 1000 token 提示，含四大机制：①反循环约束（禁止单 hold-out、连续微调超参/后处理、首发大重写）；②人类优先实践（首版起用 K-fold、尽早集成、缓存 OOF 预测、多模型/种子混合）；③任务特定先验（Text/Tabular/CV/Time-series 差异化建议）；④每 30-60 分钟周期性自检（7 项检查清单）。在 Codex CLI 上以 12 小时预算、相同后端与 MLE-bench 评分器进行对照与消融实验。

## 实验与结果
- **数据集规模**：人类 4,465 轨迹（134 竞赛，覆盖 Grandmaster/Expert/Master/Contributor）；配对子集 7 竞赛、430 条人类轨迹、207 条 Agent 轨迹（Codex 18、MLEvolve 189）。
- **核心发现数字**：
  - 动作谱距离：Codex 与顶级人类 JSD ≈ 0.077–0.095 bits（接近人类内部差异），MLEvolve 明显偏离（0.09–0.12 bits）。
  - 细粒度动作：Codex 精力集中在 ensemble/inference 本地微调（占 19.7%+18.9%），MLEvolve 集中在 model/training（20.4%+18.0%）；人类分布更均衡。
  - 转折与回溯：人类转折率 25%（平均 +0.089 分）、Codex 9%、MLEvolve 58%（+0.008，得失相抵）；人类回溯率 9%（78% 成功超越回退点），Agent 几乎为 0。
  - 集合质量：78% Codex 集成编辑仅为重加权，人类高质量集合表现为增量添加新成员；`change_weights` 与排名呈负相关（ρ=-0.42）。
- **Harness 干预结果**：5/7 竞赛显著提升（gquest Spearman↑、aes2 QWK↑、hms KL↓、ranzcr AUC↑、amex 提升），2 在噪声范围内，无一退化；重加权比例下降约 5 倍，微小早期编辑从无升至超人类水平；但工作模式切换率仍远低于人类（2.2% vs 13.2–14.1%），说明指令仅触及可命名行为边界。

## 相关工作脉络
1. **MLE-bench / MLAgentBench / AIRA**：以最终提交或工具调用日志评测 Agent，缺失人类对照与版本级过程记录；TraceML 填补同任务下人类-Agent 轨迹对齐与细粒度行为诊断空白。
2. **RE-Bench / HCAST**：引入人类基线但多基于定制环境或仅统计时间预算成败，未提供完整代码版本历史；TraceML 提供 134 竞赛真实公开
