# 论文速读：VBVR-Pro: A Scalable and Verifiable Suite for Native Visual Reasoning

## 一句话总结
本文提出了 VBVR-Pro，一个面向"原生视觉推理"（native visual reasoning）的可训练、可验证、可优化的闭环基准套件，包含 300 个程序化生成的任务、逐任务可验证的奖励评分器，以及跨图像/视频/交错生成器的系统性对比与 RL 优化实验。

## 研究问题与动机
- **原生视觉推理缺乏可扩展的训练数据源**：现有视觉推理基准多为评测设计，提供的训练数据极少；已有大规模合成数据 [58] 聚焦简化符号设定，能否教授可迁移的视觉推理能力存疑。
- **缺少可靠的反馈信号**：主流的 VLM-as-a-judge 范式在"精确计数、细粒度空间关系、时序一致性和规则满足"类任务上存在系统性失效，不适合作为强化学习奖励。
- **不同生成基元（image/video/interleaved）在统一任务分布下的对比尚未开展**：三种模态各具优势，但缺乏基于相同任务与验证协议的受控比较，难以回答"何种生成基元最适合视觉推理"这一核心问题。

## 核心贡献（创新点）
1. **任务规模扩展（Task Scaling）**：构建 300 个程序化生成任务的大规模数据集 VBVR-Pro-Dataset（1.25M 训练实例），模型在该数据集上训练后可跨七个外部基准（如 RISE-Video、MME-CoF-Pro、BabyVision）稳定提升，并证明增益来源于视觉推理而非指令模式拟合。
2. **可验证奖励评分器（Verifiable Rewards）**：提出基于结构化语义提取与任务特定规则的逐任务 scorer，规避像素级比较；在 Arena 式人类偏好评测中取得最高的 per-vote 一致性（>0.60），远超 GPT-5.5 与 Gemini-3.1-Pro，并可稳定用于大规模多任务 RL。
3. **机理研究（Mechanism Study）**：在 30+ 图像/视频/交错生成器上开展受控模态比较，发现视频生成在需持续时空状态追踪的任务上最强，交错生成以更低计算代价提供等效性能；消融与干预实验表明"视觉状态轨迹"比显式语言链思维更重要。
4. **RL 基线与 CPS 采样策略**：首次将可验证奖励用于多任务视觉推理 RL（RLVR），并使用 Coefficients-Preserving Sampling (CPS) 在保持生成保真度的同时提供足够的探索多样性。

## 方法详解
- **任务生成器设计**：300 个参数化生成器（150 修订自 VBVR [58] + 150 全新设计），覆盖感知（Perception）、空间性（Spatiality）、变换（Transformation）、抽象（Abstraction）与知识（Knowledge）五大认知层面，每个生成器附带 solver 提供程序化标注答案与 metadata（seed、规格、完整解）。
- **多模态对齐**：每实例同时渲染为视频与图像两种模态；图像输出采用三种 regime：Last-Frame（仅需最终态）、Key-Frame（关键中间态）与 Multi-Frame（均匀采样中间态），确保视频与图像是同一问题实例的不同渲染，而非独立语料。
- **可验证评分器**：规避像素差异，采用 HSV 颜色分割、轮廓检测、OCR、轨迹跟踪等经典 CV 方法提取任务相关语义属性，按"加权求和（软约束）"或"乘法门控（硬约束）"聚合为最终分数；全程确定性，无 API 调用开销。
- **RL 优化框架**：基于 Flow-GRPO/DanceGRPO 类 group-relative 方法，使用 CPS 采样公式 $x_{t-\Delta t} = (1-(t-\Delta t))\hat{x}_0 + (t-\Delta t)(\cos(\eta\pi/2)\hat{x}_1 + \sin(\eta\pi/2)\epsilon)$，通过增大 $\eta$ 引入语义级探索而不增加总噪声系数；配套一步延迟异步流水线提升 GPU 利用率。

## 实验与结果
- **数据集规模**：300 任务，50 任务 held-out 为 OOD 评测集；从 250 任务中每任务采样 5,000 实例 → 1.25M SFT 训练集；另含 50K 专用 RL 子集。
- **主基准 VBVR-Pro-Bench**：最强开源视频模型 VBVR-Pro-Wan2.2-I2V-A14B 在 ID 上达 0.719，OOD 上达 0.377；训练后平均总提升 +0.290（ID +0.401，OOD +0.179）。
- **跨模态比较**：视频模型 VBVR-Pro-Wan2.2-I2V-A14B（整体 0.638）与最强交错模型 VBVR-Pro-SenseNova-U1（整体 0.638）在 ID 上持平，但交错模型计算成本更低；单图像模型（最高 VBVR-Pro-FLUX.2 为 0.407）明显落后。
- **转移实验**：VBVR-Pro-Wan2.2-I2V-A14B 在七个外部基准上均取得 ≥20pp 提升，如 V-ReasonBench 从 10.21 → 38.22，RISE-Video 从 62.83 → 66.18，VideoThinkBench mini 从 25.71 → 52.86。
- **RL 实验**：RLVR 达总得分 0.548（ID 0.719，OOD 0.377），优于 RLVLM（0.508）与 SFT（0.503），且 OOD 收益更显著，证明可验证奖励提供更强迁移信号。
- **诊断分析**：最近邻检索（CLIP/DINOv2/BGE）显示测试样本在特征空间中距离训练样本较远；同 prompt 视觉反事实实验表明模型对视觉状态变化敏感而非记忆指令模板。

## 相关工作脉络
- **VBVR [58]**：前代基准，提供 150 任务与可验证评分器，但任务规模与推理深度有限；本文在其基础上将任务数翻倍并引入 RL 训练与跨模态对比。
- **DiffThinker [22] / EndoCoT [10]**：将视觉推理重构为图像生成任务，但仅在少量固定任务上验证，缺乏统一基础设施与大规模训练源。
- **Chain-of-Step（CoS）[60]**：揭示视频扩散模型在去噪步中的推理行为；本文将其扩展至图像与交错生成器，并证明视觉轨迹的作用。
- **Zebra-CoT [31] / StructCoT [59] / ThinkMorph [18]**：大规模交错视觉-文本语料，但非程序化生成、不可验证；本文证明视觉中间状态比文本语义贡献更大（Table 5 消融）。
- **Flow-GRPO [33] / DanceGRPO [68]**：通用视觉生成 RL 方法，奖励多基于像素保真度或美学；本文将其适配至"语义正确性+任务约束满足"的原生视觉推理目标，并提出 CPS 作为更好的探索策略。
- **VLM-as-a-judge 范式**：多数现有基准依赖 GPT/Gemini/Qwen 等大模型评分（见表 1）；本文系统性指出其数值不精确、忽略细粒度证据、误解任务规则三类失效模式，并证明确定性 scorer 在实例级精度与可复现性上全面超越。

## 局限性与未来方向
- **任务仍为程序化生成**：场景抽象程度较高（空白画布、棋盘布局、精灵场景），与真实世界复杂场景存在域差；向更复杂自然场景的迁移有待验证。
- **RL 训练规模有限**：当前 RL 仅在 50 任务 / 50K 实例上开展，尚未探索更大尺度或多任务组合下的 scaling behavior。
- **VLM judge 的失效分析主要覆盖商业模型**：对新兴开源大模型的失效模式分析不足，可能遗漏某些架构特有行为。
- **单模态固定比较**：每种生成器的训练超参与训练时长一致，未深入探究不同 architecture scale 与训练预算对模态优势的交互影响。

## 研究启发与可借鉴点
1. **程序化任务 + 确定性 scorer + RL 闭环**的架构设计可作为其他生成推理方向（如 3D 推理、机器人操作）的可复用模板，无需依赖 VLM 评分即可实现大规模优化。
2. **CPS 采样用于视觉推理 RL 探索**的发现表明：在离散语义决策类任务中，单纯增加噪声幅度会损害视觉保真度，而系数保持策略能更好分离"探索多样性"与"生成质量"，值得在其他 diffusion RL 场景中复现。
3. **中间视觉状态的因果干预实验**（移除/污染中间帧导致性能骤降）提供了强有力的因果证据，可借鉴用于验证其他"链式推理"工作是否真正依赖中间表示而非捷径。
4. **Last-Frame/Key-Frame/Multi-Frame 三种图像输出 regime 的设计**为视觉推理数据构建提供了灵活框架，可根据任务对过程显式程度的需求自动选择，避免统一视频或统一单图带来的信息损失。
5. **同实例视频-图像对齐生成**的思路可直接迁移：任何视频生成基准均可衍生出对齐的图像子集，从而在相同任务分布下公平比较视频与图像生成器的推理能力。

## 关键术语表
- **Native Visual Reasoning（原生视觉推理）**：将视觉生成本身作为推理基元，模型通过构造、更新和优化视觉状态（图像/视频）来解决问题，而非仅将视觉输入/输出服务于语言链思维。
- **VBVR-Pro-Bench**：包含 100 任务（50 域内 + 50 域外）的评测基准，所有任务均有程序化可验证 scorer。
- **Chain-of-Step（CoS）**：视频扩散模型在去噪过程中展现的多步推理行为，如多路径探索与逐步收敛。
- **CPS（Coefficients-Preserving Sampling）**：一种 RL 探索采样策略，在替换部分预测噪声为高斯噪声的同时保持总系数为 1，避免过度累积噪声而损害生成质量。
- **RLVR / RLVLM**：分别指使用可验证 scorer 与 VLM judge 作为奖励信号的强化学习训练变体。
- **Interleaved Generation（交错生成）**：在推理过程中交替生成文本推理步骤与中间视觉状态（图像）的生成范式。
- **VLM-as-a-Judge**：将视觉-语言大模型用作开放型生成输出的自动评分器，已被广泛采用但本文指出其在精确视觉推理任务中存在系统性失效。

## 可复现要素
- **数据集**：VBVR-Pro-Dataset（300 任务，1.25M 训练实例）与 VBVR-Pro-Bench（100 任务）已开源；RL 子集（50K 实例）同步发布。
- **代码**：项目论文声明全部代码、scorer 与数据均已开源，参见 arXiv 摘要末尾的 release 声明。
- **关键超参**：SFT 分辨率 512×512，LoRA rank-32，视频训练 16 fps；RL 使用 CPS η=0.7、30 步采样、学习率 5×10⁻⁶、batch 32 prompts × 32 trajectories。
- **评估协议**：Arena 式人类偏好标注（每对模型 10 次独立标注，四档 L₀–L₃ 映射为四类别偏好向量）。
