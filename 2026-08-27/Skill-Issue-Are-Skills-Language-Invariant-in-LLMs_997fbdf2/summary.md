# 论文速读：Skill-Issue-Are-Skills-Language-Invariant-in-LLMs

## 一句话总结
本文通过多语言自博弈（multilingual self-play）方法，在控制规则与状态空间不变的前提下，量化了同一LLM在不同语言接口下表现出的技能不一致性——相同模型在弈棋、博弈等交互式任务中的胜率、策略行为与推理能力会随语言接口系统性地变化。

## 研究问题与动机
1. **现有工作聚焦知识存取差异，忽视技能表达差异**：已有跨语言一致性研究主要关注模型能否在不同语言中检索到相同的知识（knowledge accessibility），但较少探讨模型是否在不同语言下具备相同水平的推理、规划与决策技能。
2. **多语言LLM部署公平性存疑**：随着LLM日益多语化，其在不同语言间的表现不平等愈发明显，需识别阻碍模型成为"语言无关系统"的根本原因。
3. **缺少对交互式行为的跨语言评估**：静态基准（如MMLU、Belebele）只能衡量固定输入下的准确率，无法反映模型在动态交互中是否表达等价策略。
4. **语言是否影响中间推理阶段尚不明确**：即便环境观测非语言依赖，语言接口仍可能通过影响状态解释、推理过程或动作选择等多个决策阶段来改变最终行为。

## 核心贡献（创新点）
1. **提出"多语言自博弈"框架以正交隔离语言效应**：通过令同一模型的两次实例在不同语言界面下对弈，固定规则/状态/动作空间，从而将语言对行为的影响从知识存取和整体基准性能中剥离出来；区别于此前仅比较静态翻译输入一致性的工作。
2. **构建Multilingual TextArena扩展数据集**：将TextArena的65个游戏扩展至193种语言（含8种Tier A手动验证语言），提供大规模多语言交互式评测基准；现有工作大多局限于单一语言或少数语言的对齐评测。
3. **首次系统量化LLM跨语言技能不一致性**：在6个游戏、8种语言、3个4B级开源模型上发现同一模型可在不同语言下展现显著不同的胜率与策略倾向，而不仅是知识存取差异；区别于 prior work 仅报告跨语言知识孤岛（compartmentalization）。
4. **揭示"强语言推理可部分恢复弱语言性能"的现象**：证明保持弱语言界面不变时，将中间推理切换至更强语言可恢复部分性能（如TicTacToe中恢复89.4%），说明语言敏感性可作用于推理阶段；此前工作仅关注输入翻译而非推理语言干预。
5. **将静态基准与网页数据可用性作为解释变量进行系统分析**：发现静态MMLU/Belebele成绩与交互胜率呈中等正相关（r=0.71~0.92），但无法解释稳定性差异；并识别出文字系统（script）与数据量各自只能解释部分方差，剩余为模型特异性。

## 方法详解
1. **多语言自博弈设置**：对于每个游戏g，Player 0使用语言ℓ₀，Player 1使用语言ℓ₁（ℓᵢ ∈ {en, ar, de, es, fr, he, ms, zh}），双方观测对手原始语言消息。棋盘符号、坐标、卡牌点数、数值及动作语法（如`[bet]`、`[cell]`索引）在多语言版本中保持一致。
2. **六种博弈环境**：TicTacToe（空间推理）、Nim（算法策略）、Simple-Tak（空间连接）、Colonel Blotto（资源分配）、Kuhn Poker（不完全信息/ bluff）、Iterated Prisoner's Dilemma（重复社会交互）。
3. **角色池化胜-负边际（Role-pooled win-loss margin）**：
   $$\Delta_{m,g}(A,B) = \frac{W_{m,g}(A,B) - L_{m,g}(A,B)}{N_{m,g}(A,B)}$$
   通过同时评估(A,B)与(B,A)两种角色分配并池化结果，消除先手等优势。
4. **语言强度汇总**：先按游戏计算每种语言的均值边际μ，再跨游戏macro-average得到$\bar{\mu}_m(A)$，数值越大表示该语言接口下平均表现越强。
5. **推理语言干预实验**：固定界面语言为弱语言（如German），要求模型以另一种语言进行中间推理，比较其对$\mu$的提升幅度：
   $$\text{Recovery} = \frac{\mu - \mu_{\text{weak}}}{\mu_{\text{best}} - \mu_{\text{weak}}}$$
6. **采样参数**：temperature=1.0, top_p=0.95, top_k=64，鼓励多样对弈轨迹；每语言对×每游戏×每方向各400局，总518,400局。
7. **翻译流水线**：Tier A（8语言）由Claude Opus 4.8/GPT-5.2翻译并经母语者验证；Tier B/C/E分别采用Llama-3.1-405B/Qwen2.5-72B+NLLB-200 + 反向翻译+LLM判定 fidelity ≥85%。

## 实验与结果
- **模型**：Gemma-4-E4B-it、Qwen3-4B、Ministral3-3B-Instruct-2512（均≈3-4B参数）。
- **语言**：8种Tier A语言（en/ar/de/es/fr/he/ms/zh）。
- **游戏**：6种两玩家博弈。
- **总对局数**：86,400局/游戏，518,400局总计。
- **主要发现**：
  - **英语整体最强，希伯来语整体最弱**（图2热图），Qwen3语言层级最显著。
  - **语言敏感度因游戏而异**（表2）：Colonel Blotto最大差距（Qwen: 1.48, Ministral: 1.28），Kuhn Poker最小差距（Qwen: 0.13, Ministral: 0.20）。
  - **空间推理差异**（附录G.1）：Gemma/Ministral在非拉丁语界面下对角线/列方向失分偏高（如Gemma英语对角线失分36.7%，阿拉伯语升至45.3%）；Qwen相对均衡。
  - **策略行为差异**（附录G.2）：Kuhn Poker中Qwen最弱牌的bluff率跨语言变化超过2倍；Ministral最优牌Fold率高达10.4%~23.7%。
  - **Nim策略存取**（附录G.3）：Qwen在英语最优首步执行率80.8%，法语仅24.6%，提及策略次数与执行率并不一致。
  - **强语言推理恢复**（表3）：Gemma固定German界面、推理切换为English时，TicTacToe边际从-0.22升至+0.20，恢复89.4%；SimpleTak恢复60.5%。Kuhn Poker恢复有限（37.6%~49.3%）。
  - **与静态基准的相关性**（表4、图4a）：平均语言边际与Global-MMLU相关性r=0.73~0.92，与Belebele相关性r=0.71~0.79；但**稳定性（max-min范围）与平均成绩解耦**——Gemma MMLU最低却最稳定，Qwen最高却最不稳定。
  - **与网页数据的相关性**（图4b）：FineWeb-2词频与语言强度呈正相关（r≈0.79），但马来语（Latin script）异常高于趋势线，中文在Qwen/Ministral上异常高于其数据量预期。

## 相关工作脉络
1. **跨语言知识一致性（XOR-QA, X-FACTR, Eclektic等）**：关注不同语言间的事实性知识是否可比及可转移；本文与之正交——研究的是同一知识下技能表达（skill expression）是否一致。
2. **跨语言提示/自我翻译（Cross-lingual-thought, Question Translation Training）**：通过翻译输入或切换推理语言提升多语性能；本文发现推理语言干预可部分恢复技能，但恢复效果因游戏而异，说明仅靠翻译不足以解决深层语言敏感性。
3. **静态多语基准（Belebele, Global-MMLU, XTREME, BenchMAX等）**：评估固定输入下的准确率；本文强调动态交互中政策一致性，揭示静态高分≠跨语言行为稳定。
4. **交互式LLM评估（GameBench, SmartPlay, τ²-bench, GTBench, Spin-Bench等）**：多在单一语言接口下比较不同模型/方法；本文首次在同一模型内以自博弈隔离语言对交互技能的因果效应。
5. **跨语言技能迁移（source-finetuning transfer, multilingual instruction tuning）**：研究从一种语言微调后向其他语言的zero-shot迁移；本文关注运行时语言界面条件化而非训练时的技能获取。
6. **脚本与跨语言知识转移（Goldman et al., Ifergan et al., Malkin et al.）**：发现共享文字系统的语言间转移更强；本文验证马来语（Latin script）借势英语提升表现、希伯来语受限的现象，并与数据量效应分解。

## 局限性与未来方向
1. **训练数据不可见**：被评模型训练数据不公开，只能以网页文本量（FineWeb-2）作为代理变量，无法直接归因训练分布差异。
2. **模型规模有限**：仅评测3-4B参数模型，更大模型的语言不一致性模式可能不同，结论未必具有规模不变性。
3. **语言覆盖有限**：核心实验仅8种Tier A语言，尽管扩展到193种但低资源语言质量参差；跨脚本/形态复杂语言的系统性偏差仍有待验证。
4. **恢复策略普适性存疑**：推理语言切换仅在部分游戏（如空间类）有效，在Kuhn Poker等不完全信息博弈中恢复有限且非单调。
5. **未探索训练阶段干预**：本文停留在评测与分析层面，未提出跨语言技能对齐的训练方法，也未验证数据配比或指令微调对技能一致性的改善效果。

## 研究启发与可借鉴点
1. **"自博弈+固定规则"范式可迁移至其他交互场景**：通过控制环境状态与动作空间不变、仅替换语言接口，可在任何多轮Agent-Environment交互基准（如工具使用、对话任务、模拟仿真）中隔离语言效应，是一种干净的反事实评估设计。
2. **推理语言干预（reasoning-language switching）可作为即插即用缓解手段**：在保持界面语言为用户偏好语言的前提下，将中间CoT切换至强语言，可在空间/策略类任务中恢复大量性能；值得在生产系统中作为低成本优化策略。
3. **"平均成绩×稳定性"双轴评测维度值得推广**：本文揭示"整体更强≠更一致"（Qwen vs Gemma），建议后续多语评测同时报告跨语言均值与max-min spread，避免单一平均分掩盖不平等问题。
4. **技能分层归因（空间/策略/知识存取/动作执行）的分析框架可复用**：本文按 defeat type、card-conditioned action、optimal move execution 等维度拆解语言敏感度来源，此归因思路可直接迁移到任何多Agent交互评估中。
5. **文字系统（script）作为控制变量的价值**：马来语高出于其数据量的现象提示，跨语言研究应将script sharing纳入混杂因素控制，便于更精确分离数据量效应与表征共享效应。

## 关键术语表
**Multilingual Self-play**：同一模型的不同语言接口实例在相同规则下进行对弈，用于隔离语言对行为的影响。
**Role-pooled Win-loss Margin (Δ)**：通过合并正反两方角色分配后计算的胜率边际，取值[-1,1]，正值为行语言强于列语言。
**Mean Language Margin (μ)**：某语言与其他所有语言配对边际的均值，衡量该语言接口的平均交互强度。
**Language Sensitivity**：某模型在某游戏中最强与最弱语言接口之间μ值的差距，量化语言依赖性程度。
**Language-conditioned Skill Difference**：同一模型在不同语言界面下表现出的系统性行为差异，涵盖空间推理、策略倾向与已知知识可及性三个层面。
**Recovery Rate**：固定弱语言界面、切换强语言推理时，恢复的可达性能差距比例。
**Fidelity（翻译保真度）**：通过反向翻译或LLM判定机制评估翻译文本与原英文规则的语义忠实度，以≥85%为Tier C阈值。
**Script Transfer Effect**：共享书写系统的语言之间因表征重叠而产生的跨语言性能溢出效应。

## 可复现要素
- **数据集**：Multilingual TextArena，65个游戏扩展至193种语言，基于MIT许可开源（集成到TextArena仓库）；核心8语言×6游戏实验数据随论文发布。
- **代码/权重**：Gemma-4-E4B-it、Qwen3-4B、Ministral3-3B-Instruct-2512均为开源权重；TextArena开源（Guertler et al., 2025）。
- **推理框架**：vLLM + Ray分布式rollout。
- **采样超参**：temperature=1.0, top_p=0.95, top_k=64。
- **每对语言×每游戏×每方向**：n=400局；角色双向评估。
- **硬件**：每场跑需2块NVIDIA H200 GPU，约6 H200 GPU-hours/游戏（不含IPD）。
- **外部评测**：Belebele与Global-MMLU（5-shot）使用官方仓库与LM-Evaluation-Harness默认配置。
- **翻译模型**：Claude Opus 4.8、GPT-5.2（Tier A）；Llama-3.1-405B、Qwen2.5-72B、NLLB-200（Tier B/C/E）。
- **未提及**：具体随机种子、完整训练数据配比、推理语言干预实验的seed细节。
