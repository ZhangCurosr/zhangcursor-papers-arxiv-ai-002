# 论文速读：Skill-Issue-Are-Skills-Language-Invariant-in-LLMs

## 一句话总结
本文通过多语言自我对弈实验证明，同一LLM在不同语言界面下会表现出显著的策略能力与空间推理差异；即使严格控制游戏环境、规则与动作空间不变，语言本身仍是影响模型技能表达的关键变量，且通过切换至更强语言进行中间推理可在部分任务中恢复大部分性能缺口。

## 研究问题与动机
- **知识差异 vs. 技能差异**：现有跨语言一致性研究多聚焦于模型在不同语言中检索事实知识的偏差，但缺乏对“同一模型在不同语言交互下能否同等调用推理、规划与决策技能”的系统量化。
- **静态基准的盲区**：Global-MMLU、Belebele等静态评测仅衡量固定输入的产出准确性，无法捕捉多轮对抗、状态更新与策略适应过程中的语言敏感性。
- **部署公平性隐患**：若同一能力在英语界面下稳定执行而在阿拉伯语/希伯来语界面下频繁失效，多语言大模型的实际部署将产生系统性语言偏见。
- **因果隔离需求**：需构建控制变量严格的对抗环境，剥离知识储备差异与基线性能差异，单独度量“语言接口”对模型 realized behavior 的独立影响。

## 核心贡献（创新点）
- **多语言自我对弈评测范式**：构造相同模型的双实例对抗设置，双方共享规则、状态空间与动作集，仅交换语言接口，首次正交分离语言对技能表达的影响。
- **开源 Multilingual TextArena 扩展**：构建覆盖6款博弈游戏与193种语言的自动化翻译与结构化验证管线，为跨语言 Agent 评测提供可复用资源。
- **技能粒度差异的实证刻画**：揭示同一模型在空间推理失败轴（行/列/对角线分布）、风险偏好（Kuhn Poker  bluff rate 跨语言翻倍）、已知策略调用（Nim-sum 提及与执行率）上均随语言发生系统性波动。
- **推理语言干预的有效性验证**：证明固定弱界面语言（如 German）并切换至强语言进行中间推理，可在 TicTacToe 与 Simple-Tak 中分别恢复 89.4% 与 60.5% 的性能缺口，指出语言敏感性可作用于推理阶段。

## 方法详解
- **实验设置**：对每款游戏 $g$，分配玩家 0 使用语言 $\ell_0$，玩家 1 使用语言 $\ell_1$（$\ell \in \{en, ar, de, es, fr, he, ms, zh\}$）。棋盘符号、卡牌等级、数值、固定动作语法（如 `[bet]`、`[cell]`）在所有语言中保持原样，仅自然语言描述与指令被翻译。
- **角色池化胜率差指标**：$\Delta_{m,g}(A,B) = (W_{m,g}(A,B) - L_{m,g}(A,B)) / N_{m,g}(A,B)$，将 $(A,B)$ 与 $(B,A)$ 两种角色分配的结果聚合，消除先手优势等结构性偏差，取值范围 $[-1, 1]$。
- **语言强度汇总**：单游戏平均 $\mu_{m,g}(A) = \frac{1}{|\mathcal{L}|-1}\sum_{B \neq A} \Delta_{m,g}(A,B)$，跨游戏宏观平均 $\bar{\mu}_m(A) = \frac{1}{|\mathcal{G}|}\sum_{g} \mu_{m,g}(A)$。
- **推理语言干预**：固定界面语言为弱语言，通过 system prompt 强制模型在 reasoning 阶段使用强语言（如 German interface + English reasoning），对比性能恢复比例。
- **翻译与质量保障管线**：Tier-A 语言由 GPT-5.2 / Claude Opus 4.8 翻译并经母语者人工审核；扩展语种采用 NLLB-200 正向翻译 + LLM 双模型反向忠实度判定器；所有翻译保留 `{placeholder}`、`[action_token]` 并经由 parser-token oracle 校验结构可玩性。
- **采样与执行**：temperature=1.0, top_p=0.95, top_k=64；最终动作强制包裹于 `\boxed{}` 供环境解析；每模型-游戏-语言对进行 400 局双向对弈，总规模 518,400 局。

## 实验与结果
- **数据集与基线**：Multilingual TextArena（6 游戏×8 语言）、Global-MMLU（5-shot）、Belebele；对比模型 Gemma-4-E4B-it、Qwen3-4B、Ministral3-3B-Instruct-2512。
- **整体表现**：English 在所有模型中平均最强，Hebrew 持续最弱；Qwen3-4B 语言层级分化最尖锐（avg. gap 0.54），Gemma 最稳定（0.28）。Colonel Blotto 语言敏感度最高（1.07），Kuhn Poker 最低（0.13）。
- **技能差异细化**：
  - **空间推理**：TicTacToe 与 Simple-Tak 中，Arabic/Hebrew 界面的失败显著偏向列与对角线（Gemma 对角线失败占比高达 45%+），而 English 分布相对均衡。
  - **策略行为**：Kuhn Poker 中 Qwen3-4B 的最弱牌 bluff rate 跨语言波动超两倍；Ministral3-3B 的 Invalid action 率高达 12.3%，且强牌 Fold 率波动显著。
  - **知识调用**：Nim 最优策略提及数与胜率在 Arabic/Hebrew 下骤降；Qwen3-4B 在 English 下首步最优执行率达 80.8%，French 仅 24.6%，显示“知道”与“能执行”存在语言割裂。
- **干预恢复**：German 界面 + English 推理在 TicTacToe 恢复 89.4%，Simple-Tak 恢复 60.5%；Kuhn Poker 恢复有限且非单调，表明语言影响分布在状态解析、推理、决策多个阶段。
- **归因分析**：$\bar{\mu}_m(A)$ 与 Global-MMLU 准确率呈强正相关（r=0.73~0.92），与 Belebele 呈中等正相关（r=0.71~0.79），与 FineWeb-2 网页词频（log 尺度）亦呈强拟合（r≈0.79）；但马来语（拉丁脚本）表现超越希伯来语（高资源词频但非拉丁脚本），Chinese 在 Qwen/Ministral 下接近 English 水平而 Gemma 仍近零，说明数据量与脚本共享仅解释部分方差，模型自身特性决定剩余差异。

## 相关工作脉络
- **跨语言知识隔离研究**（Goldman et al., 2025; Ifergan et al., 2024; Qi et al., 2023）：聚焦参数化知识在不同语言中的 compartmentalization，本文与之正交，转向动态交互中的技能调用一致性。
- **多语言静态基准**（Belebele, Global-MMLU, XCOPA, MMLU-Pro）：衡量固定输入输出的语言均衡性，本文引入多轮对抗博弈，补全“交互决策能力”的语言评估维度。
- **自翻译/路由到英语**（Zhu et al., 2024; Etxaniz et al., 2024; Huang et al., 2023）：主张非英语输入经 English routing 提升性能，本文验证“界面语言固定+内部推理切换”在博弈场景中的有效性与适用边界。
- **文本 Agent 博弈评测**（TextArena, GtBench, SmartPlay, Spin-Bench）：现有工作多在单一语言下比较不同模型或 prompting 策略，本文在该框架上扩展多语言接口，专攻单模型跨语言行为方差。
- **脚本迁移与低资源语言研究**（ECLeKTic, Malkin et al., 2022; Diskind et al., 2026）：指出共享书写系统的语言间迁移更强，本文马来语优于希伯来语的结果与此规律一致，强化脚本特征在跨语言对齐中的重要性。

## 局限性与未来方向
- **训练数据不可观测**：三个模型的预训练语料分布未公开，无法精确量化各语言学习强度对技能差异的因果贡献，仅能以 FineWeb-2 词频与基准分作为代理。
- **模型规模限制**：仅评估 3B-4B 量级模型，大模型（如 70B+）的参数冗余可能稀释语言敏感性，结论未必可外推至 scale-up 场景。
- **语言与任务覆盖有限**：仅 8 种 Tier-A 语言与 6 款游戏，未涵盖黏着语、 agglutinative 语言及长程多轮协作任务，技能差异的普适性待扩展验证。
- **未来方向**：开发语言鲁棒的策略对齐训练机制；探索多层级推理语言动态路由；将框架迁移至真实多语言 Agent 工具调用与跨语言人机协作场景；结合可解释性方法定位语言敏感的具体推理链节点。

## 研究启发与可借鉴点
- **控制变量自我对弈范式可直接迁移**：凡涉及多轮交互、状态更新、对手响应的任务（如对话 Agent、协作规划、经济模拟），均可套用“同模双语对弈”设计，精准剥离语言接口噪声。
- **“界面-推理语言解耦”工程策略**：在低资源语言线上部署时，可固定用户端弱语言界面，强制模型内部 Chain-of-Thought 使用强语言，以极低成本挽回策略型任务性能。
- **结构化占位符与 parser-token oracle 校验**：保留 `{placeholder}` / `[action_token]` 并在翻译后强制回代匹配，对多语言工具调用、代码生成、程序化评测具有高复用价值。
- **细粒度技能拆解指标**：除宏观胜率外，按空间轴失败分布、卡牌条件动作概率、策略提及vs执行对齐度等指标可精准定位语言敏感瓶颈，为针对性微调提供信号。
- **脚本级特征建模机会**：拉丁脚本马来语受益于正字法迁移的表现提示，未来多语言预训练或 SFT 可显式引入 script family 软提示或对比学习损失，缩小非拉丁语技能鸿沟。
