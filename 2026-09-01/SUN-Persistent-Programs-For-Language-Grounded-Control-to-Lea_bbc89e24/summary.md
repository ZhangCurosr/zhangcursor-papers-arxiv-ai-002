# 论文速读：SUN: Persistent Programs For Language-Grounded Control-to-Learning-to-Real Policies

## 一句话总结
本文提出 SUN Program（语义统一程序）与 Kuafu 系统，通过 LLM 从自然语言合成可执行的任务程序，经 MPC 闭环仿真筛选后持久保留，用于训练阶段条件策略并生成高质量仿真数据，最终实现零样本 sim-to-real 迁移，在九项操作任务上达到 82.03% 宏观成功率，显著优于稀疏奖励（35.67%）和 Stage-BC（24.75%）基线。

## 研究问题与动机
- **控制与学习的语义鸿沟**：模型控制精确编码任务结构，学习则将行为摊还进反应式策略，但现有方法在两者交接时丢弃任务语义，导致奖励手工设计、行为漂移，且错误仅在部署后才暴露。
- **奖励工程脆弱且低效**：RL 需要稠密结构化奖励，手动设计耗时且脆弱；自动奖励生成方法需等待完整训练后才能评估，迭代成本高昂。
- **MPC 对模型保真度敏感**：基于模型的规划在模型失配、观测噪声或规格错误时易失败，且每新任务均需大量人工工程。
- **已有桥接方法语义不持久**：现有工作将任务结构重新编码为独立学习信号，导致阶段逻辑需重新实现，奖励可能与控制验证的规范产生漂移。

## 核心贡献（创新点）
1. **提出 SUN Program**：一种类型化可执行程序，将几何与接触关系定义一次并编译为对齐的 MPC 代价、满足谓词、RL 奖励与阶段转移守卫，消除控制→学习→部署链中的语义漂移。与已有工作的本质区别在于：关系身份、接地与容差在整条流水线中保持固定，而非被重新编码为分离信号。
2. **提出 Kuafu 系统**：由大型视觉语言系统驱动，从自然语言和场景语义自动合成 SUN Program，经 MPC 可行性筛选后持久保留，训练阶段条件策略，无需手工密集奖励或种子演示。与 Eureka/VoxPoser 等方法的本质区别：语言交互从每次执行的重复成本转化任务级一次性成本。
3. **证明程序持久性随任务视距缩放**：在九项任务上，Kuafu 的增益不仅来自行为迁移，更来自已验证语义的持续监督；长视距任务（T6、T7）上 Kuafu 保持 87.25%/95.21% 成功率，而基线无法超越 13.81%/38.80%。
4. **实现高效数据生成与零样本 sim-to-real**：以 500 轨迹/任务的数据量训练 DP3 达 46.0% 仿真成功（对手方法 22.4%），并在实体 Franka/Kinova 机器人上实现 34.7% 零样本迁移成功率。

## 方法详解

**SUN Program 结构**：给定自然语言指令 I、场景帧库 F 和类型化算子库 L，LLM 从 L 中选取算子模式并绑定到 F 中的注册帧，组织为有序阶段。Program 定义为：

$$\Gamma = \{\Gamma_k\}_{k=1}^{K}, \quad \Gamma_k = \{(e_{k,j}(x, \xi_k), \epsilon_{k,j}, w_{k,j})\}_{j=1}^{m_k}$$

其中 $K$ 为阶段数，$e_{k,j}$ 为接地物理关系，$\epsilon_{k,j}$ 为容差，$w_{k,j}$ 为学习权重。每个关系编译为三接口：MPC 代价项 $\phi_{k,j}^{\mathrm{mpc}}$、阶段监视谓词 $P_{k,j}$、RL 学习项 $c_{k,j}^{\mathrm{rl}}$。

**阶段推进**：扩展状态 $\tilde{x}_t = (x_t, z_t, \xi_{z_t})$，$z_t$ 为当前阶段，$\xi_k$ 记录进入阶段 k 时的物理快照。当所有谓词满足（$D_{z_t}$）时不可逆地进入下一阶段，新阶段初始化入口快照。

**MPC 筛选**：对候选 Program 在 10 个初始条件下闭环仿真筛选，至少一次达成物理目标且无假完成即接受；失败可触发最多 5 轮诊断修复。MPC 优化问题为直接多重射击：

$$\min_{x_{1:H}, u_{0:H-1}} \sum_{h=0}^{H-1} \ell_{z_t}(\tilde{x}_h) \quad \text{s.t.} \quad x_{h+1} = f(x_h, u_h)$$

**独立评估器**：每个任务配备手工编写的独立评估器 $g_{\mathrm{ext}}$，与 SUN Program 无关，提供稀疏终端信号用于接受、校准和最终评估；假完成指 SUN 监视器声明最终阶段完成但 $g_{\mathrm{ext}}$ 未判定物理成功。

**策略学习**：
- Stage-BC：收集 1000 条物理成功 MPC 轨迹训练确定性阶段条件 BC 策略 $\pi_\theta$，预测 10 步 action chunk，训练严格阶段绑定。
- 有界残差 RL：冻结 $\pi_\theta$ 后训练加法残差策略 $\pi_\psi$（PPO + GAE）：

$$\pi(o_t, z_t) = \mathrm{clip}(\pi_\theta^{(1)}(o_t, z_t) + \alpha_\rho \pi_\psi(o_t, z_t), u_{\min}, u_{\max})$$

其中 $\|\pi_\psi\|_\infty \leq \rho_{\max}$。

**程序衍生残差奖励**：

$$r_t = \lambda_{\mathrm{prog}}[S_{z_t}(\hat{x}_{t+1}) - S_{z_t,t-1}^{\mathrm{best}}]_+ + \lambda_{\mathrm{stage}}\mathbb{I}[z_{t+1}>z_t] + \lambda_{\mathrm{true}}\mathbb{1}[\mathrm{TS}_t] - \lambda_{\mathrm{false}}\mathbb{1}[\mathrm{FC}_t] - \lambda_{\mathrm{act}}\mathbb{I}[\|u_t\|_2^2]$$

阶段进度分数 $S_k(\tilde{x}) = 1 - \frac{\sum_j w_{k,j} c_{k,j}^{\mathrm{rl}}(\tilde{x})}{\sum_j w_{k,j}}$，奖励单调进步。

**LLM 校准**：用 LLM agent 调节奖励权重、残差强度 $\alpha_\rho$ 和残差界 $\rho_{\max}$，但谓词容差、逻辑、接地关系、阶段顺序固定不变。

**数据生成**：训练完成的控制器在无特权状态信息下生成轨迹，仅用记录 observations/actions 训练下游视觉策略。

## 实验与结果

**数据集与任务**：Isaac Lab 5.1 中 9 项多阶段操作任务（T0-T8）：推动、双立方体堆叠、拉抽屉、急停扭转、扶正瓶子、马克笔插入杯子、三立方体堆叠、抽屉开并放置物体、灵巧悬挂。

**主要结果**：
- Kuafu 宏观成功率 **82.03%**（$L_{42}$），3 条独立谱系平均 **79.43%**，假完成率仅 **0.60%**。
- 对比基线：稀疏奖励 + 有界 RRL = 35.67%，Stage-BC 单独 = 24.75%，Eureka 最佳 ≤5 轮 = 18.24%，VoxPoser = 10.00%。
- **计算效率**：Kuafu 总计 122.67 GPU 小时 vs. Eureka 479.60 GPU 小时（3.91× 优势）。
- **语言交互**：Kuafu 每任务 110.5k tokens vs. Eureka 234.4k；VoxPoser 每次 rollout 16.99 次调用/31.6k tokens，2 次执行后超过 Kuafu。
- **数据效率**（500 轨迹/任务训练 DP3）：Kuafu = **46.02%** vs. SkillMimic（最强替代）= 22.44%（2.05× 差距）；T5/T6 上其他方法 0%，Kuafu 分别达 15.80%/12.70%。
- **Q95 产出率**：Kuafu = **57.3%** vs. MimicGen = 20.4%（2.81×），轨迹最平滑（相对 MPC50：完成时间 1.04、EEF 路径 0.67、动作路径 0.52）。
- **数据生成吞吐量**：Kuafu 每 GPU 小时生成 **246.79 分钟**成功轨迹，为人类遥操作（23.34 min/hr）的 **10.57×**。
- **Sim-to-Real**：DP3 在 Franka FR3/Franka Hand/Kinova Gen3 共 106 次物理试验达 **34.72%** 宏观成功率，零样本无需微调。
- **视觉策略**：ManiFlow-PC 单任务最大均值 46.46%，DP3 46.02%，均超过最强 RGB 策略 38.52%。

## 相关工作脉络
1. **ReKep**：将多阶段任务表达为接地关键点代价序列并在闭环中优化；Kuafu 的区别在于 SUN Program 从控制验证到策略学习全程保持语义持久，而非各阶段独立重新编码。
2. **Eureka**：用 LLM 自动生成奖励函数并通过 RL 迭代搜索；Kuafu 将 LLM 限制为可执行的几何关系，受 MPC 闭环物理筛选，避免全训练周期的高昂评估成本。
3. **VoxPoser**：将语言映射为可组合 3D 价值图；Kuafu 的区别：使用固定的类型化算子库和显式阶段结构，而非每次 rollout 重复 LLM 推理。
4. **MPC-Net**：用哈密顿损失编码原始控制目标训练策略；Kuafu 保留完整 SUN Program 作为持续监督源（阶段转移、残差奖励、假完成检测），而非仅用终态损失。
5. **PLATO**：用自适应轨迹优化适配学习者状态分布；Kuafu 用固定 MPC 筛选的可执行程序作为先验，不依赖学习者的状态分布偏移。
6. **SkillMimic/MimicGen**：将稀疏演示转换为多样化模仿数据；Kuafu 的数据具有独立于原始演示的 grounded monitor 验证，不依赖演示语义绑定。

## 局限性与未来方向
- SUN Program 依赖注册场景接口和有限类型化算子库，**无法处理变形物体或流体**，除非定义新算子。
- 未覆盖**保留指令、新算子、新场景语义或新任务组合**的测试，限制了开放世界泛化的强结论。
- 阶段监视器**单调推进，不支持物理退化后的回滚**。
- Q95 指标是 MPC 相对的，衡量相对于特定规划器的效率而非绝对轨迹质量。
- Sim-to-real 验证仅覆盖 6 项任务 106 次试验，**未在非结构化环境中验证广泛迁移可靠性**。
- 未来方向：扩展算子库以支持柔性体和流体、支持跨任务/场景泛化、引入回滚机制、探索真实世界的持续校准。

## 研究启发与可借鉴点
1. **语义持久的交叉流水线设计**：将任务语义定义为一次编译、多处消费的持久 artifact，可有效防止控制→学习→部署链中的语义漂移，这一思想可迁移到任何需多阶段监督对齐的机器人学习管线。
2. **MPC 作为高效筛选器而非仅轨迹生成器**：用模型预测控制验证任务规格可行性，在政策训练前拦截无效规范，可将高成本的 RL 重试循环转化为低成本的闭环仿真筛选。
3. **有界残差学习架构**：冻结 BC 先验 + 有界加法残差的政策结构（$\pi = \mathrm{clip}(\pi_\theta + \alpha_\rho \pi_\psi)$）兼具稳定性和适应性，适合从高质量先验出发的 fine-tuning 场景。
4. **程序衍生奖励的工程实践**：将几何关系直接编译为 RL 奖励项（单调进步奖励 + 阶段转移 + 真/假完成信号）提供了无需手工调参的稠密奖励方案，可推广到其他具有明确几何约束的操作任务。
5. **LLM 角色定位**：将 LLM 限制为"从已有算子库中选择和绑定"而非"发明新关系"，降低了合成复杂度并提高了可靠性；这一约束设计值得在需要可靠性的机器人程序生成任务中借鉴。

## 关键术语表
**SUN Program（Semantically UNified Program）**：一种类型化可执行程序，将任务几何与接触关系定义一次并编译为对齐的 MPC 代价、RL 奖励和阶段转移守卫，在控制→学习→部署全程保持语义固定。

**Stage-BC（阶段条件行为克隆）**：以当前阶段 $z_t$ 为条件的行为克隆策略，预测固定长度的 action chunk，训练严格阶段绑定，不允许跨阶段预测。

**有界残差 RL（Bounded Residual RL）**：在冻结 BC 先验基础上训练加法残差策略，残差受坐标级边界约束，确保策略偏离可控范围。

**假完成（False Completion）**：SUN 监视器内部谓词判定阶段完成，但独立评估器 $g_{\mathrm{ext}}$ 未检测到实际物理成功的错误事件。

**Q95 产出率**：rollout 同时满足物理成功且完成时间、EEF 路径、动作路径和动作二阶差分均在成功 MPC 轨迹的 95 分位数以内的比例。

**谱系（Lineage）**：从接受的 SUN Program 到其 MPC 轨迹、Stage-BC 先验、有界残差控制器再到最终评估策略的完整链条。

**程序衍生奖励（Program-derived Reward）**：由 SUN Program 中的关系项和权重直接编译生成的 RL 奖励信号，包括单调进步、阶段转移、真/假完成等分量。

**独立评估器（$g_{\mathrm{ext}}$）**：手工编写、与 SUN Program 完全独立的外部任务成功评估函数，作为最终评估和假完成检测的 ground truth。

## 可复现要素
- **数据集**：论文使用 Isaac Lab 5.1 仿真环境，9 项自定义操作任务；未提及公开数据集。
- **代码/权重**：论文未明确声明代码开源状态（Kuafu 标记为 footnote 1，但未给出 GitHub 链接）。
