# 论文速读：Which-Rules-Matter-Now-Policy-Centroid-Routing-Before-an-Int

## 一句话总结
论文提出了"策略质心路由"（Policy-Centroid Routing）机制：在智能系统采取行动前，通过语义空间中的质心距离测量，从非结构化操作描述中路由出可能适用的多项政策体系，解决"注意力该投向何处"的上游问题而非直接进行合规判断。论文目前为概念性/理论性工作，尚未报告已完成实验。

## 研究问题与动机
- **上游注意力分配问题**：同一操作可同时触及信息安全性、隐私、采购、AI治理等多个重叠政策体系；系统必须在结构化请求形成之前，先确定哪些权威体系应进入审查。
- **现有结构化系统的边界**：XACML、OPA等正式策略架构需要已结构化的决策请求和机器可读属性，但"如何把世界的语言（非结构化意图）连接到应被检查的正式体系"仍未解决。
- **自然语言策略与不完整行动描述**：大量规则仍以自然语言表述而非结构化代码；行动本身往往是不完整的意图描述，缺乏判断所需的关键事实，系统需先识别哪些体系"已被接近"。
- **避免将路由混同为判决**：现有检索/问答任务可召回法条但未必确立其管辖权；本文强调路由只是"先于判决的注意力分配"，不替代机构对条件、例外、冲突的解释权。

## 核心贡献（创新点）
- **提出策略质心路由的概念框架**：将策略景观视为可搜索的语义几何空间，用声明式质心与阈值实现多策略体系的同时触发，区别于既有的单一路径匹配或结构化引擎。
- **给出可检验的六项命题与七项研究计划**：涵盖比较路由、尾部保留、信息泄露检验、与结构化工作流的互增价值、选择性预测边界等，形成系统性的实证议程而非孤立评测。
- **澄清"路由≠判决"的功能分层**：明确机制停在"路由/ Abstention"层，把条件解释、例外裁决与执行留给下游权威，避免语义检索越界替代机构判断。
- **开放参考实现以支持可检视的验证**：提供基于确定型 TF-IDF 编码器的合成可执行演示，强调其为"机制可检视性证明"而非效力证据，鼓励独立复现与对比。

## 方法详解
- **策略体系统一表示**：设策略集 $\mathcal{P} = \{P_1, \ldots, P_m\}$，$P_j = (\mathrm{id}_j, \ell_j, E_j)$，其中 $E_j = (p_{j1}, \dots, p_{j n_j})$ 为该体系的策略表达序列；表达可跨体系复用。
- **共享编码与归一化**：预定义编码器 $\phi: \mathcal{T} \to \mathbb{R}^d$ 将策略文本与操作文本映射到同一空间；总归一化 $N(v) = v / \|v\|_2$（零向量除外）。
- **质心构造**：$z_{ji} = N(\phi(p_{ji}))$，$\bar{z}_j = \frac{1}{n_j} \sum_i z_{ji}$，$c_j = N(\bar{z}_j)$，即归一化后算术平均的代表质心；一个体系可设多个质心（论文中为备选扩展）。
- **路由得分与阈值判定**：操作 $x$ 编码为 $a = N(\phi(x))$，得分 $s_j(x) = a^\top c_j$（余弦相似度）；对声明阈值 $0 < \tau \le 1$，路由集合为 $R_{\phi,\tau}(x) = \{(id_j, \ell_j, s_j(x)) : s_j(x) \ge \tau\}$，采用包含式不等号、不设 top-k 截断；空集合视为"回避/ abstain"而非授权。
- **失败闭合（fail-closed）设计**：零向量、重复标识符、格式错误、维度不匹配等情形在输出前被拒绝，避免生成虚假路由。
- **声明式度量和阈值**：距离/相似度的具体度量、多质心构造、阈值选择方法均为实验变体，不在基线内默认；审查预算（review budget）作为评估约束而非机制组件。
- **合成参考实例**：使用确定性 TF-IDF 编码器（仅在策略表达上拟合）、归一化算术质心、余弦相似度与包含式阈值，便于人工检视，但不声称具最佳实证表示力。

## 实验与结果
- **当前状态**：论文明确声明"没有任何已完成的实证研究、试点结果或效能声明"，实证账本"仍为空"（Section 8）。
- **参考实现**：提供一个有界参考实现，基于 TF-IDF + 余弦 + 包含式阈值的合成演示，代码与机制可检视，但不代表实证系统。
- **待执行研究计划（七项）**：Study 1 比较基线路由与强候选方法在相同审查负担下的表现；Study 2 定位压缩对稀有/条件/少数/交叉结构的破坏；Study 3 去除下游答案语言后检验剩余信号；Study 4 与成熟结构化工作流并置、计入适配与人力成本；Study 5 在可辩护层次结构下检验前门质心对下游检索目标的增量增益；Study 6 在冻结版本策略修订下追踪路径；Study 7 在独立领域复现失败模式与边界。
- **报告原则**：要求报告"完整处置"（完整排列、覆盖率、尾部/重叠损失、回避率），而非仅呈报最佳单项指标。

## 相关工作脉络
- **XACML / OPA / OSCAL 等结构化策略架构**：需在结构化请求与显式属性上才能选择与求值策略；本文定位为其上游——把非结构化行动描述链接到应被检索的正式体系。
- **策略文本分析系统（Polisis 等）**：在已建立领域与分类法后可标注、分类、查询长规则；本文关注其前提（行动描述如何被附加到相关体系）之前的路由问题。
- **法律/策略检索任务（PolicyQA、FR statute retrieval 等）**：可在已知文档内抽取答案语句，但未必确立管辖权；本文强调"路由对象"与"权威判断"的分层。
- **检索技术家族**：BM25/SPLADE（词项与稀疏扩展）、DPR（稠密向量）、ColBERT（晚期交互）分别保留不同粒度的信号；论文主张通过"相同信息机会与负担下的比较"来界定质心路由的独特价值。
- **原型网络与多原型聚类（Prototypical Networks、Mixture Prototypes、Polythetic classification）**：启发"用代表性向量组织类别"的可行性，但也提示单质心对复杂/组合类群的覆盖风险。
- **选择性预测与概念漂移（SelectiveNet、MultiEURLEX、Concept Drift survey）**：提供 abstention 的风险-覆盖词汇与时间切片评估思路，用于划定方法的可报告边界。

## 局限性与未来方向
- **尚无实证验证**：核心命题均未测试，机制的召回/精确/尾部保留/冲突处理能力仍是未知。
- **压缩带来的尾部与交叉遗漏风险**：算术质心放大常见语言、可能稀释稀有义务与条件性组合规则（长尾分类、多质心文献的风险在此重现）。
- **多标签坍缩**：行动靠近一个主导体系时，其他并存适用的体系可能被阈值吞没；需要 exact-set recovery 与 per-regime recall 等细粒度度量。
- **编码器与度量选择的任意性**：表示决定哪些区别进入空间；后验选择几何等价于搜索胜利，必须在实验前声明。
- ** Oracle 不完备与时间维度**：策略修订、语料变化、行动分布漂移会破坏静态评估的稳定性；当前不提出在线更新方案。
- **未来方向**：完成七项对照研究；发展多质心/层次质心构造；引入分层与选择性预测接口；在不同法域与策略版本间进行独立复现。

## 研究启发与可借鉴点
- **"注意力分配先于判断"的分层设计**可迁移到其他需要"先识别适用范围再决策"的领域（如代码合规、医疗协议路由、内容审核分流），避免将检索混同为裁决。
- **多体系同时触发与审查预算对齐**的思路：通过声明式阈值保留"并行业务"视角，而非只取 top-1；与 selective prediction 的 coverage-risk 权衡结合，能形成可报告的 abstention 行为。
- **合成可检视基线（TF-IDF + 算术质心 + 余弦）**的价值：为后续稠密编码器、多质心、Mahalanobis 距离、分层阈值等变体提供干净的对照起点，便于隔离"表示"与"机制"的贡献。
- **完整处置报告规范**优于单一指标汇报；把 rare-policy 损失、overlap-specific recall、abstention 率并列呈现，可直接复用到多标签、分层分类、法律文本评测的审稿标准中。
- **与结构化工作流互补的实验范式**（Study 4/5）：计入适配器与人工劳动成本后的"固定总负担比较"，为 RAG/检索增强治理管线的设计提供可复用的经济学评估框架。

## 关键术语表
- **Policy-Centroid Routing（策略质心路由）**：在共享语义空间中，用策略表达压缩出的代表质心度量操作距离，从而将可能适用的多项政策体系路由给下游审查的机制。
- **Policy Regime（策略体系）**：由机构事先确定的权威集合，具有唯一标识、可读标签与一组策略表达；是路由的对象而非被路由发现的实体。
- **Policy Centroid（策略质心）**：某策略体系内所有归一化表达向量的算术平均再归一化得到的代表向量；可为单个或多个。
- **Abstention（回避/放弃路由）**：当操作未跨越任何声明阈值时返回空路由集，需由机构预设的后备流程接手，不等于允许行动。
- **Review Budget（审查预算）**：评估阶段为各候选方法分配的同等处理/人工预算，用于控制"以无限召回换召回率"的伪提升。
- **Exact-Set Recovery（精确集恢复）**：要求把该体系全部真正适用的 regime 都召回，而非仅命中部分或 top-1，针对多标签治理场景的核心度量。
- **Fail-Closed（失败闭合）**：遇到零向量、维度失配、重复标识、格式异常时返回错误或拒绝输出，避免产生误导性路由。
- **Selective Prediction（选择性预测）**：允许模型在不确定时拒绝输出并给出风险-覆盖权衡，本文用以形式化路由的 abstention 操作含义。

## 可复现要素
- **数据集**：论文提供合成工作示例（synthetic worked example）；未使用外部公开基准。政策/法律相关讨论引用了 MultiEURLEX、PolicyQA、FR statute retrieval 等既有资源的动机与比较维度，但本文未在其上完成评测。
- **代码**：开源。有界参考实现发布于 `github.com/SRF-PBC/policy-centroid-routing`，实现声明式路由回路、完整有序分数记录、对畸形/非有限输入 fail-closed。
- **权重**：论文未训练/提供专用模型权重；参考实现使用确定性 TF-IDF 编码器（仅在策略表达上拟合）。
- **关键超参**：编码器 $\phi$（论文基线为 TF-IDF）、余弦相似度、声明式阈值 $\tau$、是否多质心（基线为单质心）。阈值选择方法为实验变体，未在基线中固定。
