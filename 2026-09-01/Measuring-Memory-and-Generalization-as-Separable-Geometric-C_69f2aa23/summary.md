# 论文速读：Measuring-Memory-and-Generalization-as-Separable-Geometric-C

## 一句话总结
提出 Topo² 测量框架，利用持久同调 $H_1$ 将表征空间因果分离为类内流形通道（$H_1^{\mathrm{within}}$）与类间通道（$H_1^{\mathrm{cross}}$），并通过 FM0 零损失干预实现记忆与泛化的可度量、可叠加/剥离与可逆操作，最终确立记忆-泛化拓扑分层定律（TLS）与量化记忆成本公式。

## 研究问题与动机
- 现有噪声训练评估多以单一标量（如 noisy 样本训练损失）回答“是否记忆”，混淆了过拟合与记忆，无法定位记忆在表征几何中的位置，亦无法将其剥离。
- 缺乏可因果操纵的测量工具，泛化能力与记忆负载长期被视作同一容量维度的压力，难以独立优化或诊断。
- 拓扑数据分析（TDA）在深度学习中多停留于描述性统计，尚未建立可与训练动力学绑定的可验证定律与干预协议。
- 科学测量框架需经过严格的仪器证验并公开失败假设，以明确工具的适用范围与边界。

## 核心贡献（创新点）
1. **双通道拓扑测量协议**：用 $H_1$ 分解表征空间为 $H_1^{\mathrm{within}}$（类内局部密度均匀性）与 $H_1^{\mathrm{cross}}$（邻域标签混合度），并通过六类全局统计量的排除链验证其携带独立信息。
2. **因果干预工具 FM0 与操作算子**：从 epoch 0 起对翻转标签样本施加零损失，构建纯净泛化基底；配套 Overlay（叠加）、Strip（剥离）、Re-anchor（重锚定）三操作形成封闭因果实验空间。
3. **记忆-泛化拓扑分层定律（TLS）**：确立记忆的四重可测性质——因果可加性、干净特征锚定性、$H_1^{\mathrm{within}}$ 次级响应性、以及可计费性（记忆成本定律）。
4. **轨迹决定论与评估 cadence 分析**：证明 $H_1^{\mathrm{within}}$ 是 RNG 序列的确定性函数，揭示中间评估通过消耗全局随机种子扰动数据顺序并改变 attractor，使轨迹从观测上升为可预测定律。
5. **诚实框架记录**：公开九项证伪终点（如选择性遗忘、环过载、独立预测假设等）与两项自我修正（G1 管道伪常数、C2 语义澄清），明确测量工具的边界条件。

## 方法详解
- **$H_1$ 管道与归一化义务**：在测试特征流形上，计算同类子流形的 $H_1$ 循环数得 $H_1^{\mathrm{within}}$，计算跨类连接复形的 $H_1$ 得 $H_1^{\mathrm{cross}}$。强调 $H_1^{\mathrm{cross}}$ 绝对值随 N\_PAIRS×N\_INTERP 线性缩放，跨模型对比必须固定管道并报告；rng 采样噪声约 ±15–30%，大效应（≥2×）不受影响。
- **双范围记忆读出**：以 `mem_noisy`（未增强、未打乱加载器上预测值等于噪声标签的翻转样本比例）为决定性读出，辅以 `mem_clean`；CONT 模式 mem_noisy≈0.999，FM0≈0.004。
