# 论文速读：SingProbe-Technical-Report

## 一句话总结
SingProbe 是一种轻量级内生运行时护栏，直接复用冻结基础大模型自回归解码过程中的隐藏状态，以约 2M 额外参数和 <0.5% 延迟开销在 token 级同步预测查询意图、响应安全性与幻觉风险，并进一步拓展为可引导受限安全解码与按需医疗风险干预的生成期控制系统。

## 研究问题与动机
- **独立护栏引入冗余计算与部署负担**：现有方案多采用独立外部模型二次编码输入，造成额外的前向传播、通信同步与运维复杂度。
- **安全信号滞后，缺乏细粒度干预能力**：传统护栏仅在完整响应生成后或 chunk 级别评估，无法在危险内容首次出现时及时截断或修正。
- **容量错配限制复杂场景下的判断可靠性**：独立护栏参数量通常远小于被监控的主模型，面对长上下文、多轮 agent 任务时难以充分理解输出语义。
- **流式评测缺乏对时序行为的显式验证**：现有安全基准仅提供响应级标签，无法检验检测器是否在安全前缀保持静默、在危险 onset 准时响应，且 Token 级标注本身存在语义噪声。

## 核心贡献（创新点）
1. **内生流式护栏架构**：直接拼接基础模型浅/中/深三层隐藏状态输入轻量注意力头，替代独立外部编码器，实现查询意图、响应安全与幻觉的 token 级联合预测，参数量大幅缩减且无需重复文本编码。
2. **自适应置信度加权训练机制**：针对安全/幻觉仅有响应级粗粒度标签的问题，提出基于预测标准差门控的 Token 加权聚合器，在早期预测分化不足时退化为均匀平均，分化后强化高风险 token 监督，有效抑制训练噪声。
3. **SingStreamBench 流式安全基准**：构建 Tier 0–5 分层手工验证评测集，显式测试护栏在安全前缀下的静默能力与危险内容出现时的即时定位精度，弥补现有基准仅关注最终响应级标签的不足。
4. **按需干预解码范式（SingProbe-Med）**：将内生信号解耦为“何时干预”（四信号分层准入策略）与“如何干预”（目标支持的对比重定向解码 sGDS），仅在临床风险前缀激活有界双分支，兼顾安全性与基座模型通用能力。
