# 论文速读：Stratified-Consistency-Distillation-for-Natural-Language-Formalization

## 一句话总结
论文提出**分层一致性蒸馏（SCD）**框架，将前沿大模型（如 Claude Sonnet 3.7）的自然语言→SMT-LIB 逻辑翻译能力，通过语义熵分层的伪标签选择机制，高效蒸馏至轻量开源模型（Qwen2.5-7B-Instruct）。在 FOLIO 基准上 Pass@10 达到 55.208%，显著超越更大规模的预训练模型，同时将推理延迟降低约 4.1 倍。

## 研究问题与动机
1. **高 stakes 场景的逻辑可靠性需求**：LLM 在合规、定价、监管等领域易产生幻觉，需将自然语言转化为可被符号求解器（如 Z3）验证的 SMT-LIB 公式以保障逻辑严谨性。
2. **现有方法依赖提示工程且难以扩展**：当前 NL2SMT 任务主要依赖前沿 LLM 的 few-shot/CoT 提示，跨领域、跨输入格式的泛化与规模化成本极高。
3. **前沿模型不可微调且算力昂贵**：70B–500B+ 参数的前沿模型通常闭源且仅开放 API，无法通过 fine-tuning 持续优化，性能上限被限制在 prompt 设计层面。
4. **缺乏针对逻辑翻译的软/硬标签蒸馏机制**：多采样候选的噪声与歧义未被系统利用，简单多数投票或单点监督难以在低熵（高置信）与高熵（高歧义）样本间取得平衡。

## 核心贡献（创新点）
1. **提出分层一致性蒸馏（SCD）框架**：依据符号语义熵将样本划分为低/中/高三层并分别采用多数投票、LLM-as-a-Judge、统一/弃权策略，与全量微调或单点提示的本质区别在于**自适应分配蒸馏信号的置信度权重**。
2. **将语义熵扩展至符号逻辑空间**：利用 Z3 求解器验证 SMT-LIB 候选的逻辑等价性进行聚类，并定义符号语义熵量化翻译不确定性，区别于传统基于 token 概率的文本熵，**直接作用于形式化结构的语义一致性**。
3. **构建从非结构化政策文档自动生成 NL-SMT-LIB 对齐数据的流水线**：通过 LLM 抽取声明、生成 Q&A 并翻译，实现无需人工标注的可扩展合成数据生产，与手工构建数据集相比**大幅降低垂直领域知识抽取成本**。
4. **在精度与效率上双重突破**：蒸馏后的 7B 模型在 FOLIO 上 Pass@10 达 55.208%，以不到一半的参数超越 14B 预训练模型，并在保持 4.1× 延迟优势的同时实现更强的逻辑对齐，证明**小模型+高质量伪标签蒸馏**在该任务上的可行性。

## 方法详解
SCD 流程分为四个阶段，输入为自然语言 prompt $p$：
1. **冗余生成**：调用前沿教师 LLM（Claude Sonnet 3.7）采样 $M=10$ 个 SMT-LIB 候选 $\{t^{(1)}, \dots, t^{(M)}\}$，使用 vLLM 加速推理。
2. **等价聚类与符号语义熵计算**：通过 `check_smt_equivalence` 函数（基于 Z3 验证双向蕴含是否不可满足）将候选分组为语义等价类 $\mathcal{C}=\{C_1,\dots,C_{|\mathcal{C}|}\}$。计算熵：
   $$\mathrm{SE}(p) = -\sum_{i=1}^{|\mathcal{C}|} P(C_i|p)\log P(C_i|p)$$
   其中 $P(C_i|p)$ 为第 $i$ 个簇的样本占比。
3. **分层伪标签选择**：
   - **低熵**：分布高度集中于主导簇，直接选取最大簇的代表翻译 $\hat{t} \in \arg\max_{C_i}|C_i|$。
   - **中熵**：Top-2 簇竞争激烈，启用教师 LLM 作为 Judge 进行裁决。
   - **高熵**：候选分布均匀、分歧严重，对 Top-2 翻译进行结构统一或直接丢弃该样本。
4. **知识蒸馏**：使用筛选后的 $(p, \hat{t})$ 配对数据，以 LoRA（rank=32, $\alpha$=64, lr=$5\times10^{-5}$, batch=32）微调 Qwen2.5-7B-Instruct。

## 实验与结果
- **数据集**：FOLIO（开源一阶逻辑推理 benchmark，含政策对话与受控逻辑推理场景）；消融实验额外使用客服领域合成数据集。
- **评估基线**：Qwen3-4B/8B/14B、Mistral-7B-Instruct、Qwen2.5-7B-Instruct（few-shot）、Claude Sonnet 3.7（few-shot）。
- **核心指标**：Pass@K（Z3 验证逻辑等价）与连续相似性得分 [0,1]（Egglog 抗统一化）。
- **主要结果（FOLIO）**：
  - 原始 Qwen2.5-7B-Instruct：Pass@10 = 21.875%
  - Vanilla Distillation：Pass@10 = **50.347%**（超 Qwen3-14B 的 7.639pp）
  - **SCD：Pass@10 = 55.208%**（最优，超 Qwen3-14B 达 12.500pp，超 Vanilla 4.861pp）
- **延迟优势**：蒸馏后 Qwen2.5-7B-Instruct P50=4.040s，较 Claude Sonnet 3.7（16.680s）快 **~4.1×**；P90/P99 同样保持显著优势。
- **消融结论**：低熵样本训练始终优于高熵样本；Top@2 簇选择策略已接近 Oracle 上限（Pass@10），验证了分层选择的合理性。

## 相关工作脉络
1. **LLM 逻辑推理增强**（CoT、SFT、RLHF）：本文不优化推理链生成，而是聚焦**自然语言到形式化逻辑的直接翻译**，并与 Z3 求解器深度对接。
2. **自动形式化（Autoformalization）**：传统工作面向数学定理证明（Lean/Coq/Isabelle），本文面向企业政策与自然语言的 SMT-LIB 映射，填补工业级合规推理落地空白。
3. **语义熵幻觉检测**（Farquhar et al., 2024）：原用于文本生成的不确定性度量，本文将其迁移至**符号逻辑等价空间**，提出可计算的“符号语义熵”。
4. **提示蒸馏与多采样聚合**：现有方法多依赖单点或简单多数投票，SCD 通过熵分层实现**置信度感知**的标签选择，更贴合逻辑翻译任务的离散等价性特征。
5. **参数高效微调（LoRA）**：结合分层伪标签替代全量微调，在保持 SMT-LIB 语法与逻辑约束对齐能力的同时大幅降低训练成本。

## 局限性与未来方向
1. **高熵样本被丢弃或强制统一**，可能丢失部分困难但具判别价值的边界案例，影响模型在复杂策略上的鲁棒性。
2. **熵分层阈值依赖经验设定**，跨不同领域政策文档或不同教师模型时可能需重新校准。
3. **当前仅验证 SMT-LIB 形式化**，未探索向完整一阶逻辑量化嵌套、动态声明扩展的场景。
4. **教师模型闭源**，若替换为开源教师（如 Qwen3-14B/72B）蒸馏上限尚未验证，实际落地可能受限于教师可用性与版权。

## 研究启发与可借鉴点
1. **“熵分层+自适应伪标签选择”范式**可直接迁移至代码生成、数学公式翻译、协议解析等多候选生成任务，替代僵化的 majority vote 或单样本监督。
2. **符号工具驱动的评测替代纯文本相似度**：利用 Z3/Egglog 等求解器与结构压缩技术计算逻辑等价性与连续相似度，为神经符号任务提供可解释、可微（间接）的评估维度。
3. **从非结构化规则文档自动构建 NL-Symbolic 对齐数据流**的管线设计，适用于金融合规、医疗指南、安全策略等强规则领域的知识工程自动化。
4. **小模型 + 分层蒸馏**是算力受限团队提升垂直领域形式化推理能力的有效路径，值得结合本团队在策略执行器或约束满足任务中的方向进行复现与扩展。

## 关键术语表
- **NL2SMT**：自然语言至 SMT-LIB 的逻辑翻译任务，将非形式化文本映射为可被符号求解器验证的形式化公式。
- **SMT-LIB**：广泛采用的符号满足理论求解器标准输入语言，用于表达一阶逻辑、算术约束及声明-定义结构。
- **符号语义熵（Symbolic Semantic Entropy）**：基于 Z3 验证的语义等价聚类分布计算的熵，用于量化模型在逻辑翻译任务中的预测不确定性。
- **分层一致性蒸馏（SCD）**：本文提出的蒸馏框架，依据符号语义熵将样本划分为低/中/高三层并应用差异化伪标签选择策略。
- **Pass@K**：在 K 次独立采样中至少有一次生成结果与地面真实值逻辑等价的百分比指标。
- **LLM-as-a-Judge**：利用前沿大模型作为自动评判器，对多个候选翻译进行质量比对与裁决的方法。
- **Anti-unification**：一种符号结构压缩技术，提取两个 SMT-LIB 公式的最大公共逻辑骨架，用于计算连续相似性得分。
