# 论文速读：VFR-Audit: Verdict-Level Reliability for Fairness Audits in Hospital Length-of-Stay Prediction

## 一句话总结
论文提出了 **VFR-Audit** 框架，通过引入判决翻转率（Verdict Flip Rate, VFR）及三轴可靠性评估，量化医院住院时长（LOS）预测模型中二元公平性审计判决在重复审计与跨院部署下的稳定性，弥补了现有方法仅关注连续指标不确定性而忽略决策层面可靠性的空白。

## 研究问题与动机
1. **临床AI治理依赖二元判决**：医院治理委员会和监管机构根据公平性指标是否超过阈值（如四分之五法则 DI≥0.80）给出“通过/不通过”的二元判决，而非直接使用连续数值。
2. **判决在重复审计中存在不稳定性**：随着新患者记录积累、人口统计特征变化及多站点部署，相同的已训练模型在不同审计队列上可能产生相反的判决（Flip），但现有不确定性方法（如Bootstrap置信区间、贝叶斯后验）仅在连续指标层面量化不确定性，无法直接推导判决层面的稳定性。
3. **缓解干预的效果难以评估**：现有的去偏见步骤（如重加权或分组阈值移动）是否能带来稳定的通过判决尚不明确，且现有工作未将“指标通过”与“判决可靠”区分开来。
4. **缺乏针对LOS预测的公平性审计研究**：既往LOS预测文献普遍缺乏判决稳定性、跨院一致性验证及审计规模指导。

## 核心贡献（创新点）
1. **提出判决翻转率（VFR）指标**：定义了一个介于[0, 0.5]之间的标量，衡量在分层Bootstrap重采样下二元公平性判决发生翻转的概率，从而将连续指标的不确定性转化为治理导向的判决稳定性度量。
2. **开发三轴可靠性框架**：构建了覆盖“队列内重采样稳定性（VFR）”、“审计规模敏感性（最小可靠样本量 $N^*$）”和“跨医院判决一致性（Fleiss’ $\kappa$）”的三个评估轴，并结合为四级可靠性分类体系。
3. **实证揭示判决不可靠的普遍性及干预机制**：在Texas-100X数据集上发现，基线模型的43.5%审计单元存在判决翻转；标准的重加权干预无法通过四分之五法则，而按单元调整阈值是达成全属性通过的主要驱动力，且VFR-Audit能识别出干预导致的稳定性转移现象。
4. **建立了可复现的审计基准**：开源了代码与实验笔记本，为临床AI公平性审计提供了包含预测性能与可靠性双重评估的标准化工具。

## 方法详解
1. **判决翻转率（VFR）计算**：
   - 对审计队列进行 $K$ 次分层Bootstrap重采样（保持标签与属性联合分布），对每个 (模型, 指标, 属性) 单元计算通过率 $n_{pass}$。
   - 公式：$\mathrm{VFR}(c) = \frac{\min(n_{pass}(c), K - n_{pass}(c))}{K}$。
   - VFR=0表示判决完全稳定，VFR=0.5表示判决完全随机（通过/失败各半）。设定操作阈值 $\tau_{VFR}=0.10$，即至少90%重采样结果一致视为稳定。
   - Bootstrap次数固定为 $K=500$，基于最坏情况二项标准误（Monte Carlo误差<0.05）及Hoeffding不等式确定。

2. **三轴可靠性评估**：
   - **轴1：重采样稳定性（VFR）**：评估相同模型在不同审计队列重采样下判决是否一致。
   - **轴2：审计规模敏感性（$N^*$）**：通过 sweeps 不同样本量，计算指标变异系数（CV），找到CV<0.05时的最小样本量 $N^*$，判断单站审计是否可行。
   - **轴3：跨医院一致性（Fleiss’ $\kappa$）**：使用GroupKFold将医院分为20折，以医院折为评分者，计算各公平性指标在跨院判决上的一致性。

3. **可靠性分级规则**：
   - 同时满足 $\mathrm{VFR} \le 0.10$、$N^* \le 5\times10^4$、$\kappa \ge 0.40$ 划分为“实用稳定（Practical-Stability）”；违反一项为“需警惕（Caution-Required）”，两项为“高方差（High-Variance）”，三项为“灾难性不稳定”。

4. **干预策略对比**：
   - **B2 重加权**：Kamiran-Calders交叉公平性重加权。
   - **B3 阈值移动**：在预测概率上针对每个单元搜索SR/TPR/PPV以优化公平性。
   - **B4 VFR-Audit**：在B3基础上，通过贪心细化在保持所有四个DI≥0.80约束下进一步优化VFR。

## 实验与结果
- **数据集**：Texas-100X，包含441家德克萨斯州医院的925,128条出院记录，预测目标为LOS>3天（阳性率45.0%）。
- **基线模型**：12种标准表格分类器（XGBoost为 canonical 模型，AUROC=0.9528）。
- **公平性指标与属性**：7种指标（DI, SPD, EOpp, EOD, TI, PP, Cal）与4个受保护属性（种族、性别、民族、年龄），共28个审计单元/模型。
- **主要结果**：
  - **基线不稳定性**：在未干预的基线上，336个跨模型审计单元中有 **146个（43.5%）** 在Bootstrap重采样下发生判决翻转。
  - **重加权的失效**：无论正则化强度如何，交叉重加权均无法满足四分之五法则（四属性中仅通过1个），因为年龄基础率差异构成了选择率比的下界。
  - **阈值移动的局限**：B3（阈值移动）虽达成四属性全部通过DI≥0.80，但Race-DI和Age-DI的VFR仍高达0.41和0.40，表明判决高度不稳定。
  - **VFR-Audit的改进**：B4（VFR-Audit）在保持准确率仅降低4.24个百分点（相对B1）的同时，将平均VFR从0.0863降至0.0809，最大VFR从0.490降至0.476，且21/28单元达到稳定标准。
  - **跨医院一致性**：Equal Opportunity风格指标跨院一致性较强（$\kappa \approx 0.5$），而DI和Calibration的跨院一致性差（$\kappa$ 接近0或为负），说明在一家医院达成的判决难以迁移至另一家医院。

## 相关工作脉络
1. **LOS预测文献**：既往研究（如MIMIC/eICU数据集上的深度学习和GBDT研究）主要关注预测精度（AUROC/MAE），普遍缺乏对公平性判决稳定性、跨院验证及审计规模的报告。
2. **临床AI公平性审计框架**：FINS和MACAIF等专用审计工具主要关注群体公平性筛选或交互界面，未定义二进制判决不稳定性标量，也未在多站点临床队列上验证。
3. **公平性指标不确定性量化**：现有贝叶斯、Bootstrap置信区间及置换检验方法仅在连续指标层面量化不确定性，未建立指标不确定性到二进制判决稳定性的直接映射。
4. **判决稳定性相关研究**： prior work 指出公平性判决对训练种子敏感或存在预测多重性，但本文首次提出了适用于治理报告的可扩展标量指标（VFR）。
5. **去偏见干预方法**：Kamiran-Calders重加权在此数据集上因基础率差距（Feature-based floor）而失效，凸显了后处理阈值调整相较于预处理重加权在应对基础率差异时的优势。

## 局限性与未来方向
1. **回顾性数据的局限性**：使用的是2006年的行政出院数据，包含终点变量（TOTAL_CHARGES等），尽管通过剔除这些变量进行了鲁棒性检查，但仍需前瞻性入院时特征验证。
2. **交叉公平性的稀疏性**：由于种族×年龄×性别的交叉单元格数据稀疏，主要分析仅限于单属性，精细交叉组的可靠推断受限。
3. **种族编码的非标准性**：THCIC数据集的种族与民族编码存在重叠（99.4%黑人记录也被编码为西班牙裔），结果反映的是行政类别而非自我认同。
4. **未来方向**：需在入院时特征和前瞻性地排除医院上进行验证；扩展至稀疏交叉组（使用层次池化）；开发流式实现以支持近实时的公平性监控。

## 研究启发与可借鉴点
1. **指标稳定性与预测性能解耦**：证明了高预测性能（AUROC>0.95）不等于公平性判决的可靠性，审计框架必须独立评估判决在重采样下的波动。
2. **干预效果的细化归因**：通过对比B3和B4，揭示了“通过”判决背后的稳定性代价，以及去偏见干预可能将不稳定性从一组属性转移到另一组属性（如从Age转移到Race）。
3. **审计规模的量化指导**：提出的 $N^*$ 概念为审计者提供了明确的样本量下限，指出了单站季度审计对于某些指标（如Calibration）可能因样本不足而不可靠。
4. **跨院一致性的度量价值**：引入Fleiss’ $\kappa$ 评估跨院判决一致性，为多站点部署的可迁移性提供了量化工具。

## 关键术语表
- **Verdict Flip Rate (VFR)**：判决翻转率，衡量在Bootstrap重采样下二元公平性审计判决（通过/失败）发生反转的概率，取值[0, 0.5]。
- **Four-fifths rule (四分之五法则)**：源自美国民权法的歧视影响审查标准，要求少数群体通过率不低于多数群体通过率的80%（即DI≥0.80）。
- **Disparate Impact (DI)**：差别影响，一种公平性指标，计算受保护组与对照组的正面预测率之比。
- **Intersectional Reweighing (交叉重加权)**：结合Kamiran-Calders方法与交叉属性（如种族×年龄×性别）进行预处理去偏重的策略。
- **Per-cell Threshold Shifting (按单元阈值移动)**：针对每个（模型, 指标, 属性）单元独立搜索决策阈值以优化公平性指标的后处理方法。
- **Fleiss’ κ (Fleiss' Kappa)**：用于评估多个评分者（此处为医院折）对多个项目（此处为受保护属性单元格）分类一致性的统计量。

## 可复现要素
- **数据集**：Texas-100X (THCIC Public Use Data File)，公开可用。
- **代码**：已开源，地址为 https://github.com/MdJoy31/VFR-Framework。
- **关键超参**：Bootstrap重采样次数 $K=500$，重采样大小 $N=10^4$，VFR稳定性阈值 $\tau_{VFR}=0.10$，Fleiss' $\kappa$ 医院折数 $K_{hosp}=20$。
